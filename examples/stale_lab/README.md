# 오래된 혈액검사 예제

환자에게 3개월 전 혈소판 결과가 있고 당시 수치는 시험 기준 안에 있다. 시험은 최근
14일 이내 공식 검사 결과를 요구한다.

처음 결과는 다음과 같다.

- **후보 유지:** 오래된 결과에서 참가 가능성이 보이므로 시험을 바로 제외하지 않는다.
- **추가 확인 필요:** 최근 14일 이내 결과가 없으므로 현재 확인은 끝나지 않는다.

프로그램은 최근 공식 결과를 요청하고, 새 결과가 들어오면 이 검사와 연결된 조건만
다시 판단한다.

## 파일

| 파일 | 프로그램이 읽는 시점 |
|---|---|
| `system_input.json` | 처음부터 읽는 시험 조건과 환자 기록 |
| `public_questions.json` | 선택할 수 있는 추가 확인 항목과 방법 |
| `hidden_answers.json` | 프로그램이 올바른 확인을 선택한 뒤에만 읽는 합성 답 |
| `gold_initial.json` | 실행이 끝난 뒤 첫 판단을 채점할 때만 읽는 기대 결과 |

숨긴 답과 기대 결과는 질문을 고르는 입력에 포함되지 않는다.

## 실행

```powershell
.\.venv\Scripts\clarifytrial.exe run-example `
  --case examples\stale_lab `
  --output runs\stale_lab
```

최종 결과는 `runs\stale_lab\result.json`, 단계별 변화는
`runs\stale_lab\trace.jsonl`에 저장된다.

이 예제는 외부 언어모델을 부르지 않고 미리 정한 역할별 응답으로 프로그램 연결을
점검한다. 성공 결과는 모델 성능이 아니라 후보 유지와 현재 확인 상태가 의도대로
바뀌는지 보여 준다.
