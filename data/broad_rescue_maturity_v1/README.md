# 넓은 합성 환자 성숙도 점검 자료

최종 성능평가를 시작하기 전에 여러 질환과 정보 부족 상태에서 전체 프로그램이
흔들리지 않는지 확인하는 합성자료다. 실제 ClinicalTrials.gov 참가 조건을 옮긴 자료가
아니며 최종 성능 수치에는 사용하지 않는다.

## 구성

| 항목 | 수 |
|---|---:|
| 질환 | 10개 |
| 합성 시험 | 50개 |
| 합성 환자 | 50명 |
| 환자–시험 조합 | 250개 |
| 완전한 정보에서 참가 가능 | 154개 |
| 완전한 정보에서 제외 | 96개 |

환자마다 다섯 가지 핵심 정보를 정한 뒤, 처음 화면에서는 한 개·두 개·세 개 또는
다섯 개를 가린다. 질환마다 시험과 정보가 연결되는 모양도 세 종류로 나눴다.

확인 방법에는 환자 답변, 기존 기록, 이미 받은 공식 결과와 새 비침습 검사가 포함된다.
새 검사는 환자 선택과 별도 승인이 있어야 실행되는 정보로 표시한다.

## 파일

| 파일 | 내용 |
|---|---|
| `trial_set.json` | 합성 시험 50개와 계산 가능한 조건 |
| `patient_pairs.json` | 완전한 환자 상태, 처음 가린 정보, 확인 방법과 답 |
| `../../configs/broad_rescue_maturity_v1.json` | 질환·값·정보 연결 구조를 다시 만드는 기준 |

## 다시 만들고 확인하기

```powershell
.\.venv\Scripts\clarifytrial.exe build-broad-rescue-dataset
.\.venv\Scripts\clarifytrial.exe audit-broad-rescue-dataset
```

실제 공개 시험 조건과 모집 가능한 589건 검색을 연결한 평가는 이 자료로 대신하지
않는다. 이 자료를 통과한 뒤 공개 시험 50건에 맞춘 최종 합성 환자를 별도로 만든다.
