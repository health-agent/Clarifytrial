# 초기 공개 조건 평가 원문 묶음

`source_snapshot`은 환자별 확인 방법과 부담 제한 실험에서 원문 대조에 사용하는
ClinicalTrials.gov 공개 시험 15건이다. 실험이 나중의 API 수정에 따라 달라지지 않도록
2026-08-30에 내려받은 응답을 그대로 보관한다.

- 출처: ClinicalTrials.gov API v2
- 자료 시각: `2026-08-28T09:00:06`
- 받은 시각: `2026-08-30T14:15:36.825210+00:00`
- 이용 조건: <https://clinicaltrials.gov/about-site/terms-conditions>
- 표시 출처: ClinicalTrials.gov, U.S. National Library of Medicine

각 파일의 시험 번호와 참가 조건 해시는 `source_snapshot/source_metadata.json`에 있다.
원문은 참가 가능 여부의 정답이 아니라, 구조화한 일부 조건이 실제 공개 문구에 있는지
확인하는 데에만 사용한다. ClarifyTrial의 MIT License가 이 제3자 원문의 이용 조건을
대체하지 않는다.
