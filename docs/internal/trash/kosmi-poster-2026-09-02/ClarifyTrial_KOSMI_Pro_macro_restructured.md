## 제목

불완전한 환자 정보에서 제한된 확인 기회와 환자 제약을 고려한 상호작용형 임상시험 사전선별: ClarifyTrial

## 초록

**Backgrounds:** 임상시험 사전선별에서 미확인 정보를 곧바로 충족 또는 불충족으로 처리하면 참가 가능성이 남은 후보를 버리거나 근거가 모자란 시험을 적격으로 확정할 수 있다. ClarifyTrial은 후보 유지 여부와 현재 확인 상태를 분리하고, 제한된 기회 안에서 여러 시험에 공통으로 영향을 주는 정보를 확인한다.

**Methods:** 공개 임상시험 15건에서 선별·구조화한 객관적 조건 80개와 사전 고정 합성 평가 환자 20명을 사용하였다. 환자마다 서로 다른 두 가림 구성을 적용하고 사례마다 시험 5건을 연결하여 40개 사례와 200개 반복 관측을 만들었다. 확인 0~3회에서 여섯 정보 선택 정책을 비교하였다. 별도로 9종 1,800개 연결 구조와 합성 환자 20명의 80개 짝지은 경로 제약 설정을 평가하였다.

**Results:** 처음 미정인 120건은 전체 정보 기준 적격 30건과 부적격 90건이었다. 영향 우선 기본 규칙은 확인 1·2·3회에 적격 0·3·13/30건을 복원하고 부적격 39·57·75/90건을 정리하여 상태 일치율 59.5%, 70.0%, 84.0%를 보였다. 확인 3회에서는 가능한 순서 평균보다 5.73%p 높았으나 0~3회 곡선 차이의 환자 단위 95% 범위는 0을 포함했다. 개발분포 기반 기대값 계획기는 확인 3회 86.0%였지만 기본 규칙과의 차이 범위도 0을 포함했다. 완전 공유 구조에서 기본 규칙은 단계별 무작위보다 43.28%p 높았고, 사슬형에서는 조합 포괄 탐색이 3.22~4.27%p 높았다. 환자 제약 후 새 검사와 추가 방문 제안은 각각 21→0회, 56→0회로 줄었고 설정당 미정 시험은 0.88건에서 1.24건으로 늘었다.

**Conclusion:** 직접 공유가 큰 정보에는 단순 규칙이, 연쇄 구조에는 더 깊은 탐색이 유리했다. 환자 제약은 실행 불가능한 제안을 없애는 대신 미정 상태를 늘렸다. 결과는 합성 전체 정보 상태의 복원과 프로그램 상태 전이이며 실제 환자의 적격 판정 정확도나 임상 성과를 뜻하지 않는다.

## Backgrounds

임상시험 사전선별에서는 판정에 필요한 환자 정보가 빠져 있거나 요구 시점과 맞지 않을 수 있다. 미확인 값을 불충족으로 간주하면 참가 가능성이 남은 후보가 조기에 제외되고, 부족한 근거만으로 충족을 확정하면 아직 확인이 끝나지 않은 시험이 적격처럼 제시된다. 선행연구는 부분 정보에서 미정 상태를 보존하는 논리[1], 환자 답에 따라 시험을 줄이는 동적 문진[2], 추가 검사의 비용을 고려한 순서 결정[3], 대규모 검색과 조건별 판정[4], 모호한 사례에 대한 추가 질의와 재분류[5], 시험 참여 부담에 따른 선호 차이[6]를 각각 다루었다.

본 연구는 이 요소들을 하나의 추적 가능한 흐름으로 통합하였다. 시스템은 참가 가능성이 남아 계속 검토할 후보인지와 현재 근거만으로 확인이 끝났는지를 분리한다. 이어 제한된 확인 횟수 안에서 여러 시험의 판정을 함께 바꿀 정보를 고르고, 환자에게 허용된 방법으로 근거를 얻은 뒤 그 정보와 연결된 조건만 다시 판단한다. 본 연구는 이 흐름이 합성 전체 정보 상태를 적격과 부적격 양방향에서 얼마나 복원하는지, 선택 정책의 차이가 어떤 정보 연결 구조에서 생기는지, 환자 제약을 지킬 때 미정 상태가 얼마나 늘어나는지를 평가하였다.

## Methods

ClarifyTrial은 조건별 초기 판단에서 후보 유지 여부와 현재 확인 상태를 따로 저장한다. 미정 시험이 남으면 영향 우선 기본 규칙이 현재 미정 시험 수, 연결 조건 수, 확인 부담의 순서로 다음 정보를 고른다. 이어 환자에게 허용된 확인 경로를 선택한다. 새 답과 출처를 저장한 뒤 해당 정보에 연결된 조건만 갱신하며, 모든 후보가 정리되거나 확인 한도 또는 이용 가능한 경로가 소진되면 종료한다(그림 1). 수치·날짜·명시적 논리와 상태 전이는 코드가 처리하고, 일반 실행에서 언어모델은 자유문장 구조화·조건 해석·질문 작성에 제한하였다. 본 평가에서는 미리 구조화한 객관적 조건과 코드 상태 전이만 사용하여 모델을 호출하지 않았다.

주 평가에는 3개 질환의 공개 임상시험 15건에서 선별·구조화한 객관적 조건 80개를 사용하였다. 자료 제작·조정에 사용한 합성 환자 10명과 구분하여 합성 평가 환자 20명을 사전에 고정하였다. 각 환자에게 두 가지 정보 가림 구성을 반복 적용하고, 각 구성에서 정보 5개를 가린 뒤 시험 5건을 연결하였다. 따라서 분석 자료는 가림 사례 40개와 환자-시험 반복 관측 200개였으며, 통계 단위는 합성 환자 20명이었다. 전체 정보를 넣었을 때의 후보 유지 여부와 확인 상태를 기준 상태로 삼았고, 두 축이 모두 같을 때 시험 상태 일치로 셌다.

확인 한도 0~3회에서 가림 정보의 가능한 120개 순서 전체 평균, 영향 우선 기본 규칙, 가장 넓은 영향 우선, 부담 대비 영향, 남은 부족 정보의 조합을 세는 조합 포괄 탐색(exact coverage), 개발자료의 답 분포를 이용하는 기대값 계획기(expected decision-tree planner)를 비교하였다. 어느 정책도 가린 평가 답을 선택에 사용하지 않았으며, 확인 3회 설정과 0~3회 정규화 사다리꼴 곡선 면적을 함께 보고하였다.

원리 검증에서는 완전 공유, 완전 분리, 사슬형 등을 포함한 9개 연결 모양을 각각 200개씩 생성하였다. 같은 1,800개 구조에 확인 1·2·3회를 반복 적용하여 한 단계의 직접 영향에 반응하는 규칙과 남은 정보 조합을 더 깊게 계산하는 방법의 차이를 살폈다. 환자 제약 평가에서는 별도 합성 환자 20명의 80개 짝지은 설정에 모든 확인 경로를 허용한 조건과 새 검사·추가 방문을 제거한 조건을 적용하였다. 질환 구성을 유지한 환자 단위 부트스트랩 5,000회로 95% 범위를 계산하였다. 이 범위는 합성 환자 구성의 재표집 민감도이며 실제 환자 모집단의 추정구간이 아니다.

마지막으로 공개 시험 50건과 조건 202개로 만든 합성 환자 50명 중 20명은 자료 제작·조정에 사용하고, 사전 고정한 30명의 환자-시험 150조합은 여러 질환과 시험에서의 작동 범위만 확인하는 평가로 두었다.

## Results

### 주 평가: 확인에 따른 상태 복원

200개 반복 관측 중 80건은 확인 전부터 전체 정보 기준 상태와 일치했다. 처음 미정인 120건은 전체 정보 기준 적격 30건과 부적격 90건이었다. 영향 우선 기본 규칙은 확인 1·2·3회에 적격 0·3·13/30건을 복원하고 부적격 39·57·75/90건을 정리하였으며, 전체 상태 일치율은 59.5%, 70.0%, 84.0%였다. 확인 3회에서 기본 규칙은 가능한 순서 평균 78.27%보다 5.73%p 높았고, 차이의 환자 단위 95% 범위는 +3.04~+8.55%p였다. 반면 0~3회 곡선 면적에서 기본 규칙과 가능한 순서 평균의 차이는 +2.72%p였고 95% 범위는 -1.03~+6.76%p였다. 따라서 3회 설정의 차이를 모든 확인 한도의 일반적 우위로 해석하지 않았다.

전체 정책을 함께 비교하면 확인 1회에는 가장 넓은 영향 우선이 62.0%, 확인 2·3회에는 개발분포 기반 기대값 계획기가 75.0%와 86.0%로 가장 높았다(표 1). 기대값 계획기와 기본 규칙의 확인 3회 차이는 +2.00%p였으나 환자 단위 95% 범위는 -2.00~+6.50%p였다. 0~3회 곡선 면적의 점추정치는 기대값 계획기 65.67%, 가장 넓은 영향 우선 65.25%, 기본 규칙 63.83%, 조합 포괄 탐색 61.75%, 가능한 순서 평균 61.11%였다. 기대값 계획기는 가장 높은 곡선 면적 점추정치를 보였지만 개발자료의 답 분포를 필요로 하며 확인 1회 최고 정책도 아니었다. 정책의 우위는 예산과 가정에 따라 달라졌다.

### 원리 검증: 정보 연결 구조

확인 1회에서 영향 우선 기본 규칙과 단계별 무작위의 차이는 완전 공유 +43.28%p, 완전 분리 0.00%p, 사슬형 -0.75%p였다. 같은 정보가 여러 미정 시험을 곧바로 정리할 때 영향 우선 규칙의 이점이 컸고, 정보가 분리되면 순서 효과가 사라졌다. 확인 2~3회에는 조합 포괄 탐색이 기본 규칙보다 전체 구조 평균 +1.19~+2.00%p, 사슬형 +3.22~+4.27%p 높았다. 여러 단계 뒤의 도달 가능성을 계산하는 방법은 연쇄 의존성이 있는 구조에서 더 유리했으나 전체 평균 차이는 2.00%p 이내였다. 이는 단순 규칙의 보편적 우위보다 연결 구조에 따른 정책 선택을 뒷받침한다.

### 부차 평가: 환자 제약의 대가

새 검사와 추가 방문을 허용하지 않는 조건을 경로 선택 전에 적용하자 해당 제안은 각각 21회에서 0회, 56회에서 0회로 줄었다. 새 검사와 추가 방문은 한 행동에 함께 포함될 수 있어 두 횟수를 합산하지 않았다. 동시에 설정당 미정 시험은 0.88건에서 1.24건으로 0.36건 늘었고, 환자 단위 95% 범위는 +0.21~+0.53건이었다. 시험 5건을 모두 정리한 설정도 42/80개에서 32/80개로 줄었다. 이는 환자에게 실행 가능한 경로를 지키면서 발생한 미정 상태의 증가이며, 실험에 사용한 부담값과 대기시간은 실제 의료 환경의 추정값이 아니다.

### 범위 평가

전체 정보 기준 상태 일치는 확인 0~5회에 128→142→147→149→150→150/150이었다. 다만 처음 미정인 22건이 모두 전체 정보 기준 적격이어서 부적격 정리 성능을 측정하지 못했다. 이 결과는 공개 시험 50건에서 프로그램 흐름이 작동한 범위를 보여 줄 뿐, 주 평가의 양방향 결과를 대체하지 않는다.

## Conclusion

ClarifyTrial은 후보 유지 여부와 현재 확인 상태를 분리한 채 제한된 횟수 안에서 공유 영향이 큰 정보를 선택하고, 환자에게 허용된 경로로 근거를 보완한 뒤 관련 조건만 갱신한다. 공개 원문 조건과 합성 환자를 사용한 평가에서는 적격 복원과 부적격 정리가 모두 나타났고, 직접 공유가 큰 구조에서는 단순 영향 우선 규칙이, 사슬형 구조에서는 더 깊은 조합 탐색이 유리했다. 환자 제약을 적용하면 실행 불가능한 제안은 제거되지만 미정 시험이 늘었다. 정책별 우위가 확인 예산, 연결 구조, 답 분포 가정에 따라 달라져 한 정책의 보편적 우위는 확인되지 않았다. 모든 결과는 공개 시험 원문의 일부 객관적 조건과 합성 환자에서 전체 정보 상태를 복원한 프로그램 평가이며, 실제 환자의 적격 판정 정확도, 모집 성과, 비용·시간 절감 또는 임상 안전성을 뜻하지 않는다.

## 표 1. 주 평가에서 정보 선택 정책별 시험 상태 일치율

| 정보 선택 정책 | 확인 1회 | 확인 2회 | 확인 3회 |
|---|---:|---:|---:|
| 가능한 순서 전체 평균 | 56.24% | 67.96% | 78.27% |
| 영향 우선 기본 규칙 | 59.50% | 70.00% | 84.00% |
| 가장 넓은 영향 우선 | 62.00% | 72.00% | 83.50% |
| 부담 대비 영향 | 58.50% | 71.00% | 83.50% |
| 조합 포괄 탐색(exact coverage) | 58.00% | 66.00% | 82.50% |
| 개발분포 기반 기대값 계획기 | 59.00% | 75.00% | 86.00% |

**주:** 확인 0회 상태 일치율은 모든 정책에서 40.0%였다. 가능한 순서 평균은 각 가림 사례의 120개 정보 순서를 모두 실행한 값으로 무작위 표본오차가 없다. 조합 포괄 탐색은 남은 부족 정보의 조합 범위를 계산하고, 기대값 계획기는 자료 제작·조정 환자에서 얻은 답 분포로 미래 상태의 기대값을 계산하므로 서로 다른 정책이다. 통계 단위는 사전 고정 합성 평가 환자 20명이며, 환자별 두 가림 구성과 시험 5건은 반복 관측이다.

## 2쪽 조판 시 우선 덜어낼 항목

1. **범위 평가의 전체 수열**: `128→142→147→149→150→150/150`을 지우고 “공개 시험 50건에서는 작동 범위만 확인했으며 초기 미정 사례가 적격 방향으로 치우쳤다”로 압축한다.
2. **곡선 면적의 정책별 전체 수치**: 기대값 계획기부터 가능한 순서 평균까지의 AUC 나열을 지운다. 표 1과 기본 규칙의 0~3회 차이만으로 선택 편향 방어가 가능하다.
3. **기대값 계획기의 반복 해석**: “가장 높은 곡선 면적 점추정치를 보였지만…” 문장은 앞의 확인 3회 비교와 겹치므로 먼저 덜어낸다.
4. **환자 제약의 두 번째 결과**: `42/80→32/80`을 지우고 주 대가 지표인 설정당 미정 시험 `+0.36건`만 남긴다.
5. **그림의 경로 예시 행**: 본문과 도식의 ‘허용 경로 선택’만으로 뜻이 전달되면 경로 예시 다섯 항목을 제거한다.

## 현재 자료만으로 방어 가능한 핵심 주장

공개 임상시험 원문의 일부 객관적 조건과 합성 환자에서 ClarifyTrial은 후보 유지 여부와 현재 확인 상태를 분리한 채 제한된 확인으로 전체 정보 기준 적격·부적격 상태 전이를 만들었으며, 정보 선택 정책의 이점은 연결 구조에 따라 달라지고 환자 제약 적용은 미정 시험 증가를 동반했다.
