## 발표에서 전달할 핵심

**불확실한 자료를 모두 두 번 확인하는 대신, 판정에 필요한 부분만 재확인하면 같은
위험 교정 목표 아래 올바른 판정을 늘리고 방문을 줄일 수 있다.**

이 방법은 다음 세 판단을 연결한다. 실제 관측한 자료가 조건의 논리 증거인지 확인하고,
그 결론의 오류 점수가 충분히 낮은지 계산한다. 부족하면 이미 본 자료를 재확인할지
다른 자료를 얻을지 남은 예산에서 고른다. 확률이 높다는 이유로 없는 검사값을 채워
판정을 확정하지 않는다. 기본 임상 판정기를 대체하는 API도 아니다.

현재 향상은 공개 시험의 선택 수치 부분조건·유한 격자·합성 환자라는 범위에 있다.
전체 임상시험의 참가 자격이나 실제 환자 편익까지 확인한 결과가 아니다.

## 30초 설명 초안

“환자 기록이 빠지거나 틀렸을 때 무엇을 더 알아보고 다시 확인할지 고르는 연구입니다.
새 방법은 모든 자료를 두 번 확인하지 않고, 현재 결론의 오류 가능성을 보고 필요한
부분만 재확인합니다. 같은 모형과 위험 목표로 비교했을 때 판정 일치는 76.31%에서
79.42%로 높아졌고 방문은 17.3% 줄었습니다. 다만 합성 환자의 수치 일부를 평가한
결과이며, 오판 감소나 실제 임상 효과를 입증한 것은 아닙니다.”

실제 낭독 시간을 측정한 대본은 아니다. 공식 배정시간과 실제 발화에 맞춰 조정한다.

## 3분 설명 초안과 포스터 동선

아래 시간은 설명 배분 목표이며 현장 리허설 측정값이 아니다. 처음에는 숫자보다
문제와 행동의 차이를 설명하고, 비교 조건을 말한 다음 결과를 가리킨다.

| 목표 구간 | 가리킬 곳 | 전달할 내용 |
|---|---|---|
| 0:00–0:25 | 왼쪽 위 문제 | 첫 기록을 믿는 위험과 모든 자료를 재확인하는 부담 |
| 0:25–1:15 | 왼쪽 방법 | 관측 증거·오류 점수·다음 자료와 재확인의 공동 선택 |
| 1:15–1:45 | 왼쪽 아래 교정 | 방법을 먼저 고정, 별도 합성 교정과 평가, 같은 비교 조건 |
| 1:45–2:25 | 오른쪽 두 그래프·표 | +3.10%포인트와 방문 17.3% 감소, 네 비교군 |
| 2:25–3:00 | 아래 한계 | 오판·총 행동 증가, 분포 변화 실패와 임상 적용 경계 |

“임상시험 사전선별에서는 환자의 검사값이나 기록이 부족할 수 있습니다. 그런데 처음
찾은 기록의 내용이 틀릴 수도 있습니다. 첫 기록을 바로 믿으면 오판할 수 있고,
모든 자료를 두 번 확인하면 다른 후보를 살펴볼 기회를 잃습니다.

저희는 무엇을 더 알아볼지와 무엇을 다시 확인할지를 함께 고르는 방법을 만들었습니다.
먼저 실제 관측한 자료가 해당 조건의 논리 근거인지 봅니다. 근거가 있더라도 결론의
오류 점수가 높으면 보류합니다. 그 상태에서 이미 본 자료를 재확인할지 다른 정보를
얻을지, 남은 확인 횟수와 방문 한도 안에서 두 단계 앞을 계산해 선택합니다.

예를 들어 혈색소가 낮다는 첫 기록이 네 시험의 수치 조건을 위반하는 것처럼 보여도
바로 네 개를 모두 제외하지 않습니다. 첫 보고의 오류 가능성이 높은 결론은 보류하고,
추가 보고를 얻은 뒤 다시 계산합니다. 이 예는 시연의 합성 실행 기록에서 볼 수 있습니다.

모형이 계산한 확신 점수가 실제 오류율은 아닙니다. 그래서 질문과 종료 규칙을 먼저
고정하고 별도 합성 환자 1,200명으로 정책 전체를 교정했습니다. 이후 다른 1,200명에서
평가했습니다. 비교군의 확률모형과 판정기, 확인 최대 세 번·방문 최대 한 번을 같게 했습니다.

오른쪽 결과를 보시면 한 단계 선택은 76.31%, 새 방법은 79.42%의 부분조건 상태를
맞혔습니다. 차이는 3.10%포인트이며 환자 단위 재표집 구간은 2.29에서 3.90입니다.
방문은 1,136회에서 939회로 17.3% 줄었습니다. 정보량과 Bayes 오류를 줄이는
비교군보다도 올바른 상태를 더 많이 정리했습니다.

다만 오판이 있었던 환자는 23명에서 26명, 전체 행동은 2,957회에서 3,022회로
늘었습니다. 실제 오류율이 같거나 모든 비용이 감소했다고 말할 수는 없습니다.
분포와 오류율이 달라지면 교정 목표도 넘었습니다. 따라서 현재 기여는 관측 근거를
요구하는 선택적 재확인의 방법과 합성 실증이며, 실제 임상 효과는 추가 검증이 필요합니다.”

## 시연 진행 — 60~90초 설명 목표

`clarifytrial-risk-replay.html`을 브라우저로 열고 `다음 행동`을 누른다. 이 화면은 실제
Python 알고리즘의 저장 결과를 재생하며 브라우저에서 새 환자를 추론하는 데모가 아니다.
각 행동은 고정 평가 기록·잠재 반환·현재 코드와 대조했다. 합성 참값은 `정답과 한계 보기`에
분리했고 정책에 제공하지 않았다. 공개 원문은 파일 안에 포함돼 있다. 외부 원문 링크를
열 때만 인터넷이 필요하다.

| 사례 | 실제 기록 | 설명할 포인트 |
|---|---|---|
| 방문 없이 같은 판정을 끝낸 사례 | `test:56002:1` | 한 단계는 1방문, 새 방법은 0방문으로 두 방법 모두 4개 상태 일치. 방문 실패도 예산을 소비한다. |
| 재확인으로 보류를 줄인 사례 | `test:56002:5` | 혈색소 7g/dL의 첫 보고 뒤 1개만 판정. 추가 보고 뒤 네 부분조건을 정리한다. |
| 두 보고가 같아도 오판한 사례 | `test:56002:19` | 혈소판 참값은 250×10⁹/L인데 두 보고는 모두 70이다. 자료 일치만으로 참값을 보장하지 않는다. |

사례는 집계 평가가 끝난 뒤 조건을 만족하는 가장 이른 에피소드를 골랐다. 선택한 성공
사례의 4/4를 전체 성능처럼 말하지 않는다. 세 사례 모두 교육용이며 빈도 추정 표본이 아니다.

발표가 짧으면 첫 사례의 다음 행동 두세 번만 보여 준다. 질문이 들어오면 재확인 사례로
기전을 설명하고 실패 사례에서 한계를 답한다. 현장 브라우저가 막히면 PDF의 왼쪽 방법과
오른쪽 결과만으로 같은 설명을 이어간다. 실제 환자나 외부 API를 즉석에서 실행하지 않는다.

## 결과를 말할 때 사용할 정확한 분모

| 항목 | 한 단계 | 선택적 재확인 |
|---|---:|---:|
| 올바른 부분조건 상태 /4,800 | 3,663 (76.31%) | 3,812 (79.42%) |
| 실제 방문 /1,200환자 | 1,136 | 939 |
| 전체 확인 시도 | 2,957 | 3,022 |
| 새 결론 환자 중 오판 환자 | 23 /1,046 | 26 /1,064 |
| 첫 후보 기회 690개 중 확인 | 466 | 516 |

4,800은 독립 환자가 아니라 1,200합성 환자×네 시험이다. 초기부터 올바른 1,694개를
공통 포함하며 새로 맞힌 상태는 1,969→2,118개다. 같은 교정 목표는 실제 오류율의
동등성을 뜻하지 않는다. +3.10은 상대 3.10% 증가가 아니라 퍼센트포인트 차이다.
방문 17.3% 감소는 `(1136−939)/1136`이며 전체 행동이나 실제 의료비의 감소율이 아니다.

## 예상 질문과 답변

**1. 기존 연구와 무엇이 다릅니까?**
관측 자료가 결론의 논리 증거인지 요구하고, 오류 점수에 따라 어느 자료를 재확인할지와
다른 정보를 얻을지를 함께 선택했다. 질문·정지를 포함한 정책 전체를 별도 교정했다.
동일 모형의 한 단계·정보량·Bayes 오류 비교에서 판정과 방문의 향상을 확인했다.

**2. 완전히 새로운 알고리즘입니까?**
EC²·DRD의 결정 중심 획득, EDDI의 목표 정보량, 선택적 예측과 LTT의 교정은 알려진
원리다. 기여는 명시한 사전선별 부분조건 문제의 방법과 합성 실증이다. 새 일반 이론이나
최초성을 입증했다고 말하지 않는다. [원문별 차용·가정·차이](RESEARCH_KNOWLEDGE_BASE.md)를 따른다.

**3. 예전 포스터는 84%였는데 새 79.42%가 더 낮지 않습니까?**
다른 시험·환자·오류와 자료 획득 환경이므로 직접 비교할 수 없다. 선정 원고의 84%는
기존 15시험·20평가 환자의 결과다. 새 연구의 향상은 같은 새 자료와 모형에서 비교한
76.31%와 79.42%의 차이다. 두 실험을 합쳐 하나의 개선율로 만들지 않는다.

**4. 오판이 늘었는데 왜 좋아졌다고 합니까?**
향상은 같은 교정 위험 목표에서 올바른 상태와 방문에 있다. 오판은 감소하지 않았다.
새 결론을 낸 환자 수와 오판 환자 수가 함께 바뀌었고 실제 오류 동등성을 검정한 결과도
아니다. 한쪽이 모든 지표에서 우월한 결과로 제시하지 않는다.

**5. 5% 위험 목표와 점수 기준 3%는 무엇이 다릅니까?**
3%는 선언한 확률모형 아래 한 부분조건 결론의 사후 점수 기준이다. 5%는 별도 교정에서
새 결론을 낸 환자 중 하나라도 잘못된 결론이 있을 위험의 목표다. 여러 결론의 위험을
한 결론 점수와 같게 보지 않는다. 선택 정책 전체를 정확 이항 검정·다중 검정으로 교정했다.

**6. 같은 환자의 네 시험을 독립 표본으로 셌습니까?**
아니다. 위험 교정은 환자당 하나라도 잘못된 새 결론이 있는지를 한 번 센다. 판정 일치의
분모만 네 시험×1,200명이며 불확실성은 환자 단위로 짝지어 재표집했다.

**7. 실제 환자를 몇 명 검증했습니까?**
새 연구의 실제 환자는 0명이다. ClinicalTrials.gov의 실제 공개 시험 문구에서 수치 일부를
골랐고 환자 값·자료원·오류·반환 실패는 모두 합성이다. 실제 임상 정확도라고 말하지 않는다.

**8. 언어모델은 어디에 쓰였습니까?**
프로젝트의 원문 준비·조건 해석·질문 작성에서 사용한다. 이번 핵심 획득·교정 비교의
실행기는 새 LLM 호출 없이 구조화한 부분조건을 계산했다. 이번 향상을 LLM 자체의
임상 추론 성능 향상으로 설명하지 않는다. 자동 원문 해석의 외부 문구 우위도 재현되지 않았다.

**9. EDDI나 최신 학습 기반 AFA보다 좋습니까?**
전체 신경망을 학습·재현하지 않았다. 이번 정보량 비교는 같은 유한 모형에서 계산한
시험별 주변 엔트로피 감소다. 최근 L2M 등의 전체 방법보다 우수하다는 결과가 아니다.

**10. 두 보고가 같은데 왜 틀릴 수 있습니까?**
같은 잘못된 원천을 공유할 수 있다. 실패 사례의 혈소판 두 보고가 그런 경우다. 자료원
공유 모형을 복잡하게 만든 변형은 이번 자료에서 추가 이점이 없어 핵심 기여로 삼지 않았다.
실제 자료원의 독립성과 같은 측정 범위는 별도 확인이 필요하다.

**11. 어디까지 위험을 보장합니까?**
고정 정책과 교정·배포가 같은 독립 동일분포 혼합이라는 조건 안의 선택적 환자 오류
목표다. 각 질환·병원·자료원별 보장이나 분포 변화 보장은 아니다. 오류와 값 분포가
바뀐 별도 스트레스에서는 목표를 넘었다. 임상 안전성 보장으로 쓰지 않는다.

**12. 방문이 줄었으면 비용도 줄었다고 할 수 있습니까?**
현재 결과는 설정한 모형 안의 방문 횟수다. 전체 시도는 늘었다. 실제 비용·시간·검사
부담을 측정하거나 기관에서 추정한 결과가 아니므로 모든 비용의 감소를 주장하지 않는다.
자료 반환 .70/.95와 내용 오류 .05도 통제 실험의 설정이다.

**13. 수치 조건을 만족하면 임상시험에 참가할 수 있습니까?**
아니다. 진단·병기·치료력·검사 방법·시점·수혈 등 다른 문맥이 남아 있다. 출력은 수치
부분조건의 지지·위반·보류이며 전체 적격·등록 승인과 다르다. 원문 자체가 모호하면
환자에게 같은 검사를 반복시키는 대신 원문 또는 시험 담당자 확인 질문을 남긴다.

**14. 왜 시연 사례에서 성능이 더 좋아 보입니까?**
원리 설명에 필요한 조건으로 고른 사례다. 전체 성능은 별도 1,200명 집계이고 시연
사례의 성공률로 대체하지 않는다. 실패 사례도 함께 제공했다.

**15. 지금 남은 일은 무엇입니까?**
계산 방법과 합성 비교, 포스터·오프라인 설명 자료는 준비했다. 공식 규격·발표시간·추가
결과 반영 안내와 실제 발화 리허설, 임상 의미·실제 자료 품질과 임상가 검증은 남아 있다.
아직 수행하지 않은 검토를 완료했다고 말하지 않는다.

- 같은 정보를 얻는 방법은 환자 상황에 맞춰 골랐다. 새 검사와 방문을 원하지 않는 경우에는 해당 방법을 뺐고, 그만큼 확인을 기다리는 시험이 더 남았다.

## 예상 질문과 짧은 답

### 14건 확정은 실제 환자에서 살릴 비율입니까?

> 공개 시험의 일부 조건과 합성 환자에서 질문부터 다시 판단하기까지 이어지는지를 확인한 값입니다. 남은 22건은 숨긴 답이 들어오면 참가 가능 확인을 마치도록 만든 사례였습니다. 실제 환자의 모집 성공률로 일반화하지 않습니다.

### 왜 질문 뒤 14건이 모두 참가 가능 확정이고 제외는 0건입니까?

> 처음 자료로 28건이 정리됐고, 세 기본 문진으로 제외 68건과 참가 가능 확인 완료 32건이 더 정리됐습니다. 남은 22건은 합성 환자의 전체 정보 기준으로 참가 가능 확인을 마치도록 구성했습니다. 질문 뒤 제외가 0건인 것은 이 자료 구성에서 예상되는 결과이며 별도 성과로 세지 않습니다.

### 환자는 30명인데 왜 질문이 14회뿐입니까?

> 확인이 필요한 환자에게만 질문했습니다. 14명이 질문을 받았고 각자 한 번씩 답했습니다. 나머지 환자는 시작 자료로 현재 상태를 정리할 수 있었습니다.

### 36.5%포인트가 0.44%포인트로 줄었다면 질문 순서 규칙이 필요 없지 않습니까?

> 기본 문진 정보가 갖춰진 공개 평가에서는 순서 차이가 거의 없었습니다. 그래서 현재 규칙의 성능 우위를 주장하지 않습니다. 남은 22건 실험은 질문 선택, 답 연결과 다시 판단하는 과정이 이어지는지 확인했습니다. 구조 실험에서는 여러 시험이 같은 한 정보를 기다릴 때만 순서 차이가 커졌습니다.

### 36.5%포인트를 왜 보여 줍니까?

> 초기 결과가 처음 제공한 정보에 따라 크게 달라졌다는 점을 보여 주기 위해서입니다. 질문 방법의 성능 주장에는 쓰지 않습니다.

### 공유 조건 64.4%면 질문 순서의 효과가 항상 큰 것 아닙니까?

> 130개 가운데 126개가 세 기본 정보에 몰려 있었습니다. 확인을 두세 번 허용한 연결 구조 실험에서 직접 공유는 현재 규칙이 단계별 무작위보다 높았지만, 완전 분리에서는 세 방법이 같았습니다. 사슬에서는 조합 탐색이 현재 규칙보다 높았습니다.

### 사슬형 구조에서 조합 탐색이 더 높았던 이유는 무엇입니까?

> 현재 연결 수만 보는 규칙은 앞으로 몇 번 더 확인할 수 있는지까지 내다보지 못합니다. 확인을 두세 번 허용하고 함께 볼 정보 조합을 계산하자 사슬형 구조에서는 현재 규칙보다 3.2~4.3%포인트 높았습니다. 현재 규칙을 모든 구조에서 우수하다고 말하지 않고, 사슬형 연결은 정보 조합을 계산하는 방법과 함께 비교합니다.

### 앞으로 확인할 정보 조합을 계산하는 방법을 왜 기본값으로 쓰지 않습니까?

> 세 기본 문진을 제공한 합성 자료에서는 질문 순서 차이가 0.44%포인트였습니다. 구조 실험에서도 전체 평균 차이는 1.2~2.0%포인트였고, 현재 규칙은 확인 방법의 부담까지 함께 봅니다. 사슬형 연결에서는 앞으로 확인할 정보 조합을 계산한 방법이 나았으므로 비교 대상으로 남겨 뒀습니다. 어느 연결 방식에서 자동으로 바꿀지는 다음 평가에서 정해야 합니다.

### 85/85 결과가 너무 완벽한 것 아닙니까?

> 같은 답을 주는 두 확인 방법에 합성 시간과 부담만 다르게 붙인 통제 실험입니다. 선택 규칙이 입력에 맞게 움직이는지 본 기능 점검이며 실제 효용 비교가 아닙니다.

### 21회와 56회를 더해 77개 행동을 없앴다고 말할 수 있습니까?

> 한 행동에 새 검사와 추가 방문이 함께 붙을 수 있어 더할 수 없습니다. 두 부담 항목을 각각 0회로 줄였다고만 말합니다.

### 제한 뒤 내부 상태 일치가 높아진 이유는 무엇입니까?

> 환자가 허용한 정보와 확인 방법으로 도달 가능하도록 내부 목표를 정했기 때문입니다. 환자 설정을 적용한 규칙이 그 목표를 지키는지 보는 소프트웨어 점검이며 임상 정확도를 나타내지 않습니다. 해석은 내부 규칙 점검에 한정합니다.

### 제한을 지키면 환자 부담이 실제로 줄었다고 볼 수 있습니까?

> 실제 환자 편익을 측정하지 않았습니다. 합성한 제한을 프로그램이 지켰고, 그 대가로 확인 대기 시험과 끝까지 정리되지 않은 설정이 늘었다는 결과입니다.

### DQueST, MediQ, TrialTriage와 무엇이 다릅니까?

> 여러 시험에 공통인 질문을 고르고, 현재 정보가 충분한지 확인하며, 답변 뒤 다시 판단하는 방법은 선행연구에 있습니다. ClarifyTrial은 정보가 부족한 시험을 후보로 관리하고, 환자가 이용할 수 있는 방법으로 답을 얻어 관련 조건만 다시 계산합니다. 이번 평가에서는 처음 주어진 정보와 시험 사이의 연결 모양에 따라 결과가 어떻게 달라지는지도 함께 살폈습니다.

### TrialGPT보다 성능이 좋다는 뜻입니까?

> 그런 결론을 내리지 않습니다. TrialGPT 공개 조건 자료는 질문 전 조건 판단을 평가합니다. 현재 발표는 정보가 부족한 뒤의 질문 선택, 확인 방법 선택과 상태 변화를 다룹니다.

### 호출·토큰·응답시간 감소를 일반적인 성능 개선으로 볼 수 있습니까?

> 합성 환자 한 사례의 변경 전후 기록입니다. 변경 전 코드가 모델 판정 한 건을 교정한 사실도 영구적인 안전성 성과로 세지 않습니다. 이 추적에서 불필요한 조건 판단 호출을 찾아 제거했고, 변경 후에도 최종 상태와 질문 정보 순서가 같았습니다. 호출, 토큰과 응답시간 합의 감소율은 평균값으로 사용하지 않습니다.

### 확인 횟수가 늘면 연결 구조의 효과도 유지됩니까?

> 확인을 두 번과 세 번 허용했을 때 모든 시험이 한 정보를 공유한 구조의 현재 규칙과 단계별 무작위 차이는 두 답 분포에서 19.03~30.09%포인트였습니다. 시험마다 필요한 정보가 분리된 구조에서는 세 방법이 같았습니다. 조합 탐색은 현재 규칙보다 전체 구조 평균 1.2~2.0%포인트, 사슬형 구조에서 3.2~4.3%포인트 높았습니다. 확인 1회 결과는 첫 질문만 분리한 보조 분석으로 남겼습니다.

### 실제 환자에게 적용하려면 무엇이 더 필요합니까?

> 완전한 환자 기록, 독립된 임상 전문가 판단, 다양한 시험 원문, 실제 비용과 대기시간, 사람 검토 과정이 필요합니다. 새로운 질환과 병원 환경에서도 같은 경계를 유지하는지 따로 검증해야 합니다.

발표에서 사용할 기여 문장

> ClarifyTrial은 정보가 부족한 시험을 바로 제외하지 않는다. 여러 시험에 함께 필요한 정보를 찾고, 환자가 이용할 수 있는 방법으로 확인한 뒤, 새 근거와 연결된 조건만 다시 계산한다. 이번 합성 평가에서는 이 과정이 끝까지 이어지는지와 어떤 정보 연결 모양에서 질문 순서가 달라지는지를 확인했다.
