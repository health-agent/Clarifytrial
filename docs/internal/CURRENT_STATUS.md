## 확정한 실행 조건

- 주 비교 모델: Claude Sonnet 5, `medium` effort
- 성능 상한 확인: Claude Opus 4.8, 대표 사례
- 저비용 작동 확인: Solar Pro 4
- 주 비교 반복: 사례별 3회
- 외부 확인 행동: 최대 3회
- 고정 에이전트: 진행 관리, 검색·판정, 다음 확인 3개
- 선택적 에이전트: 근거 검토 1개, 사례당 최대 1회
- 모델 호출: 후보·조건 묶음 수에 따라 계산하고 에이전트별 실제 횟수를 기록
- 모든 구조에 같은 검색 결과, 모델과 합성 답변 환경 사용

## 다음 구현

4. 조건 상태, 두 판단과 다음 행동을 채점하는 공통 평가기

7. 세 고정 에이전트와 선택적 검토가 연결된 ClarifyTrial v5 전체 흐름
