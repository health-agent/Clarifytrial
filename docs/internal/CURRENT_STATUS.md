# ClarifyTrial 현재 상태

마지막 갱신: 2026-08-24

## 현재 결론

정해진 JSON 입력 안에서는 관련 시험 검색, 조건 판단, 추가로 확인할 정보 선택, 환자
부담을 고려한 확인 방법 선택, 질문과 답변, 관련 시험 재판정, 중단·재개와 자동 보고서가
한 흐름으로 연결돼 있다.

현재 정밀 평가는 3개 질환, 공개 시험 15건의 참가 조건 92개와 별도 합성 환자 30명을
사용한다. 이 자료는 기능을 세밀하게 검사하기에는 충분하지만 여러 질환에 넓게 적용된다는
근거로는 좁다. 다음 단계는 새 기능 추가보다 자료 범위 확장과 최종 통계 정리다.

## 현재 프로그램이 처리하는 흐름

```text
환자와 시험 자료 입력
→ 관련 시험 검색
→ 시험 조건별 판단
→ 후보 유지 여부와 현재 확인 가능 여부 분리
→ 가장 도움이 되는 다음 정보와 확인 방법 선택
→ 답변 또는 새 자료 반영
→ 관련 시험만 다시 판단
→ 현재 확인된 시험과 추가 확인 후보를 나누어 저장
```

일반 환자·시험 JSON과 팀의 `topics[num, title]` 형식 합성 환자 파일을 모두 받을 수
있다. 답변은 터미널이나 JSON 파일로 입력하며 중단한 실행은 저장된 세션에서 이어간다.
같은 시험 조건은 정리 결과를 저장해 다음 환자에서 재사용한다.

## 현재 사용한 자료

| 용도 | 자료 |
|---|---|
| 관련 시험 검색 | TREC Clinical Trials 2021·2022의 수만 건 시험과 전문가 관련성 정답 |
| 한 번의 조건 판단 | TrialGPT 환자-조건 판단 1,015개 |
| 질문과 재판정 | 공개 시험 15건·조건 92개, 별도 합성 환자 30명·시험 판단 150개 |
| 환자 부담에 맞는 확인 방법 | 별도 합성 환자 20명의 240개 부담 상황 |
| 구조 검사 | 700개 정보 연결 구조와 공개 조건 값 77,792개 조합 |

합성 환자는 환자 상태와 답을 먼저 정한 뒤 일부 정보를 가린다. 질문을 고르는 코드는
가려 둔 답을 읽지 못한다.

## 현재 핵심 결과

### 관련 시험 검색

- TREC 2021: 관련 시험을 상위 500개 안에 남긴 비율 83.59%
- TREC 2022: 관련 시험을 상위 500개 안에 남긴 비율 81.55%
- 두 결과 모두 TrialGPT 공개 수치와 소수점 첫째 자리까지 같았다.

이 결과는 후보 시험을 찾아오는 검색 단계만 설명한다.

### 질문 뒤 판단 완료

별도 합성 환자 30명에게 시험 5개씩 연결한 150개 판단에서 추가 정보를 최대 세 번
확인했다.

| 확인 방법 | 세 번 안에 판단을 끝낸 시험 |
|---|---:|
| 추가 정보를 확인하지 않음 | 63개, 42% |
| 입력 파일에 적힌 순서대로 확인 | 99개, 66% |
| 가장 많은 시험 판단을 끝낼 정보를 매번 계산 | 115개, 77% |

마지막 방법은 입력 순서대로 확인한 방법보다 환자 16명에서 좋았고, 12명에서 같았으며,
2명에서 낮았다.

### 환자 부담을 반영한 확인 방법

이동과 비용 제한이 있는 80개 합성 상황에서 환자가 실제로 이용할 수 있는 방법만
사용해 판단을 끝낸 비율은 81.0%에서 88.5%로 높아졌다. 새 검사나 추가 방문을 피해야
하는 환자에게 그런 방법을 선택한 횟수는 65회에서 0회로 줄었다.

## 다음 작업

### 1. 넓은 검색 자료 연결

- 팀이 공개한 ClinicalTrials.gov 시험 1,931건을 넓은 후보 검색 자료로 사용한다.
- 모집이 끝난 시험은 현재 추천 후보에서 제외한다.
- 자료를 받은 날짜, 수집 방법, 포함 상태와 원문 필드를 기록한다.

### 2. 정밀 평가 범위 확장

- 질환 범위를 현재 3개에서 약 10개로 넓힌다.
- 자세히 채점할 시험을 현재 15건에서 약 50건으로 넓힌다.
- 새 질환 7개에서 합성 환자 약 35명과 두 가지 정보 부족 상태를 추가한다.
- 수치, 기간, 복약, 과거 치료, 임신·피임, 환자 답변, 기록 조회와 새 검사가 고르게
  포함되도록 시험을 고른다.

1,931개 시험 전체에 조건별 정답을 붙이지 않는다. 전체 자료는 검색에 사용하고,
검색된 시험 가운데 정밀 평가 대상으로 고른 약 50건에만 자세한 정답을 만든다.

### 3. 최종 통계 고정

- 현재 질문 방법으로 몇 개 시험 판단을 끝냈는지
- 한 질문이 여러 시험에 얼마나 도움이 됐는지
- 판단을 바꾸지 못한 질문이 몇 개였는지
- 환자에게 불필요한 새 검사나 추가 방문을 얼마나 피했는지
- 실행 시간, 모델 호출, 토큰과 시험 조건 저장본 재사용량

자료와 지시문을 고정한 뒤 같은 평가자료를 전체 프로그램에 실행해 한 보고서로 만든다.

|---|---|---|

| R103 | 넓은 후보 검색 자료와 여러 질환의 정밀 평가자료 확장 | 미완료 |
| R104 | 확장된 자료로 전체 기능 통계와 모델 사용량을 다시 계산 | 미완료 — R103 뒤에 실행 |

## 결과를 해석할 때 지킬 범위

- 검색 수치는 관련 시험을 후보로 가져오는 단계만 설명한다.
- 조건 답 이름의 일치율과 실제 후보 유지·제외 결과를 따로 설명한다.
- 질문과 환자 부담 수치는 공개 시험 조건과 합성 환자 안에서 기능이 어떻게 움직였는지
  보여 준다.
- 과거 합성 데모 수치와 Solar 84%는 현재 결과나 비교 기준으로 사용하지 않는다.

자세한 실행 조건과 각 실험의 채택·기각 이유는
[검증 결과](CLARIFYTRIAL_VALIDATION_RESULTS.md)에 있다.

완료·보류·기각된 요구사항 101개, 모델 설정, 실행 비용과 세부 연결 검사는
[개발 상세 기록](CLARIFYTRIAL_IMPLEMENTATION_RECORD.md)에 보존했다. 프로그램을 수정하거나
과거 결정의 이유를 확인할 때만 읽는다.
