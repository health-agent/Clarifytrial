# ClarifyTrial 현재 상태

마지막 갱신: 2026-08-22

## 완료한 설계

- 연구 질문과 실험 원칙
- 에이전트 전체 워크플로우
- 워크플로우 단계별 근거문헌과 공개 코드 색인
- TrialGPT를 최소 기준으로 한 후보 RAG의 자료, 검색 순서와 후처리 방법
- 공통 입력·출력, 합성 답변 환경과 평가 구분
- 모델 교체 방식과 주 비교의 기본 모델
- 기존 자료·새 검사와 환자별 추가 부담을 구분하는 후속 설계
- 선택 가능한 환자 부담 입력의 기본 규칙과 환자용·연구자용 결과 형식

현행 연구계획은 [CLARIFYTRIAL_RESEARCH_PLAN_V5.md](CLARIFYTRIAL_RESEARCH_PLAN_V5.md)다.
세부 구현은
[에이전트 워크플로우](CLARIFYTRIAL_AGENT_ARCHITECTURE_REDESIGN.md)와
[RAG·평가 구현계획](CLARIFYTRIAL_RAG_EVALUATION_IMPLEMENTATION_PLAN.md)을 따른다.

| R62 | 모델이 요약문을 잘못 다시 써도 환자·시험 근거 문장이 바뀌지 않게 함 | 완료 — 상태표와 조건표의 문장은 코드가 찾은 실제 원문으로 저장 |

첫 합성 시험 한 건의 상태 흐름을 거쳐 공개 시험 15건, 구조화 조건 80개, 합성 환자
30명까지 질문 정책 평가를 확대했다. 구조화된 여러 시험을 한 환자 흐름에서 판단하고,
환자 맞춤 경로를 골라 새 정보를 반영한 뒤 두 추천 목록을 만드는 실행기도 연결했다.
TrialGPT 공개 주석은 Claude 조건 판단과 GPT-5.6 Sol 구조 비교에 연결했고 후보 시험
전체 검색도 TREC에서 실행했다. 후보 검색부터 자연어 조건·환자 구조화까지 포함한
한 명령과 합성 연결 검사까지 구현했다. 외부 LLM을 사용한 자연어 전체 실행과
구조화 정확도 평가는 아직 실행하지 않았다.

## 확정한 실행 조건

- 주 구조 비교 모델: GPT-5.6 Sol, ChatGPT 구독 연결, `medium` effort
- 생각량 민감도 확인: GPT-5.6 Sol `high`, 주 결과가 엇갈린 20~30조건
- 제공자 민감도 확인: Claude Sonnet 5 `medium`, 대표 표본
- 저비용 작동 확인: Solar Pro 4
- 주 비교 반복: 전체 한 번, 개발 20조합과 엇갈린 사례만 반복
- 외부 확인 행동: 최대 3회
- 대화형 작동 확인: 기본 환자 12명, 환자당 후보 5개, 확인 후보 5개, 행동 3회
- 첫 벤치마크: 기본 환자 30명, 개발 10명·고정 평가 20명, 마스크 2개씩
- 질환 범위: 제2형 당뇨병, 유방암, 주요우울장애의 객관적으로 확인 가능한 조건
- 고정 에이전트: 진행 관리, 검색·판정, 다음 확인 3개
- 선택적 에이전트: 근거 검토 1개, 사례당 최대 1회
- 모델 호출: 후보·조건 묶음 수에 따라 계산하고 에이전트별 실제 횟수를 기록
- 모든 구조에 TrialGPT 공개 구조 이상으로 확인된 같은 후보 검색 결과, 모델과
  합성 답변 환경 사용

## 다음 구현

1. 전수 질문 나무와 최악 우선 정책은 비교 코드로만 보존하고 일반 실행기에는 넣지 않는다.
2. 환자 맞춤 규칙은 구조화 공개 조건 실행기의 기본 비교 방식으로 유지하되 합성 부담
   결과를 실제 환자 편익으로 확대하지 않는다.
3. LLM은 임상시험 원문과 환자 기록을 구조화하고 질문 문장을 쓰는 일에만 사용한다.
4. 공개 원문 조건 80개와 합성 환자 기록에서 핵심값 구조화 정확도와 원문 지지율을 먼저 잰다.
5. 외부 모델 소표본으로 후보 검색부터 질문·답변·재판정까지 실행하고 역할별 호출·토큰을 기록한다.
6. 숫자·기간 near-miss는 주 흐름을 바꾸지 않는 보조 결과로 붙인다.

## 아직 열려 있는 결정

- 공개 원문에서 옮긴 80개 조건에 대한 두 번째 연구자 검토 범위
- 비전공자 두 명의 불일치 사례를 제외할지 보류 정답으로 둘지
- 새 검사·침습 절차·치료 변경의 부담 단계와 사람 승인 기준에 대한 의료 전문가 확인
- TrialMatchAI 공식 실행에 사용할 계산 환경

질환 범위, 첫 사례 수, 숨은 사실 수와 행동 한도는 현행 연구계획에서 확정했다.
