마지막 갱신: 2026-08-21

## 완료한 설계

- 연구 질문과 실험 원칙

첫 구현은 고정된 합성 시험 한 건으로 상태 흐름을 검사한다. TrialGPT 공개 주석은
Claude 조건 판단과 GPT-5.6 Sol 구조 비교에 연결했고 후보 시험 전체 검색도
TREC에서 실행했다. 후보 검색부터 최종 추천까지 잇는 실행과 v5 합성 흐름의 외부
LLM 비교는 아직 실행하지 않았다.

## 확정한 실행 조건

- 주 구조 비교 모델: GPT-5.6 Sol, ChatGPT 구독 연결, `medium` effort
- 생각량 민감도 확인: GPT-5.6 Sol `high`, 주 결과가 엇갈린 20~30조건
- 제공자 민감도 확인: Claude Sonnet 5 `medium`, 대표 표본
- 저비용 작동 확인: Solar Pro 4
- 주 비교 반복: 전체 한 번, 개발 20조합과 엇갈린 사례만 반복
- 외부 확인 행동: 최대 3회
- 대화형 작동 확인: 기본 환자 12명, 환자당 후보 5개, 확인 후보 5개, 행동 3회
- 첫 벤치마크: 기본 환자 30명, 개발 10명·고정 평가 20명, 마스크 2개씩
- 질환 범위: 제2형 당뇨병, 유방암, 주요우울장애의 객관적으로 확인 가능한 조건
- 고정 에이전트: 진행 관리, 검색·판정, 다음 확인 3개
- 선택적 에이전트: 근거 검토 1개, 사례당 최대 1회
- 모델 호출: 후보·조건 묶음 수에 따라 계산하고 에이전트별 실제 횟수를 기록
- 모든 구조에 TrialGPT 공개 구조 이상으로 확인된 같은 후보 검색 결과, 모델과
  합성 답변 환경 사용

## 다음 구현

1. 정적 조건 라벨 지시문과 검토 에이전트는 더 조정하지 않는다.
2. 12명 작동 확인에서 드러난 반복 구조를 주 실험 자료에 복제하지 않는다.
3. 30명 자료에는 공통 사실 수, 조건 겹침, 대체 질문, 경로 비용과 통과·위반 답의
   비율을 달리한 최소 네 개 구조를 넣는다.
4. 개발 10명과 고정 평가 20명은 환자 ID뿐 아니라 사례 구조 서식도 겹치지 않게 나눈다.
5. 각 마스크에서 32개 정보 조합을 전수 계산해 최소 충분 사실과 정보별 실제 민감도를 고정한다.
6. 규칙 선택, 영향 범위, 영향 대비 비용, 무작위와 Sol `medium`을 같은 공개 입력으로 비교한다.
7. 성능이 같으면 호출이 없는 규칙을 기본 질문 정책으로 채택하고, Sol은 자연어 질문 생성에만 제한한다.
8. 주 실험을 고정한 뒤 숫자·기간 near-miss를 보조 기능으로 붙인다.

## 아직 열려 있는 결정

- 30명 자료에 사용할 공개 임상시험 조건의 수동 확인 범위
- 비전공자 두 명의 불일치 사례를 제외할지 보류 정답으로 둘지
- TrialMatchAI 공식 실행에 사용할 계산 환경

질환 범위, 첫 사례 수, 숨은 사실 수와 행동 한도는 현행 연구계획에서 확정했다.

## 실험 결과

- 구현 검사: 합성 오래된 검사 사례가 `retain/not_confirmed`에서 공식 확인 뒤
  `retain/confirmed`로 바뀌는 전체 흐름 통과
- 자동 검사: 147개 통과
- 대화형 12명 작동 확인: 규칙·영향 기준·Sol `medium` 전체정보 시험 상태 회복 100%, 무작위 58.3%, 공개 목록 순서 20.0%
- Sol 질문 선택 36회: 입력 450,044·출력 4,555·사고 62·제공자 보고 전체 454,599토큰
- TrialGPT 공개자료 연결: 조건 1,015개, 환자 53명, 환자-시험 105조합과 임상시험
  103개를 재확인. 조건 원문이 비어 있는 1행은 모델 표본에서 제외
- Claude 비용 예비실행: 20개 환자-시험 조합, 조건 211개, 40회 호출 모두 성공.
  입력 69,451토큰, 출력 17,023토큰, 생각 토큰 754개, 재시도 0회,
  2026-08-20 공식 단가 기준 0.309132달러
- 개발 20조합의 조건 라벨 일치: 기존 지시문 65.9%, 원문 재현 방식 72.0%,
  선정·제외 비대칭 방식 반복 82.5%와 80.6%. 선택 재검토는 35회 추가 호출로
  정답 3건 순증에 그쳐 기각
- 미관측 환자 33명·64조합·654조건: 기존 지시문 52.0%, 선정·제외 비대칭 방식
  79.1%, 공개 TrialGPT 고정 출력 88.8%. 비대칭 방식은 기존 방식보다 높지만
  공개 TrialGPT 전체 일치율에는 미치지 못함
