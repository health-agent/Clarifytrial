# ClarifyTrial 현재 상태

기준일: 2026-08-25

## 현재 결론

정해진 JSON 입력 안에서 관련 시험 검색, 조건 판단, 다음 정보 선택, 환자 부담을
고려한 확인 방법 선택, 질문과 답변, 관련 시험 재판정, 중단·재개와 자동 보고서가 한
흐름으로 연결돼 있다.

현재 3개 질환·15개 시험·별도 합성 환자 30명으로 정밀 기능을 평가했다. 팀의 시험
1,931건을 프로그램 형식으로 읽고 모집 상태를 거른 뒤 검색하는 경로와, 10개 질환군에서
정밀 평가 후보 50건을 고르는 절차도 연결했다. 다음 단계는 이 50건의 조건을 정리하고
새 합성 환자를 만들어 검색부터 재판정까지 같은 사례로 평가하는 일이다.

## 완성된 범위

- 환자와 시험의 표준 JSON 입력
- 팀의 `topics[num, title]` 합성 환자 입력 변환
- 관련 시험 검색과 처음 검색 순위 보존
- 조건별 판단과 근거 저장
- 후보 유지 여부와 현재 확인 가능 여부 분리
- 여러 정보가 동시에 부족할 때 확인 순서 계산
- 환자 부담에 맞는 확인 방법 선택
- 직접 답변, JSON 답변, 중단과 재개
- 새 정보와 연결된 시험만 다시 판단
- 현재 확인된 시험과 추가 확인 후보를 나눈 최종 목록
- 여러 환자 일괄 평가와 표·그림·보고서 생성
- 반복되는 시험 조건 정리 결과 재사용
- 팀 시험 1,931건 변환과 모집 중·모집 예정 589건 필터
- 10개 질환군·정밀 평가 후보 50건 선택
- 현재 영향 우선 질문 방식과의 추가 비교
- 선택한 정보를 얻지 못한 뒤 다른 정보로 넘어가는 평가
- 긴 시험 원문과 많은 조건의 분할 호출, 빠진 조건만 재호출
- 중단된 일괄 평가에서 완료 사례 재사용

## 현재 평가자료

| 평가 | 자료 |
|---|---|
| 관련 시험 검색 | TREC Clinical Trials 2021·2022 |
| 한 번의 조건 판단 | TrialGPT 조건 1,015개 |
| 질문과 재판정 | 공개 시험 15건·조건 92개, 별도 합성 환자 30명·시험 판단 150개 |
| 환자 부담 | 별도 합성 환자 20명의 240개 상황 |
| 구조 안정성 | 정보 연결 구조 700개와 공개 조건 값 77,792개 조합 |
| 넓은 시험 목록 | 팀 공개 시험 1,931건 중 모집 중·모집 예정 589건 |
| 다음 정밀 평가 후보 | 10개 질환군·50건 |

## 핵심 결과

| 평가 | 결과 |
|---|---|
| TREC 2021 관련 시험 상위 500개 유지 | 83.59% |
| TREC 2022 관련 시험 상위 500개 유지 | 81.55% |
| 추가 질문 없이 끝난 시험 판단 | 63/150개, 42% |
| 입력 순서대로 세 번 확인한 뒤 끝난 시험 판단 | 99/150개, 66% |
| 현재 가장 많은 미완료 시험에 연결된 정보부터 확인 | 112/150개, 75% |
| 현재 방법으로 세 번 확인한 뒤 끝난 시험 판단 | 115/150개, 77% |
| 환자 제한 안에서 판단을 끝낸 시험 | 81.0% → 88.5% |
| 피해야 할 새 검사·추가 방문 선택 | 65회 → 0회 |

현재 질문 방법은 입력 순서 방식보다 환자 16명에서 좋았고, 12명에서 같았으며,
2명에서 낮았다.

더 강한 현재 영향 우선 방식과 비교하면 현재 방법은 환자 3명에서 좋았고 27명에서
같았으며 낮은 환자는 없었다. 평균 차이는 2퍼센트포인트였고 부호검정 값은 0.25였다.
따라서 남은 확인 횟수 전체를 계산하는 방법의 추가 이득은 현재 자료에서 작다.

환자마다 정해 둔 답 하나를 얻을 수 없게 한 평가에서는 현재 방법의 판단 완료가 77%에서
58%로 낮아졌다. 얻지 못한 정보를 다시 물은 횟수는 0회였으며, 다른 정보로 넘어가는
동작은 정상적으로 작동했다.

## 다음 작업

### R103. 자료 범위 확장 — 미완료

- 완료: 팀 공개 ClinicalTrials.gov 시험 1,931건을 넓은 후보 검색 형식에 연결
- 완료: 모집이 끝난 시험을 제외하고 589건만 현재 후보 검색에 사용
- 완료: 10개 질환군에서 정밀 평가 후보 50건 선택
- 미완료: 선택한 50건의 조건 정리와 객관적 조건 선별
- 새 질환 7개에서 합성 환자 약 35명과 두 가지 정보 부족 상태 추가

1,931개 시험 전체에는 조건별 정답을 붙이지 않는다. 전체 자료는 검색에 사용하고,
정밀 평가 대상으로 고른 약 50개 시험에만 조건·환자 사실·확인 방법·질문 뒤 판단을
정한다.

### R104. 최종 통계 재계산 — 미완료

자료와 지시문을 고정한 뒤 다음 값을 전체 프로그램에서 다시 계산한다.

- 질문 전후에 판단이 끝난 시험 수
- 한 질문으로 상태가 바뀐 시험 수
- 판단을 바꾸지 못한 질문 수
- 새 검사와 추가 방문 선택 수
- 환자 제한을 벗어난 확인 방법 수
- 실행 시간, 모델 호출, 토큰과 시험 조건 저장본 재사용량

기존 30명의 외부 모델 없는 통계는 네 질문 방식과 답을 얻지 못하는 상황까지 다시
계산했다. 이 요구사항은 R103의 새 50건과 합성 환자가 준비된 뒤 같은 통계를 다시
계산해야 완료된다.

### R105. 검색부터 재판정까지 통합 평가 — 미완료

- 넓은 시험 목록에서 후보를 찾는 단계부터 질문 뒤 최종 순위를 갱신하는 단계까지 같은
  환자 사례로 실행
- 관련 시험을 미리 다섯 개로 제한한 현재 질문 평가와 넓은 검색을 포함한 평가를 구분
- 후보 검색, 조건 판단, 질문 선택과 최종 결과를 환자별 한 기록으로 저장
- 질환, 조건 종류와 정보 부족 종류별 결과를 같은 보고서에서 분리

넓은 시험 파일을 실제 실행 경로에 넣는 기능은 구현했다. 현재 30명 평가는 질환별 시험
5개가 미리 정해진 상태에서 시작하므로, 넓은 검색을 포함한 성능 결과로 합치지 않는다.

### R106. 강한 비교 방식과 확인 실패 상황 — 미완료

- 완료: 현재 가장 많은 미완료 시험에 연결된 정보를 고르는 방식과 비교
- 완료: 답 하나를 얻지 못했을 때 반복 없이 다음 정보로 넘어가는 평가
- 완료: 후보를 잘못 제외한 수, 성급한 확정과 실제 상태 전환을 직접 계산
- 미완료: 환자가 모름, 기록 없음과 경로 사용 불가의 원인을 나눈 추가 집계

### R107. 입력 근거와 복잡한 조건 범위 — 미완료

- 완료: 환자 사실의 수치뿐 아니라 항목 이름과 날짜가 원문에 실제로 있는지 검사
- 완료: 판단 시점 뒤에 기록된 자료와 서로 충돌하는 자료를 현재 확인 근거에서 제외
- 복합 `AND`·`OR`, 예외와 시험군별 조건을 지원하거나 지원하지 않는 조건을 입력 단계에서
  명시적으로 제외

### R108. 큰 입력과 반복 실행 안정성 — 완료

- 긴 시험 원문은 줄 경계에서 나누고, 조건 판단은 최대 40개씩 나누어 호출
- 응답에서 일부 조건만 빠지면 성공한 판단은 보존하고 빠진 조건만 다시 요청
- 일괄 평가가 중단되면 완료한 환자·비교 방식은 다시 호출하지 않고 이어서 실행
- 저장소 밖에 설치한 프로그램에서도 역할별 지시문을 읽을 수 있게 배포 파일에 포함

### 보류 항목

- 외부 모델의 전체 30명 성능·비용 측정: R103 뒤에 실행
- 복잡한 `AND`·`OR` 조건과 시험군별 조건: R103에서 선택한 50건을 확인한 뒤 범위를 결정

## 결과 범위

- 검색 수치는 후보 시험을 찾아오는 단계만 설명한다.
- 조건 답 이름의 일치율과 실제 후보 유지·제외 결과는 별도 지표다.
- 질문과 환자 부담 결과는 공개 시험 조건과 합성 환자 안에서 측정했다.
- 과거 합성 데모 수치와 Solar 84%는 현재 결과에 포함하지 않는다.

세부 실행 결과는 [검증 결과](CLARIFYTRIAL_VALIDATION_RESULTS.md), 자료 구성은
[실험자료 구성](CLARIFYTRIAL_DATASETS.md)에 정리돼 있다. 완료·보류·기각된 과거 요구사항은
[개발 상세 기록](CLARIFYTRIAL_IMPLEMENTATION_RECORD.md)에 남아 있다.
