# ClarifyTrial 현재 상태와 핸드오프

마지막 갱신: 2026-08-20

## 현재 상태

- `health-agent/Clarifytrial`을 현행 연구와 구현의 기준 저장소로 사용한다.
- 현행 연구계획은 `CLARIFYTRIAL_RESEARCH_PLAN_V5.md` 하나다.
- v5 에이전트 구조와 데이터 후보 조사는 정리했다.
- v5 실행 코드, 공통 평가 코어와 성능 결과는 아직 없다.
- 구형 v1.2 에이전트 골격과 합성 데모는 현행 구현에서 제외했다.

## 현재 선택한 평가 틀

```text
공통 환자·시험 자료
        ↓
시스템별 입력·출력 변환기
        ↓
숨은 환자 정보와 행동 결과를 가진 공통 환경
        ↓
후보 유지·현재 확정·다음 행동 공통 평가기
```

모든 시스템은 조건별 판단과 근거 ID, 후보 유지, 현재 확정, 다음 행동, 확인하려는
사실과 조건 ID, 종료 이유를 반환한다. 자연어 질문의 표현보다 무엇을 확인하려
했는지를 먼저 평가한다.

첫 구조 비교에서는 임상시험 조건 검색 결과를 미리 계산해 동일하게 제공한다.
환자 기록 조회는 검색 증강 생성이 아니라 통제된 도구 호출로 처리한다. 인터넷
검색과 일반 의료지식 검색은 첫 실험에 넣지 않는다.

자료 확보, 공통 RAG, 평가 입출력과 시스템 연결의 상세 기준은
[CLARIFYTRIAL_RAG_EVALUATION_IMPLEMENTATION_PLAN.md](CLARIFYTRIAL_RAG_EVALUATION_IMPLEMENTATION_PLAN.md)에
정리한다.
