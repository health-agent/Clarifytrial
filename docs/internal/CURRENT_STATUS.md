# ClarifyTrial 현재 상태

기준일: 2026-08-25

## 현재 결론

공개 임상시험 검색, 조건별 판단, 추가로 확인할 정보 선택, 환자 상황에 맞는 확인 방법,
답변 반영, 관련 시험 재판정과 보고서 생성이 한 흐름으로 연결돼 있다. 평가자료도 기존
세 질환을 벗어나 10개 질환·공개 시험 50건·조건 202개·합성 환자 50명으로 넓혔다.

학생 발표용 시스템으로는 충분히 선보일 수 있는 수준이다. 입력과 출력만 있는 시연이
아니라, 자료 출처·복합 조건·질문 전후 변화·환자 부담·중단 상황·비교 결과를 같은
프로그램에서 설명할 수 있다. 발표 순위는 보장할 수 없지만 완성도와 설명 가능성은
강점이다.

소논문은 시스템 구현과 평가를 중심으로 하면 가능성이 있다. 다만 새 질문 알고리즘이
기존 방식보다 크게 우수하다는 논문은 아니다. 현재 방법은 강한 단순 비교 방법과 거의
같았다. 논문의 중심은 정보 부족 때문에 사라질 후보를 별도 목록으로 보존하고, 제한된
확인으로 실제 후보를 확정한 수와 결국 제외한 수, 그 과정의 검사·방문을 함께 평가하는
체계다. 마지막 외부 모델 실행 전에는 모델 성능을 확정적으로 주장하지 않는다.

조건처럼 안전하게 옮기지 못한 문장은 실행 대상에서 제외했다.

## 공개 시험을 연결한 전체 실행 결과

개발에 사용하지 않은 합성 환자 30명에게 시험 5개씩 연결했다. 먼저 589건에서 관련
시험을 검색하고, 검색된 평가 대상에 조건 판단과 추가 확인을 최대 세 번 실행했다.

| 정보를 고른 방법 | 150개 시험 판단 중 최종 상태 일치 | 실제 참가 가능 후보 확정 | 결국 제외될 후보 정리 |
|---|---:|---:|---:|
| 추가 확인 없음 | 24.0% | 0/54개 | 0/60개 |
| 입력 파일에 적힌 순서 | 90.0% | 39/54개 | 60/60개 |
| 현재 가장 많은 시험에 연결된 정보 우선 | 95.3% | 47/54개 | 60/60개 |
| 남은 확인 횟수 전체를 계산 | 95.3% | 47/54개 | 60/60개 |

- 현재 확인이 끝난 시험만 보여 주면 사라질 실제 참가 가능 후보 54개를 모두 추가 확인
  후보로 보존했다.
- 세 번 안에 47개를 실제 참가 가능 후보로 확정했다.
- 처음에는 후보로 남았지만 가상 환자 전체 상태에서는 제외되는 60개를 모두 정리했다.
- 남겨야 할 시험을 잘못 제외한 수, 정보가 부족한데 확정한 수와 실행 오류는 모두 0개다.
- 모집 중 시험 589건에서 평가 대상 150건을 모두 상위 200개 안에 찾았다. 평균 순위는
  37.3위, 가장 낮은 순위는 123위였다. 이 50건은 같은 시험 모음에서 고른 대상이므로
  검색 일반화 성능으로 해석하지 않는다.

남은 확인 횟수 전체를 계산한 방법은 입력 순서보다 환자 6명에서 좋고 24명에서 같았으며
낮은 환자는 없었다. 평균 차이는 5.3퍼센트포인트였다. 반면 현재 가장 많은 시험에
연결된 정보부터 고르는 방법과는 30명 모두 같았다. 복잡한 계산의 큰 우월성을 주장하지
않고, 이 비교 방법을 기본적인 강한 기준선으로 유지한다.

## 남은 판단

외부 모델 30명 실행은 코드 결함을 찾는 작업과 분리한다. 현재 결정론적 평가는 프로그램이
의도한 규칙대로 연결되는지를 확인한 결과다. 외부 모델 실행에서는 조건 문장을 실제로
해석하는 정확도, 호출 실패, 토큰과 시간이 추가로 측정된다.

그 실행 뒤에도 소논문 주장은 다음 범위를 넘기지 않는다.

- 질문·답변·재판정이나 여러 역할의 사용 자체를 새 기여로 말하지 않는다.
- TrialGPT보다 전체 추천 성능이 높다고 말하지 않는다.
- 공개 시험 50건의 전체 참가 조건을 구조화했다고 말하지 않는다.
- 강한 즉시 영향 기준선과 같은 결과를 새로운 질문 알고리즘의 우월성으로 말하지 않는다.

세부 수치와 실행 조건은 [검증 결과](CLARIFYTRIAL_VALIDATION_RESULTS.md), 자료 생성 규칙은
[실험자료 구성](CLARIFYTRIAL_DATASETS.md)에 있다.
