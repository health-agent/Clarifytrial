# ClarifyTrial 현재 상태

기준일: 2026-08-24

## 현재 결론

정해진 JSON 입력 안에서 관련 시험 검색, 조건 판단, 다음 정보 선택, 환자 부담을
고려한 확인 방법 선택, 질문과 답변, 관련 시험 재판정, 중단·재개와 자동 보고서가 한
흐름으로 연결돼 있다.

현재 3개 질환·15개 시험·별도 합성 환자 30명으로 기능을 평가했다. 코드의 주요 흐름은
완성됐으며, 다음 단계는 여러 질환으로 자료 범위를 넓히고 같은 통계를 다시 계산하는
일이다.

## 완성된 범위

- 환자와 시험의 표준 JSON 입력
- 팀의 `topics[num, title]` 합성 환자 입력 변환
- 관련 시험 검색과 처음 검색 순위 보존
- 조건별 판단과 근거 저장
- 후보 유지 여부와 현재 확인 가능 여부 분리
- 여러 정보가 동시에 부족할 때 확인 순서 계산
- 환자 부담에 맞는 확인 방법 선택
- 직접 답변, JSON 답변, 중단과 재개
- 새 정보와 연결된 시험만 다시 판단
- 현재 확인된 시험과 추가 확인 후보를 나눈 최종 목록
- 여러 환자 일괄 평가와 표·그림·보고서 생성
- 반복되는 시험 조건 정리 결과 재사용

## 현재 평가자료

| 평가 | 자료 |
|---|---|
| 관련 시험 검색 | TREC Clinical Trials 2021·2022 |
| 한 번의 조건 판단 | TrialGPT 조건 1,015개 |
| 질문과 재판정 | 공개 시험 15건·조건 92개, 별도 합성 환자 30명·시험 판단 150개 |
| 환자 부담 | 별도 합성 환자 20명의 240개 상황 |
| 구조 안정성 | 정보 연결 구조 700개와 공개 조건 값 77,792개 조합 |

## 핵심 결과

| 평가 | 결과 |
|---|---|
| TREC 2021 관련 시험 상위 500개 유지 | 83.59% |
| TREC 2022 관련 시험 상위 500개 유지 | 81.55% |
| 추가 질문 없이 끝난 시험 판단 | 63/150개, 42% |
| 입력 순서대로 세 번 확인한 뒤 끝난 시험 판단 | 99/150개, 66% |
| 현재 방법으로 세 번 확인한 뒤 끝난 시험 판단 | 115/150개, 77% |
| 환자 제한 안에서 판단을 끝낸 시험 | 81.0% → 88.5% |
| 피해야 할 새 검사·추가 방문 선택 | 65회 → 0회 |

현재 질문 방법은 입력 순서 방식보다 환자 16명에서 좋았고, 12명에서 같았으며,
2명에서 낮았다.

## 다음 작업

### R103. 자료 범위 확장 — 미완료

- 팀 공개 ClinicalTrials.gov 시험 1,931건을 넓은 후보 검색에 연결
- 모집이 끝난 시험을 현재 추천 후보에서 제외
- 질환 범위를 3개에서 약 10개로 확장
- 정밀 평가 시험을 15건에서 약 50건으로 확장
- 새 질환 7개에서 합성 환자 약 35명과 두 가지 정보 부족 상태 추가

1,931개 시험 전체에는 조건별 정답을 붙이지 않는다. 전체 자료는 검색에 사용하고,
정밀 평가 대상으로 고른 약 50개 시험에만 조건·환자 사실·확인 방법·질문 뒤 판단을
정한다.

### R104. 최종 통계 재계산 — 미완료

자료와 지시문을 고정한 뒤 다음 값을 전체 프로그램에서 다시 계산한다.

- 질문 전후에 판단이 끝난 시험 수
- 한 질문으로 상태가 바뀐 시험 수
- 판단을 바꾸지 못한 질문 수
- 새 검사와 추가 방문 선택 수
- 환자 제한을 벗어난 확인 방법 수
- 실행 시간, 모델 호출, 토큰과 시험 조건 저장본 재사용량

### 보류 항목

- 외부 모델의 전체 30명 성능·비용 측정: R103 뒤에 실행
- 복잡한 `AND`·`OR` 조건과 시험군별 조건: 평가자료에서 필요한 구조가 정해진 뒤 구현

## 결과 범위

- 검색 수치는 후보 시험을 찾아오는 단계만 설명한다.
- 조건 답 이름의 일치율과 실제 후보 유지·제외 결과는 별도 지표다.
- 질문과 환자 부담 결과는 공개 시험 조건과 합성 환자 안에서 측정했다.
- 과거 합성 데모 수치와 Solar 84%는 현재 결과에 포함하지 않는다.

세부 실행 결과는 [검증 결과](CLARIFYTRIAL_VALIDATION_RESULTS.md), 자료 구성은
[실험자료 구성](CLARIFYTRIAL_DATASETS.md)에 정리돼 있다. 완료·보류·기각된 과거 요구사항은
[개발 상세 기록](CLARIFYTRIAL_IMPLEMENTATION_RECORD.md)에 남아 있다.
