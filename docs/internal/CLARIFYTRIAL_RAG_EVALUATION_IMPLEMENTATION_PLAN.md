# ClarifyTrial 시험 검색 구현

임상시험 검색은 많은 시험 문서에서 자세히 검토할 후보를 가져오는 단계다. 검색 결과를
참가 가능 판정으로 사용하지 않는다. 후보를 찾은 뒤 시험 원문의 선정 조건과 제외 조건을
별도로 판단한다.

논문에서 자주 쓰는 `RAG`는 외부 문서를 검색해 언어모델 입력에 붙이는 방식을 뜻한다.
ClarifyTrial에서는 검색과 조건 판단을 분리하므로, 이 문서에서는 더 구체적인 표현인
`시험 검색`을 사용한다.

## 1. 검색이 받는 정보와 내는 결과

### 입력

- 환자의 질환과 주요 상태
- 나이와 성별
- 치료, 수술, 바이오마커와 검사 정보
- 지역을 사용하는 경우 이동 가능 범위
- 검색할 임상시험 모음과 모집 상태 기준

### 결과

시험마다 다음 항목을 반환한다.

- 임상시험 번호
- 처음 검색 순위와 검색 점수
- 어떤 환자 정보가 검색에 사용됐는지
- 같은 단어 검색 점수
- 의학적 의미 검색 점수
- 모집 상태

검색 요약은 후보를 찾는 데만 쓴다. 참가 조건 판단에는 시험 원문을 사용한다.

## 2. 두 검색 방법

### 같은 단어 검색

BM25는 환자 설명과 시험 문서에 같은 단어나 비슷한 표기가 많이 나타나는 시험을 위로
올린다. 질환명, 약물명, 바이오마커처럼 정확한 단어가 중요한 경우에 강하다.

### 의학적 의미 검색

MedCPT는 표현이 달라도 의학적으로 뜻이 비슷한 문장을 찾는다. 예를 들어 약물 계열명과
개별 약물명처럼 단어가 완전히 같지 않은 경우를 보완한다.

두 결과는 TrialGPT가 공개한 비중으로 합쳐 하나의 순위를 만든다. 평가에서는 같은
검색어, 문서 모음과 순위 결합 설정을 사용해 공개 결과와 대조한다.

## 3. 현재 사용하는 검색 경로

### 프로그램 전체 흐름용 검색

팀 공개 ClinicalTrials.gov 시험 1,931건 가운데 다음 상태의 589건을 검색한다.

- 모집 중
- 모집 예정
- 초대받은 사람 등록 중

질환 이름과 시험의 질환, 제목, 요약, 참가 조건 문구를 비교한다. 전체 흐름 평가에서는
상위 200건 안에서 정밀 평가 대상으로 미리 정한 시험을 찾아 조건 판단 단계에 넘긴다.

현재 150개 환자–시험 연결이 모두 상위 200개 안에 들어왔지만, 검색된 다른 시험에는
참가 조건 정답이 없다. 이 결과는 검색과 뒤쪽 프로그램이 연결되는지 확인한 값이다.

### 공개 검색 성능 재현

TREC Clinical Trials 2021·2022의 시험 문서, 환자 설명과 전문가 관련성 표시를 사용한다.
TrialGPT 저장소가 공개한 검색어를 그대로 쓰고 BM25, MedCPT와 순위 결합을 실행한다.

이 경로는 검색 단계만 평가한다. ClarifyTrial의 질문, 조건 판단과 환자 부담 규칙은
사용하지 않는다.

## 4. 자료 준비와 저장

큰 원본 문서와 검색용 벡터는 `.research-cache/`에 저장하고 Git에는 올리지 않는다.
저장소에는 다음 정보만 남긴다.

- 공식 자료 주소
- 받은 날짜와 이용 조건
- 고정한 원본 버전 또는 커밋
- 문서 수와 중복 검사 결과
- 원본 파일 해시
- 검색 설정과 사용한 패키지 버전

프로그램 전체 흐름용 팀 시험 모음은 고정 커밋의 1,931개 행과 파일 해시를 확인한다.
최종 결과를 낼 때는 같은 임상시험 번호의 최신 모집 상태를 ClinicalTrials.gov 공식
자료에서 다시 확인할 수 있도록 원본 번호를 보존한다.

자세한 출처와 이용 조건은 [자료 출처](../../DATA_SOURCES.md)에 있다.

## 5. 시험 조건 저장

검색된 시험의 참가 조건 원문을 환자마다 다시 정리하지 않는다. 다음 값이 같을 때 저장된
조건을 재사용한다.

- 임상시험 번호와 원문 내용
- 조건 정리 지시문 버전
- 사용한 모델과 설정
- 구조화 형식 버전

원문이나 설정이 달라지면 새 조건으로 저장한다. 저장된 조건에는 원문 위치, 수치, 날짜,
비교 방향, 필요한 환자 사실과 논리 관계가 함께 들어 있다.

## 6. 검색 뒤 조건 판단으로 넘기는 규칙

검색 단계는 후보를 넓게 가져온다. 다음 값만으로 시험을 최종 제외하지 않는다.

- 검색 점수가 낮음
- 환자 설명에 특정 단어가 없음
- 검색용 요약에 조건 근거가 없음

모집이 끝난 시험처럼 검색 전에 확인할 수 있는 운영 조건은 제외할 수 있다. 그 밖의
참가 가능성은 원문 조건 판단 단계에서 결정한다.

검색 순위는 최종 결과에도 남긴다. 질문 뒤 시험의 상태가 바뀌어도 처음 순위를 보존해
`왜 이 시험이 후보에 들어왔는가`와 `왜 현재 목록 위치가 달라졌는가`를 구분한다.

## 7. 평가 항목

### TREC 검색 평가

- 상위 10, 50, 100, 200, 500개 안에 전문가 관련 시험을 남긴 비율
- 관련 시험을 목록 위쪽에 배치한 정도
- 환자별, 질환별 결과
- BM25만 사용, MedCPT만 사용, 두 결과 결합 비교

### 프로그램 연결 점검

- 정밀 평가 대상으로 정한 시험이 검색 결과 상위 200개 안에 있는지
- 평균 순위와 가장 낮은 순위
- 중복 시험과 모집 상태가 맞지 않는 시험 수
- 검색 결과가 조건 판단 단계에 같은 시험 번호로 전달됐는지

두 평가를 섞지 않는다. 첫 번째는 공개 전문가 관련성 정답을 사용한 검색 성능이고,
두 번째는 미리 정한 평가 시험이 전체 실행 경로에 연결되는지 확인하는 점검이다.

## 8. 현재 결과

### TREC 검색

| 공개 평가자료 | 시험 문서 | 전문가 관련 시험을 상위 500개 안에 남긴 비율 |
|---|---:|---:|
| 2021 | 26,149건 | 83.59% |
| 2022 | 26,581건 | 81.55% |

TrialGPT 공개 수치와의 차이는 두 해 모두 0.1퍼센트포인트보다 작았다. 이 검색기는
TREC 비교 실험에 그대로 유지한다. 일반 실행은 별도 말뭉치와 큰 의미 검색 모델을
요구하지 않는 ClinicalTrials.gov 공식 질환 검색을 기본으로 사용한다. 두 결과를 같은
검색 성능으로 표현하지 않는다.

### 전체 프로그램 연결

- 검색 대상: 589건
- 서로 다른 정밀 평가 시험: 50건
- 환자별 반복을 포함한 평가 연결: 150개
- 상위 200개 안에서 찾은 연결: 150/150개
- 평균 순위: 31.78위
- 가장 낮은 순위: 120위

질환명의 일부 단어만 겹친 시험을 제거한 현재 로컬 검색기로 2026년 8월 28일 다시
실행했다. 검색된 다른 시험은 조건 판단하지 않았으므로 150/150을 전체 검색 정확도나
최종 추천 성능으로 표현하지 않는다.
