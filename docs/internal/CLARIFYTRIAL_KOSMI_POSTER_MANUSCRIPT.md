# 제한된 확인 횟수와 환자 제약을 고려한 상호작용형 임상시험 사전선별: ClarifyTrial

## 초록

**Backgrounds:** 불완전한 환자 기록을 단일 판정으로 압축하면 참가 가능성이 남은 후보를 조기에 제외하거나 근거가 부족한 상태를 확정할 수 있다. ClarifyTrial은 후보 유지와 현재 확인 상태를 분리하고 제한된 확인을 반복하는 사전선별 시스템이다.

**Methods:** 공개 임상시험 50건의 구조화 조건 202개와 합성 환자 50명을 사용하였다. 20명은 개발에 사용하고 30명은 초기 독립 평가군으로 고정하여 환자-시험 150조합에서 확인 한도 0~5회를 평가하였다. 별도 공개 시험 15건과 초기 독립 합성 환자 20명의 두 정보 가림, 200개 환자-시험 관측에서 적격·부적격 전환을 함께 평가하였다. 9종 1,800개 정보 연결 구조에서 선택법을 비교하고, 합성 환자 20명의 80개 짝지은 설정에 검사·방문 제한을 적용하였다.

**Results:** 확인 0~5회의 전체 정보 기준 상태 일치는 128, 142, 147, 149, 150, 150/150이었다. 방향별 초기 미정 120건은 적격 30건과 부적격 90건이었다. 확인 3회에서 영향 우선 규칙은 적격 13/30건과 부적격 75/90건을 정리하여 상태 일치율 84.0%를 보였고, 가능한 순서 평균 78.27%보다 5.73%p 높았다(환자 단위 95% 신뢰구간 3.04~8.55%p). 정확 탐색은 82.5%였다. 연결 구조에서는 정확 탐색이 영향 우선보다 전체 평균 +1.19~+2.00%p, 사슬형 +3.22~+4.27%p였다. 환자 제한 후 새 검사 제안은 21회에서 0회, 추가 방문은 56회에서 0회로 줄고 설정당 확인 대기 시험은 0.36건 늘었다(95% 신뢰구간 0.21~0.53).

**Conclusion:** 여러 시험에 연결된 정보를 먼저 묻는 단순 규칙은 공개 조건 평가에서 정확 탐색과 비슷했지만, 연쇄 의존성이 큰 구조에서는 더 긴 탐색이 유리했다. 환자에게 가능한 확인 경로를 지키면 허용되지 않은 행동을 피하는 대신 미확정 시험이 늘었다. 이는 합성 환자와 선별된 조건의 상태 변화이며 실제 환자의 임상시험 적격 판정 정확도를 뜻하지 않는다.

**핵심어:** 임상시험 매칭, 상호작용형 사전선별, 정보 선택, 환자 제약, 근거 추적

## Backgrounds

임상시험 사전선별에서는 필요한 시점과 출처의 환자 정보가 빠져 있는 경우가 많다. 미확인 값을 불충족으로 처리하면 참가 가능성이 남은 후보를 조기에 제외하고, 부족한 근거로 충족을 확정하면 확인이 끝나지 않은 시험을 적격처럼 제시할 수 있다. 부분 정보의 미확정 상태[1], 조건 판단[2], 순차 질문[3], 비용·영향 범위를 고려한 정보 선택[4], 답변 뒤 재판정[5], 참여 부담에 따른 선호 차이[6]는 선행연구에서 다루어졌다. 본 연구는 이 요소를 근거와 상태가 추적되는 하나의 사전선별 흐름으로 구현하고, 정보 연결 구조별 선택법과 환자 제약의 절충을 평가하였다.

## Methods

ClarifyTrial은 조건별 초기 판단 뒤 더 확인할 후보인지와 현재 근거로 확인을 마쳤는지를 따로 저장한다. 미확정 후보가 있으면 다음 정보와 환자에게 허용된 확인 경로를 고르고, 답과 출처가 들어오면 연결된 조건만 다시 판단한다. 모든 후보가 정리되거나 확인 횟수 또는 이용 가능한 경로가 소진되면 종료한다(그림 1). 수치·날짜·명시적 논리는 코드로 계산하고 자유 문장 해석과 질문 작성에만 언어모델을 사용하였다.

공개 시험 50건의 구조화 조건 202개로 만든 합성 환자 50명 중 20명은 자료 제작·조정에 사용하고, 30명은 초기 독립 평가군으로 고정하여 시험 5건씩 총 150조합을 평가하였다. 나이, 임신·수유 여부와 활동성 중증 감염은 처음부터 제공하고 확인 한도를 0~5회로 바꾸었다. 이 평가의 초기 미정 사례가 전체 정보 기준 적격에만 치우친 점을 보완하기 위해, 별도 공개 시험 15건과 초기 독립 합성 환자 20명에 두 가지 정보 가림을 적용하였다. 총 40개 가림 사례와 200개 환자-시험 관측에서 전체 정보 기준 적격·부적격 전환을 함께 측정하였다. 프로그램 기본 한도인 3회를 주 평가로 두고 1·2회와 0~3회 전체 곡선을 함께 보고했으며, 가능한 정보 순서 전체 평균, 영향 우선 규칙과 정확 탐색을 비교하였다.

별도로 연결 모양 9종×200개인 1,800개 구조에 확인 횟수 1~3회를 적용하였다. 영향 우선 규칙은 현재 미정 시험 수, 연결 조건 수와 확인 부담 순으로 다음 정보를 고른다. 정확 탐색은 남은 횟수 안의 부족 정보 조합을 빠짐없이 계산한다. 모든 선택법은 숨겨 둔 답을 사용하지 않았다. 또 다른 합성 환자 20명의 80개 짝지은 설정에서는 새 검사와 추가 방문 제한을 비교하였다. 후보 유지와 현재 확인 상태가 전체 합성 상태와 모두 같을 때 시험 상태 일치로 셌다. 두 정보 가림은 같은 환자의 반복 측정으로 두고, 질환별 층화 환자 단위 부트스트랩 5,000회로 95% 신뢰구간을 계산하였다. TREC 검색, TrialGPT 개별 조건 자료, 구조화 처리와 자동 검사는 보조 검증으로 사용하였다.

## Results

기본 문진 뒤 전체 정보 기준 상태와 일치한 조합은 128/150이었고 22/150은 미정이었다. 영향 우선 규칙으로 확인 한도를 1~5회로 늘리면 상태 일치는 142, 147, 149, 150, 150/150으로 증가했다. 확인 1회에는 합성 환자 14/30명에게 질문 14개를 선택했고, 미정 22건 중 14건을 적격으로 확인했다. 이 22건에는 전체 정보 기준 부적격 사례가 없었으므로 부적격 정리 성능은 이 평가에서 판단할 수 없다. 확인 1회의 가능한 질문 순서 평균과 영향 우선 규칙은 94.22%와 94.67%로 0.44%p 차이였고(95% 신뢰구간 0.00~1.33%p), 환자별 비교는 개선 1/30명, 동일 29/30명, 하락 0/30명이었다.

방향별 평가에서는 200개 환자-시험 관측 중 80건이 처음부터 전체 정보 기준 상태와 일치했고, 미정 120건은 적격 복원 대상 30건과 부적격 정리 대상 90건으로 나뉘었다. 영향 우선 규칙은 확인 1·2·3회에 적격 0·3·13/30건, 부적격 39·57·75/90건을 정리했고 전체 상태 일치율은 59.5%, 70.0%, 84.0%였다. 주 평가 한도인 3회에서 가능한 120개 정보 순서 평균은 78.27%로, 영향 우선 규칙의 차이는 +5.73%p였다(환자 단위 95% 신뢰구간 3.04~8.55%p). 확인 0~3회 전체 곡선의 차이는 +2.72%p였으나 95% 신뢰구간은 -1.03~6.76%p였다. 같은 3회 한도의 정확 탐색은 82.5%였고 영향 우선과의 차이는 -1.50%p였다(95% 신뢰구간 -4.00~1.00%p). 세 방법에서 안전성 오류는 없었다.

연결 구조별 차이와 환자 제약 결과는 표 1과 같다. 직접 공유가 큰 구조에서는 단순 선택이 효과적이었으나 완전 분리에서는 차이가 없었고, 사슬형에서는 확인 2~3회의 정확 탐색이 유리했다. 환자가 금지한 검사와 방문을 제거하자 해당 제안은 사라졌지만 설정당 확인 대기 시험은 0.36건 늘었다(95% 신뢰구간 0.21~0.53).

## Conclusion

ClarifyTrial은 불완전한 정보에서 후보 유지와 현재 확인 상태를 분리하고, 제한된 횟수 안에서 다음 정보와 실행 가능한 확인 경로를 선택한 뒤 관련 조건만 갱신한다. 선택법의 효과와 필요한 계산 깊이는 정보 연결 구조에 따라 달랐고, 환자 제약을 지키면 허용되지 않은 행동을 피하는 대신 미확정 시험이 늘었다. 결과는 합성 환자와 선별된 구조화 조건에서의 상태 변화이며 실제 환자의 적격 판정 정확도, 모집 성과 또는 비용·시간 절감을 뜻하지 않는다. 초기 독립 평가군의 합성 환자 30명은 동결하고 향후 확장 평가군은 별도로 분석한다. 변동 가능한 부적격 사유의 재검토는 시간순 추적자료를 이용한 향후 연구로 남긴다.

## 그림 1. 삽입 문구와 캡션

**도식 문구**

> 환자·시험 입력 → 후보 검색·초기 조건 판단 → **후보 유지 여부｜현재 확인 상태** → 다음 정보 선택 → 허용된 확인 경로 선택 → 답·근거 획득 → 연결된 조건만 재판정 → 반복 또는 종료

**도식 아래 보조 문구**

> 확인 경로: 기존 기록, 환자 답변, 공식 결과, 새 검사, 의료진 확인
> 환자 제약을 경로 선택 전에 적용하고 판단 근거와 남은 확인 사항을 저장함

**캡션**

**그림 1. ClarifyTrial의 상호작용형 임상시험 사전선별 흐름.** 후보 유지 여부와 현재 확인 상태를 분리하고, 환자에게 허용된 경로로 새 근거를 얻은 뒤 연결된 조건만 갱신한다. 미확정 상태와 확인 한도에 따라 반복하거나 종료한다.
