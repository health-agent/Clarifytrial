# 제한된 확인 횟수와 환자 제약을 고려한 상호작용형 임상시험 사전선별: ClarifyTrial

## 초록

**Backgrounds:** 임상시험 사전선별에서 미확인 정보를 곧바로 충족 또는 불충족으로 처리하면 참가 가능성이 남은 후보를 버리거나 근거가 모자란 시험을 적격으로 확정할 수 있다. ClarifyTrial은 후보 유지 여부와 현재 확인 상태를 분리하고, 제한된 기회 안에서 여러 시험에 공통으로 영향을 주는 정보를 확인한다.

**Methods:** 공개 임상시험 15건에서 선별·구조화한 객관적 조건 80개와 사전 고정 합성 평가 환자 20명을 사용하였다. 환자마다 두 가지 정보 가림을 적용하고 시험 5건을 연결하여 40개 사례와 200개 반복 관측을 만들었다. 확인 0~3회에서 여섯 정보 선택 방법을 비교하였다. 별도로 9종 1,800개 연결 구조와 합성 환자 20명의 80개 짝지은 환자 제약 설정을 평가하였다.

**Results:** 처음 미정인 120건은 전체 정보 기준 적격 30건과 부적격 90건이었다. 확인 3회에서 영향 우선 기본 규칙은 적격 13/30건과 부적격 75/90건을 정리하여 상태 일치율 84.0%를 보였고, 가능한 순서 평균 78.27%보다 5.73%p 높았다. 개발분포 기반 기대값 계획기는 86.0%였지만 기본 규칙과의 차이에 대한 환자 단위 부트스트랩 95% 구간은 0을 포함했다. 완전 공유 구조에서 기본 규칙은 단계별 무작위보다 43.28%p 높았고, 사슬형에서는 조합 포괄 탐색이 3.22~4.27%p 높았다. 환자 제약을 적용하자 설정당 미정 시험은 0.88건에서 1.24건으로 0.36건 늘었다.

**Conclusion:** 직접 공유가 큰 정보에는 단순 규칙이, 연쇄 구조에는 더 깊은 탐색이 유리했다. 환자 제약은 실행 불가능한 제안을 없애는 대신 미정 상태를 늘렸다. 결과는 합성 전체 정보 상태의 복원과 프로그램 상태 전이이며 실제 환자의 적격 판정 정확도나 임상 성과를 뜻하지 않는다.

**핵심어:** 임상시험 사전선별, 불완전 정보, 순차 정보 선택, 환자 제약, 상태 전이

## Backgrounds

임상시험 사전선별에서는 필요한 시점과 출처의 환자 정보가 빠져 있는 경우가 많다. 미확인 값을 불충족으로 처리하면 참가 가능성이 남은 후보를 조기에 제외하고, 부족한 근거로 충족을 확정하면 확인이 끝나지 않은 시험을 적격처럼 제시할 수 있다. 부분 정보의 미정 상태[1], 동적 문진[2], 확인 비용을 고려한 순서 결정[3], 대규모 검색과 조건 판단[4], 추가 질의와 재분류[5], 참여 부담에 따른 선호 차이[6]는 선행연구에서 다루어졌다.

본 연구의 초점은 하나의 환자 정보가 여러 시험 조건에 함께 연결되는 상황에서, 제한된 확인 횟수 안에 무엇을 먼저 확인할지와 어떤 경로를 사용할지를 함께 결정하는 데 있다. ClarifyTrial은 후보 유지 여부와 현재 확인 상태를 분리하고, 새 답과 근거가 들어오면 관련 조건만 다시 판단한다. 본 연구는 적격·부적격 양방향의 상태 복원, 정보 연결 구조에 따른 선택 방법의 차이, 환자 제약을 지킬 때 늘어나는 미정 상태를 차례로 평가하였다.

## Methods

ClarifyTrial은 조건별 초기 판단 뒤 계속 확인할 후보인지와 현재 근거로 확인을 마쳤는지를 따로 저장한다. 미정 시험이 남으면 현재 미정 시험 수, 연결 조건 수와 확인 부담의 순서로 다음 정보를 고르고, 환자에게 허용된 확인 경로를 선택한다. 답과 출처가 들어오면 연결된 조건만 다시 판단하며, 모든 후보가 정리되거나 확인 횟수 또는 이용 가능한 경로가 소진되면 종료한다(그림 1). 수치·날짜·명시적 논리와 상태 전이는 코드가 처리하고, 일반 실행에서 언어모델은 자유 문장 구조화·조건 해석·질문 작성에 제한하였다. 본 평가에서는 미리 구조화한 객관적 조건과 코드 상태 전이만 사용하였다.

주 평가에는 3개 질환의 공개 임상시험 15건에서 선별·구조화한 객관적 조건 80개를 사용하였다. 자료 제작·조정 합성 환자 10명과 구분하여 합성 평가 환자 20명을 사전에 고정하였다. 각 환자에게 두 가지 정보 가림을 반복 적용하고 각 사례에 시험 5건을 연결하여 가림 사례 40개와 환자-시험 반복 관측 200개를 만들었다. 전체 정보를 넣었을 때의 후보 유지 여부와 확인 상태를 기준으로 삼고, 두 축이 모두 같을 때 시험 상태 일치로 셌다.

확인 한도 0~3회에서 가능한 120개 정보 순서의 전체 평균과 다섯 선택 방법인 영향 우선 기본 규칙, 가장 넓은 영향 우선, 부담 대비 영향, 조합 포괄 탐색, 개발분포 기반 기대값 계획기를 비교하였다. 조합 포괄 탐색은 남은 부족 정보의 조합 범위를 계산하고, 기대값 계획기는 자료 제작·조정 환자에서 얻은 답 분포로 미래 상태의 기대값을 계산한다. 어느 방법도 가린 평가 답을 선택에 사용하지 않았다.

원리 검증에는 완전 공유, 완전 분리, 사슬형 등을 포함한 9개 연결 모양을 각각 200개씩 만든 1,800개 구조를 사용하였다. 같은 구조에 확인 1·2·3회를 적용해 직접 영향에 반응하는 규칙과 남은 정보 조합을 더 깊게 계산하는 방법을 비교하였다. 환자 제약 평가에서는 별도 합성 환자 20명의 80개 짝지은 설정에 모든 경로를 허용한 조건과 새 검사·추가 방문을 제거한 조건을 적용하였다. 두 정보 가림과 시험 5건은 같은 환자 안의 반복 관측으로 두고, 질환 구성을 유지한 환자 단위 부트스트랩 5,000회로 95% 구간을 계산하였다.

## Results

주 평가의 200개 반복 관측 중 80건은 확인 전부터 전체 정보 기준 상태와 일치했다. 처음 미정인 120건은 전체 정보 기준 적격 30건과 부적격 90건이었다. 영향 우선 기본 규칙은 확인 1·2·3회에 적격 0·3·13/30건을 복원하고 부적격 39·57·75/90건을 정리했으며, 전체 상태 일치율은 59.5%, 70.0%, 84.0%였다.

확인 3회에서 기본 규칙은 가능한 순서 평균 78.27%보다 5.73%p 높았고 환자 단위 부트스트랩 95% 구간은 +3.04~+8.55%p였다. 반면 확인 0~3회 곡선 면적의 차이는 +2.72%p였으나 95% 구간은 -1.03~+6.76%p였다. 개발분포 기반 기대값 계획기는 확인 3회에 86.0%로 가장 높았지만 기본 규칙과의 +2.00%p 차이에 대한 95% 구간은 -2.00~+6.50%p였다. 따라서 기본 규칙을 모든 예산에서 우수한 방법으로 해석하지 않았다.

연결 구조 실험의 확인 1회에서 기본 규칙과 단계별 무작위의 차이는 완전 공유 +43.28%p, 완전 분리 0.00%p, 사슬형 -0.75%p였다. 같은 정보가 여러 미정 시험을 직접 정리할 때 기본 규칙의 이점이 컸고, 정보가 분리되면 순서 효과가 사라졌다. 확인 2~3회에는 조합 포괄 탐색이 기본 규칙보다 전체 구조 평균 +1.19~+2.00%p, 사슬형 +3.22~+4.27%p 높았다. 여러 단계 뒤의 도달 가능성을 계산하는 방법은 연쇄 의존성이 있는 구조에서 더 유리했다.

환자가 새 검사와 추가 방문을 허용하지 않는 조건을 경로 선택 전에 적용하자 새 검사 제안은 21회에서 0회로, 추가 방문 제안은 56회에서 0회로 줄었다. 동시에 설정당 미정 시험은 0.88건에서 1.24건으로 0.36건 늘었고, 환자 단위 부트스트랩 95% 구간은 +0.21~+0.53건이었다. 금지된 행동을 피하는 대신 미정 상태가 얼마나 늘어나는지를 함께 측정한 결과다.

추가로 공개 시험 50건·조건 202개와 사전 고정 합성 환자 30명의 환자-시험 150조합에서 작동 범위를 확인하였다. 초기 미정 22건이 모두 전체 정보 기준 적격이어서 이 평가는 주 평가의 양방향 결과를 대체하지 않는다.

## Conclusion

ClarifyTrial은 후보 유지 여부와 현재 확인 상태를 분리한 채 제한된 횟수 안에서 공유 영향이 큰 정보를 선택하고, 환자에게 허용된 경로로 근거를 보완한 뒤 관련 조건만 갱신한다. 공개 원문 조건과 합성 환자를 사용한 평가에서는 적격 복원과 부적격 정리가 모두 나타났다. 직접 공유가 큰 구조에는 단순 영향 우선 규칙이, 사슬형 구조에는 더 깊은 조합 탐색이 유리했으며, 환자 제약을 적용하면 실행 불가능한 제안은 제거되지만 미정 시험이 늘었다. 선택 방법의 우위는 확인 예산과 연결 구조, 답 분포 가정에 따라 달라졌다. 모든 결과는 공개 시험 원문의 일부 객관적 조건과 합성 환자에서 전체 정보 기준 상태를 복원한 프로그램 평가이며, 실제 환자의 적격 판정 정확도, 모집 성과, 비용·시간 절감 또는 임상 안전성을 뜻하지 않는다.

## 그림 1. 삽입 문구와 캡션

**도식 문구**

> 환자·시험 입력 → 후보 검색·초기 조건 판단 → **후보 유지 여부｜현재 확인 상태** → 다음 정보 선택 → 허용된 확인 경로 선택 → 답·근거 획득 → 연결된 조건만 재판정 → 반복 또는 종료

**도식 아래 보조 문구**

> 확인 경로: 기존 기록, 환자 답변, 공식 결과, 새 검사, 의료진 확인
> 환자 제약을 경로 선택 전에 적용하고 판단 근거와 남은 확인 사항을 저장함

**캡션**

**그림 1. ClarifyTrial의 상호작용형 임상시험 사전선별 흐름.** 후보 유지 여부와 현재 확인 상태를 분리하고, 환자에게 허용된 경로로 새 근거를 얻은 뒤 연결된 조건만 갱신한다. 미확정 상태와 확인 한도에 따라 반복하거나 종료한다.
