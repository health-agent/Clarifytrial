# 제한된 확인 횟수와 환자 제약을 고려한 상호작용형 임상시험 사전선별: ClarifyTrial

## 초록

**Backgrounds:** 임상시험 사전선별에서 미확인 정보를 곧바로 충족 또는 불충족으로 처리하면 참가 가능성이 남은 후보를 버리거나 근거가 모자란 시험을 적격으로 확정할 수 있다. ClarifyTrial은 정보가 부족한 시험을 후보로 남기고, 제한된 횟수 안에서 가장 많은 미정 시험과 연결된 정보를 환자에게 가능한 방법으로 확인한 뒤 그 정보가 쓰인 조건만 다시 판단한다.

**Methods:** 공개 임상시험 15건에서 선별·구조화한 객관적 조건 80개와 사전 고정 합성 평가 환자 20명을 사용하였다. 환자마다 서로 다른 정보 가림 2개를 만들고 시험 5건을 연결하여 40개 사례와 200개 반복 관측을 구성하였다. 숨긴 정보 5개를 확인하는 120가지 순서의 평균과 다섯 가지 선택 방법을 확인 0~3회에서 비교하였다. 별도로 9종 1,800개 연결 구조와 합성 환자 20명의 80개 짝지은 환자 제약 설정을 평가하였다.

**Results:** 처음 미정인 120건은 전체 정보 기준 적격 30건과 부적격 90건이었다. 확인 3회에서 영향 우선 기본 규칙은 적격 13/30건과 부적격 75/90건, 총 88/120건(73.3%)을 정리했고 전체 상태 일치율은 84.0%였다. 이는 가능한 순서 평균 78.27%보다 5.73%p 높았다. 답변분포 기반 선택은 86.0%였지만 기본 규칙과의 차이를 환자 단위로 재표집해 구한 95% 구간은 0을 포함했다. 완전 공유 구조에서 기본 규칙은 단계별 무작위보다 43.28%p 높았고, 사슬형에서는 조합 탐색이 3.22~4.27%p 높았다. 환자 제약을 적용하자 설정당 미정 시험은 0.88건에서 1.24건으로 0.36건 늘었다.

**Conclusion:** 직접 공유가 큰 정보에는 단순 규칙이, 연쇄 구조에는 더 깊은 탐색이 유리했다. 환자 제약은 실행 불가능한 제안을 없애는 대신 미정 상태를 늘렸다.

**핵심어:** 임상시험 사전선별, 불완전 정보, 순차 정보 선택, 환자 제약, 상태 전이

## Backgrounds

임상시험 사전선별에서는 필요한 시점과 출처의 환자 정보가 빠져 있는 경우가 많다. 미확인 값을 불충족으로 처리하면 참가 가능성이 남은 후보를 조기에 제외하고, 부족한 근거로 충족을 확정하면 확인이 끝나지 않은 시험을 적격처럼 제시할 수 있다. 부분 정보의 미정 상태[1], 동적 문진[2], 확인 비용을 고려한 순서 결정[3], 대규모 검색과 조건 판단[4], 추가 질의와 재분류[5], 참여 부담에 따른 선호 차이[6]는 선행연구에서 다루어졌다.

본 연구는 확인 횟수가 제한된 상황에서 어떤 정보를 먼저 확인하고, 환자에게 가능한 방법 가운데 어떤 경로를 사용할지를 함께 다룬다. ClarifyTrial은 정보가 부족한 시험을 후보로 남겨 두고, 새 답과 근거가 들어오면 그 정보가 쓰인 조건만 다시 판단한다. 제한된 확인으로 미정 시험을 얼마나 적격·부적격으로 정리할 수 있는지, 그 효과가 어떤 시험과 정보의 연결 구조에서 커지는지, 환자에게 허용된 경로만 사용하면 미정 시험이 얼마나 늘어나는지를 차례로 평가하였다.

## Methods

ClarifyTrial은 참가 가능성이 남아 후보로 유지할지와 현재 근거로 확인을 마칠 수 있는지를 따로 기록한다. 미정 시험이 남으면 각 정보가 현재 미정인 시험과 조건에 몇 개나 연결되는지와 확인 부담을 따져 다음 정보를 고르고, 환자에게 가능한 확인 방법을 선택한다. 답과 출처가 들어오면 그 정보가 쓰인 조건만 다시 판단한다. 모든 후보가 정리되거나, 허용한 확인 횟수를 다 쓰거나, 더 이상 가능한 확인 방법이 없으면 멈춘다(그림 1). 수치·날짜·명시적 논리와 상태 전이는 코드가 처리하고, 자유 문장 구조화·조건 해석·질문 작성에만 언어모델을 사용하도록 설계하였다. 정량평가는 구조화 조건과 상태 전이를 코드로 실행했고, 별도 전체 흐름 점검에서는 GPT-5.6 Sol(중간 추론)을 질문 문장 작성에 사용하였다.

주 평가에는 3개 질환의 공개 임상시험 15건에서 선별·구조화한 객관적 조건 80개를 사용하였다. 개발용 합성 환자 10명과 구분하여 합성 평가 환자 20명을 사전에 고정하였다. 각 환자에게 서로 다른 정보 가림 2개를 만들고 각 사례에 시험 5건을 연결하여 가림 사례 40개와 환자-시험 반복 관측 200개를 구성하였다. 전체 정보를 넣었을 때의 후보 유지 여부와 확인 상태를 기준으로 삼고, 두 축이 모두 같을 때 시험 상태 일치로 셌다.

숨긴 정보 5개를 확인하는 120가지 순서를 모두 실행해 평균을 구한 뒤, 이를 영향 우선 기본 규칙, 가장 넓은 영향 우선, 부담 대비 영향, 조합 탐색, 답변분포 기반 선택과 확인 0~3회에서 비교하였다. 조합 탐색은 남은 정보의 조합을 함께 계산하고, 답변분포 기반 선택은 개발용 합성 환자에서 얻은 답변 분포로 다음 확인 뒤 정리될 시험 수를 예상한다. 어느 방법도 숨긴 평가 답을 선택에 사용하지 않았다.

원리 검증에는 완전 공유, 완전 분리, 사슬형 등을 포함한 9개 연결 모양을 각각 200개씩 만든 1,800개 구조를 사용하였다. 같은 구조에 확인 1·2·3회를 적용해 현재 영향 범위가 큰 정보를 고르는 방법과 남은 정보 조합을 함께 계산하는 방법을 비교하였다. 환자 제약 평가에서는 별도 합성 환자 20명의 80개 짝지은 설정에 모든 경로를 허용한 조건과 새 검사·추가 방문을 제거한 조건을 적용하였다. 두 정보 가림과 시험 5건은 같은 환자 안의 반복 관측으로 두고, 질환별 환자 구성을 유지한 채 환자 단위로 5,000회 재표집해 95% 구간을 계산하였다.

## Results

주 평가의 200개 반복 관측 중 80건은 확인 전부터 전체 정보 기준 상태와 일치했다. 처음 미정인 120건은 전체 정보 기준 적격 30건과 부적격 90건이었다. 영향 우선 기본 규칙은 확인 1·2·3회에 적격 0·3·13/30건을 복원하고 부적격 39·57·75/90건을 정리했다. 확인 3회에는 처음 미정인 120건 중 총 88건(73.3%)이 정리됐고, 전체 상태 일치율은 59.5%, 70.0%, 84.0%로 증가했다.

확인 3회에서 기본 규칙은 가능한 순서 평균 78.27%보다 5.73%p 높았고 환자 단위로 재표집해 구한 95% 구간은 +3.04~+8.55%p였다. 반면 확인 0~3회 곡선 면적의 차이는 +2.72%p였으나 95% 구간은 -1.03~+6.76%p였다. 답변분포 기반 선택은 확인 3회에 86.0%로 가장 높았지만 기본 규칙과의 +2.00%p 차이에 대한 95% 구간은 -2.00~+6.50%p였다. 따라서 기본 규칙을 모든 예산에서 우수한 방법으로 해석하지 않았다.

연결 구조 실험의 확인 1회에서 기본 규칙과 단계별 무작위의 차이는 완전 공유 +43.28%p, 완전 분리 0.00%p, 사슬형 -0.75%p였다. 같은 정보가 여러 미정 시험을 직접 정리할 때 기본 규칙의 이점이 컸고, 정보가 분리되면 순서 효과가 사라졌다. 확인 2~3회에는 조합 탐색이 기본 규칙보다 전체 구조 평균 +1.19~+2.00%p, 사슬형 +3.22~+4.27%p 높았다. 한 답이 다음 질문의 필요성을 바꾸는 구조에서는 남은 정보 조합을 함께 계산하는 편이 더 나았다.

환자가 새 검사와 추가 방문을 허용하지 않는 조건을 경로 선택 전에 적용하자 새 검사 제안은 21회에서 0회로, 추가 방문 제안은 56회에서 0회로 줄었다. 동시에 설정당 미정 시험은 0.88건에서 1.24건으로 0.36건 늘었고, 환자 단위로 재표집해 구한 95% 구간은 +0.21~+0.53건이었다. 허용되지 않은 제안을 없앴을 때 미정 시험이 얼마나 늘어나는지도 함께 측정하였다.

추가로 공개 시험 50건·조건 202개와 사전 고정 합성 환자 30명의 환자-시험 150조합에서 작동 범위를 확인하였다. 초기 미정 22건이 모두 전체 정보 기준 적격이어서 이 평가는 주 평가의 양방향 결과를 대체하지 않는다.

## Conclusion

ClarifyTrial은 정보가 부족한 시험을 버리지 않고, 제한된 횟수 안에서 여러 시험을 함께 정리할 정보를 환자에게 가능한 방법으로 확인한다. 이번 평가에서 확인 3회 뒤 초기 미정 120건 중 88건이 적격 또는 부적격으로 정리되었다. 하나의 정보가 여러 시험에 직접 연결되면 영향 우선 방식이, 여러 단계가 이어진 사슬형 구조에서는 조합 탐색이 유리했다. 환자 제약을 지키면 실행할 수 없는 검사와 방문은 피할 수 있지만 일부 시험은 미정으로 남았다.
