## Abstract

임상시험 사전선별에서 미확인 정보를 곧바로 충족 또는 불충족으로 처리하면 참가 가능성이 남은 후보를 제외하거나 근거가 부족한 시험을 적격으로 확정할 수 있다. ClarifyTrial은 정보가 부족한 시험을 후보로 남기고, 제한된 확인 횟수 안에서 다음 정보를 환자에게 가능한 방법으로 확보한 뒤 관련 조건만 다시 판단한다. ClinicalTrials.gov 공개 시험 15건의 객관적 조건 80개와 합성 평가 환자 20명을 이용해, 환자마다 정보 가림 2개와 같은 질환 시험 5건을 적용한 200개 환자-시험 판정을 구성하였다. 현재 가장 많은 미정 시험에 연결된 정보를 고르는 영향 우선, 남은 확인 조합을 함께 계산하는 조합 탐색, 개발 환자의 답 비율을 이용하는 방법 등을 비교하였다. 또한 9종 1,800개 시험-정보 연결 구조와 80개 환자 제약 설정을 평가하였다. 확인 3회 후 초기 미정 120건 중 88건이 적격 또는 부적격으로 정리되었고, 영향 우선의 상태 일치율은 84.0%로 120개 확인 순서 평균보다 5.73%p 높았다. 답 비율 기반 방법은 86.0%로 수치상 가장 높았지만 영향 우선과의 차이는 2.0%p였다. 공통 정보 구조에서는 영향 우선으로 충분했지만, 연쇄 정보 구조에서는 조합 탐색이 유리했다. 환자 제약을 적용하자 허용되지 않은 검사와 방문 제안은 사라졌지만 설정당 미정 시험은 0.88건에서 1.24건으로 늘었다. 이 결과는 제한된 확인 기회에서 정보 연결 구조와 환자에게 가능한 확인 경로를 함께 고려하고, 근거가 부족한 시험은 미정으로 유지하는 사전선별 설계를 뒷받침한다.

**Keywords:** 임상시험 사전선별, 순차 정보 선택, 환자 제약

## Ⅰ. 서론 / Introduction

임상시험 사전선별에서는 필요한 시점과 출처의 환자 정보가 빠져 있는 경우가 많다. 미확인 값을 불충족으로 처리하면 참가 가능성이 남은 후보를 조기에 제외하고, 부족한 근거로 충족을 확정하면 확인이 끝나지 않은 시험을 적격처럼 제시할 수 있다. 선행연구는 부분 정보의 미정 상태[1], 동적 문진과 확인 순서[2,3], 대규모 검색과 재판정[4,5], 참여 부담[6]을 각각 다루었다. 다만 이를 한 과정으로 묶어 제한된 확인 횟수와 환자 제약 아래 어떤 정보 선택 방식이 유리한지 비교한 근거는 부족하다.

본 연구는 정보가 부족한 시험을 후보로 남기고, 새 근거와 연결된 조건만 다시 판단하는 ClarifyTrial을 설계하였다. 확인 횟수와 시험-정보 연결 구조에 따른 선택 방법의 차이, 환자 제약이 남는 미정 시험에 미치는 영향을 평가하였다.

## Ⅱ. 연구 방법 / Methods

### 1. 시스템 흐름

**그림 1. 상호작용형 임상시험 사전선별 흐름**

그림의 연결 관계 기록:

- 환자·시험 입력 → 후보 검색 / 조건별 판단 → 후보 유지 여부 / 확인 완료 여부
- 종료하면 결과·근거 저장으로 이동한다.
- 미정 시험이 있고 확인 기회가 남으면 추가 확인으로 들어간다.
- 정보 선택 → 확인 방법 선택(환자 제한 반영) → 정보 확인 → 관련 조건 재판단
- 재판단 결과는 후보 유지 여부 / 확인 완료 여부로 돌아가 상태를 갱신한다.

재생성 스크립트를 참고한다. 최종 HWP에는 내장 PNG가 들어 있으며 최종 화살표와
문구는 내장 그림을 기준으로 확인한다. 위 기록은 그림을 글로 옮긴 것으로 본문 문장이 아니다.

ClarifyTrial은 추가 확인 대상으로 남길지를 뜻하는 후보 유지 여부와, 현재 근거로 적격/부적격/미정을 구분하는 확인 상태를 따로 기록한다. 여기서 확인은 환자 질문뿐 아니라 기존 기록 조회, 새 검사와 추가 방문으로 정보를 얻는 과정까지 포함한다. 미정은 참가 가능성은 남아 있지만 적격 또는 부적격을 정할 근거가 부족한 상태다. 미정 시험이 남으면 나이처럼 여러 시험/조건에 함께 쓰이는 정보를 먼저 고르고, 환자에게 가능한 범위에서 부담이 적은 확인 경로로 정보와 출처를 얻는다. 새 근거가 들어오면 관련 조건만 다시 판단하며, 모든 후보가 판정되거나 확인 기회가 끝나면 멈춘다. 수치/날짜와 상태 전이는 코드가 처리하고, 자유문장 구조화/조건 해석/질문 작성에만 언어모델을 사용하였다.

### 2. 평가 설계

2형당뇨병/유방암/주요우울장애의 ClinicalTrials.gov 시험 15건에서 객관적 조건 80개를 구조화했다. 조건에 필요한 값과 날짜를 갖춘 합성 환자 30명 중 10명은 개발, 20명은 평가에 사용했다. 전체 정보로 기준 상태를 먼저 정한 뒤, 평가 환자마다 정보 가림 2개와 같은 질환 시험 5건을 적용해 총 200개의 환자-시험 판정을 구성하였다.프로그램이 선택한 정보의 답만 공개했고, 상태 일치율이란 제한된 정보와 전체 정보에서 후보 유지 여부와 확인 상태가 동일한 비율이다.

추가 확인 선택 평가는 환자/시험/가린 정보/확인 횟수를 고정하고 선택 방식만 바꿨다. 가린 정보 5개의 가능한 120가지 순서 평균을 무작위 기준으로 삼았다. ‘영향 우선’은 현재 가장 많은 미정 시험에 연결된 정보 하나를 고른다. ‘조합 탐색’은 남은 확인 횟수 안에서 필요한 정보가 모두 채워지는 시험이 가장 많아지도록 정보 묶음을 고른다. ‘답 비율 기반’은 개발 환자 10명의 답 비율로 다음 확인 뒤 정리될 시험 수를 예상한다. 확인은 0~3회를 비교하고 3회를 주 평가로 삼았다.

시험-정보 연결 구조는 공통(한 정보가 여러 시험에 공유), 독립(시험 간 정보가 겹치지 않음), 연쇄(이웃 시험끼리 정보를 공유) 구조로 구분하였다. 이 세 유형을 포함한 9종 1,800개에서 단계별 무작위/영향 우선/조합 탐색을 확인 2회와 3회에 비교했다. 환자 제약 평가는 합성 환자 20명, 가림 2개, 자료 이용 상황 2개를 조합한 80개 설정에서 모든 방법을 허용한 경우와 새 검사·추가 방문을 제한한 경우를 비교했다.

## Ⅲ. 연구 결과 / Results

전체 200건 중 80건은 처음부터 전체 정보 기준과 상태가 같았고, 나머지 미정 120건의 기준 상태는 적격 30건과 부적격 90건이었다. 영향 우선의 상태 일치율은 확인 0/1/2/3회에 40.0%/59.5%/70.0%/84.0%로 높아졌다. 영향 우선은 120개 순서 평균보다 5.73%p 높았고,답 비율 기반은 86.0%로 가장 높았으나 영향 우선과의 차이는 2.0%p였다.

## Ⅳ. 고찰 / Discussion

추가로 확인할 정보 선택의 효과는 시험-정보 연결 구조와 남은 확인 횟수에 따라 달랐다. 공통 정보 구조에서는 영향 우선의 이점이 확인 기회가 적을수록 크게 나타났고, 독립 정보 구조에서는 순서에 따른 차이가 없었으며, 연쇄 정보 구조에서는 남은 확인 조합을 고려하는 방식이 유리했다. 답 비율 기반 방법이 가장 높은 성능을 보였으나 영향 우선과의 차이는 2.0%p에 그쳐, 별도의 답 분포가 펼요하지 않은 영향 우선을 기본 전략으로 사용할 수 있다. 또한 환자 제약 적용 후 미정 시험이 증가한 것은 실행하기 어려운 검사와 방문을 제외하고 판정을 유보한 결과로, 미정을 후속 확인 상태로 관리하는 접근을 뒷받침한다. 다만 합성 환자와 구조화된 조건을 이용한 평가이므로 실제 임상 기록을 이용한 추가 검증이 필요하다.

## Ⅴ. 결론 / Conclusion

ClarifyTrial은 불완전한 환자 정보에서 후보를 유지한 채 다음 근거를 고르고, 관련 조건을 다시 판단하는 임상시험 사전선별 과정을 제시했다. 평가 결과는 확인 횟수, 정보 연결 구조, 환자에게 가능한 확인 경로를 함께 고려할 필요가 있음을 보여주었다.

| 고찰의 기본 전략 선택 이유 | 미완료 | '차이는 2.0%p에 그쳐'가 남아 있다. 성능 동등성보다 별도의 답 분포가 필요 없다는 실용적 이유를 중심으로 다듬자는 제안만 했다. |

고찰에 제안했던 문장:

> 답 비율 기반 방법의 성능이 가장 높았지만, 영향 우선은 별도의 답 분포 없이 84.0%의
> 상태 일치율을 보여 기본 전략으로 활용할 수 있다.

이 제안은 현재 HWP에 적용되지 않았다. +2.0%p를 통계적으로 동등하다는 근거로 쓰지
않는다. 환자 단위 재추출 결과와 연결 구조 수치의 두 분포는
[검증 결과](CLARIFYTRIAL_VALIDATION_RESULTS.md)에 남아 있다.

### 참고문헌을 유지한 이유

| 번호 | 이 원고에서 맡는 역할 |
|---|---|
| 1 | 정보 부족과 부적격을 구분하는 문제 설정 |
| 2 | 여러 시험에 공통인 질문을 선택하는 동적 문진 |
| 3 | 확인 비용을 고려한 질문·검사 순서 |
| 4 | 언어모델 기반 시험 검색과 조건 판단 |
| 5 | 모호한 조건에 대한 추가 확인과 재판정 |
| 6 | 시간·이동·검사 부담에 따른 참여 선호 |

참고문헌 1번 또는 3번을 빼는 논의가 있었지만 최종본에는 6개가 모두 있다. 과거의 삭제
제안을 실행하지 않는다. 개별 기능의 최초 주장보다 이들을 연결한 흐름과 선택 방법의
작동 조건을 연구의 기여로 설명한다. 이 내부 경계를 초록에 방어적인 문장으로 반복해서
넣지는 않는다.

### 제출 안내와 작업 방식

사용자가 전달한 안내는 포스터 원고 2쪽 이내, 초록 250단어 이내, 키워드 최대 3개,
HWP 또는 Word 제출, 관리자용·심사용 두 파일, 심사용 파일과 파일명 익명화다.
발표자를 첫 번째 저자로 쓰고 밑줄로 표시하며 본문은 배경·방법·결과·결론으로 안내됐다.
샘플 양식에는 고찰과 결론이 따로 있고 최종 HWP도 둘 다 남겼다. 이를 자동으로 합치지
않는다. 원본 초록의 공백 기준 어절 수는 187개였으며 학회 자체 계수 방식은 확인하지
않았다. 참고문헌이 쪽수 제한에서 제외된다는 근거는 없다.

사용자는 전체 구성을 흔드는 수정, 과도한 주석과 통계 표기, 번역체와 생소한 축약어를
원하지 않는다. 실제 있는 문장을 인용하고 핵심 수정만 간단히 제시한다. 원고 수정
권한이 주어져도 HWP 양식·정렬·도형을 임의로 바꾸거나 복사본을 만들지 않는다.
한글을 반복해서 열고 닫지 않으며, 읽기에는 HWP 바이너리 추출을 우선한다. 원본
HWP를 바꾸는 요청과 내부 문서를 기록하는 요청은 구분한다.
