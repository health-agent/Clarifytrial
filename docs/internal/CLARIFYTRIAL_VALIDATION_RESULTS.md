# ClarifyTrial 검증 결과

기준일: 2026-09-02

## 평가 범위

이번 평가는 환자 정보가 모자란 시험이 질문 뒤 어떻게 바뀌는지, 어느 정보 연결
구조에서 질문 순서가 영향을 주는지, 환자에게 허용된 방법을 지키는지 살폈다. 공개
임상시험에서 코드로 계산할 수 있는 조건을 고르고 합성 환자의 전체 상태를 따로 만든
뒤, 시작 입력에서는 일부 정보만 보이지 않게 했다.

시험 하나에는 두 결과가 저장된다. 계속 확인할 후보인지와 현재 자료로 참가 조건 확인을
마쳤는지를 따로 계산한다. 아래의 `시험 상태 일치`는 두 결과가 모두 미리 만든 전체
환자 상태에서 계산한 결과와 같을 때 한 건으로 센 값이다.

실제 환자 모집 결과, 의료비, 임상적 참가 판정 정확도는 이 평가에 포함하지 않았다.

## 1. 공개 시험 50건의 질문 전후 변화

### 1.1 자료와 실행 조건

| 항목 | 규모 |
|---|---:|
| 질환 | 10개 |
| 공개 임상시험 | 50건 |
| 구조화한 조건 | 202개 |
| 합성 환자 | 50명 |
| 자료 제작·조정 환자 | 20명 |
| 최종 평가 환자 | 30명 |
| 환자마다 연결한 시험 | 5건 |
| 최종 평가의 환자–시험 연결 | 150건 |
| 환자마다 허용한 추가 확인 | 최대 1회 |

질환은 방광암, 폐섬유증, 급성 췌장염, 갑상선 안병증, 신증후군, 편두통,
망막박리, 만성 췌장염, 폐암과 난소암이다. 숫자 범위를 계산할 때는 환자 30명을 한 명씩
세었다. 한 환자에게 연결된 시험 다섯 건을 환자 다섯 명처럼 세지 않았다.

나이, 임신·수유 여부, 활동성 중증 감염은 기본 문진 정보로 보고 시작 입력에 넣었다.
시험 원문의 자유 문장에 남아 있던 나이 조건 다섯 개도 구조화한 나이와 같은 정보로
묶었다. 수정 전에는 그중 한 조건이 실제 질문으로 다시 선택됐고, 자료를 다시 만든
뒤에는 자유 문장 나이 조건과 중복 질문이 모두 0건이 됐다.

모든 실행은 코드로만 진행했다. 외부 모델 호출과 토큰 사용은 0이었다.

환자-시험 조합 150개 가운데 28개는 세 기본 정보를 더하기 전에도 처음 환자 자료만으로 상태가
정리돼 있었다. 기본 문진 세 항목을 넣자 명확히 제외할 수 있던 68건과 참가 가능 후보
32개가 추가로 정리됐다. 질문 전까지 상태가 정해진 조합은 모두 128개였다. 위 표의
22개는 그 뒤에도 추가 정보가 남은 후보만 센 값이다. 63.6%는 전체 150개 조합 가운데
이 조건을 만족한 22개에만 적용된다. 따라서 `14/22`는 세 기본 항목을 먼저 제공하고도
남은 22건에서 질문, 답 반영과 재판정이 이어지는지 본 값이며, 전체 환자-시험 연결의
일반 회복률이 아니다.

질문이 필요하지 않은 환자에게는 확인 횟수를 억지로 채우지 않았다. 실제 질문을 받은
14명은 모두 시험을 한 건 이상 정리했다. 따라서 선택한 질문 14번 가운데 어느 시험의
상태도 바꾸지 못한 질문은 없었다. 이번 자료에서 정리된 14건은 전부 참가
가능성이 남아 있던 후보의 확인 완료였다. 제외 조건을 확인해 정리한 사례는 없었다.
따라서 이 수치만으로 제외 후보 정리 능력까지 평가했다고 볼 수 없다.

한 환자에게 연결한 시험 다섯 건을 먼저 묶어 질문 전후를 비교했다. 환자 30명을 통계
단위로 보면 시험 상태 일치율은 평균 9.33%포인트 증가했다. 질환 구성을 유지한 환자
단위 5,000회 재추출의 95% 범위는 6.00~12.67%포인트였고, 개선 14명·동일 16명·악화
0명이었다. 이 범위는 합성 환자 구성에 대한 민감도이며 실제 환자 집단의 효과 범위가
아니다.

한 건 이상 정리된 환자는 평가에 넣은 10개 질환 모두에서 최소 한 명씩 나왔다. 특정
질환 한 곳에만 결과가 몰리지 않았음을 확인하는 범위 정보이며, 처음 보는 질환으로 같은
효과가 이어진다는 뜻은 아니다.

### 1.3 어떤 정보를 먼저 물었는가

현재 규칙은 그 순간 미확정 시험과 조건에 많이 연결된 정보를 우선한다. 비교 기준은
환자에게 남아 있는 정보의 가능한 순서를 모두 실행한 평균이다. 정보가 네 개 남아 있으면
24개 순서를 전부 계산하므로 무작위 추출 오차가 없다.

| 한 번 확인한 뒤의 결과 | 가능한 순서 전체 평균 | 현재 규칙 |
|---|---:|---:|
| 시험 상태 일치 | 94.22% | 94.67% |
| 환자별 비교 | 기준 | 개선 1명 · 동일 29명 · 하락 0명 |

차이는 0.44%포인트였다. 질환 구성을 유지한 환자 단위 5,000회 재추출의 95% 범위는
0.00~1.33%포인트였다. 양측 정확 부호 검정의 p값은 1.0이었다. 기본 문진이 들어간
최종 자료에서는 질문 순서 자체의 우위를 확인하지 못했다.

남은 확인 횟수 0~5회를 모두 합친 곡선에서도 차이는 0.09%포인트였고 95% 범위는
0.00~0.27%포인트였다. 가능한 조합을 더 깊게 계산한 방법과 현재 규칙의 결과도 같았다.
복잡한 계획 계산을 기본값으로 둘 근거는 나오지 않았다.

### 1.4 적격·부적격 방향을 함께 본 보완 평가

기본 문진을 제공한 최종 자료의 미정 22건은 전체 정보 기준 적격 사례에만 해당했다.
따라서 `확인 완료 14건, 조건 불충족 0건`은 두 방향의 성능 차이가 아니라 평가 대상의
구성에서 나온 결과다. 이를 보완하기 위해 별도 공개 조건 자료에서 적격 복원과 부적격
정리를 함께 측정했다.

| 항목 | 규모 |
|---|---:|
| 질환 | 3개 |
| 공개 임상시험 | 15건 |
| 구조화한 조건 | 80개 |
| 자료 제작·조정 합성 환자 | 10명 |
| 초기 독립 평가 합성 환자 | 20명 |
| 환자마다 반복한 정보 가림 | 2개 |
| 초기 독립 평가의 가림 사례 | 40개 |
| 가림 사례마다 연결한 시험 | 5건 |
| 환자-시험 반복 관측 | 200개 |

200개 관측 가운데 80개는 질문 전부터 전체 정보 기준 상태와 같았다. 미정 120개는
전체 정보 기준 적격 30개와 부적격 90개로 나뉘었다. 각각을 `적격 복원 기회`와
`부적격 정리 기회`의 분모로 두었다. 같은 환자의 두 정보 가림과 시험 다섯 건은 서로
독립인 표본으로 세지 않았다.

| 확인 한도 | 영향 우선의 적격 복원 | 영향 우선의 부적격 정리 | 전체 상태 일치 | 가림 사례당 평균 질문 |
|---:|---:|---:|---:|---:|
| 0회 | 0/30 | 0/90 | 40.0% | 0.00회 |
| 1회 | 0/30 | 39/90 | 59.5% | 0.90회 |
| 2회 | 3/30 | 57/90 | 70.0% | 1.60회 |
| 3회 | 13/30 | 75/90 | 84.0% | 2.20회 |

적격을 확인하려면 여러 부족 정보를 연달아 알아야 하는 사례가 있어 확인 한도 1회에는
적격 복원이 없었다. 반면 한 가지 배제 근거만 확인해도 정리되는 시험이 있어 부적격
정리는 첫 질문부터 늘었다. 따라서 두 방향을 합친 전체 일치율만으로 동작 원리를
설명하지 않고 방향별 분모를 함께 적는다.

주 평가 한도는 3회였다. 가림 정보 다섯 개의 가능한 120개 순서를 모두 실행한 평균,
영향 우선 규칙과 남은 확인 조합을 계산한 정확 탐색을 비교했다.

| 확인 3회 | 전체 상태 일치 |
|---|---:|
| 가능한 정보 순서 전체 평균 | 78.27% |
| 영향 우선 규칙 | 84.00% |
| 정확 탐색 | 82.50% |

영향 우선 규칙과 가능한 순서 평균의 차이는 +5.73%포인트였다. 질환별 구성을 유지한
환자 단위 5,000회 재추출의 95% 범위는 +3.04~+8.55%포인트였다. 적격 복원율 차이는
+26.22%포인트(95% 범위 +14.17~+39.56%포인트), 부적격 정리율 차이는
+4.00%포인트(95% 범위 -6.07~+13.39%포인트)였다. 영향 우선 규칙의 이점은 이 설정에서
주로 적격 복원 방향에서 나타났다.

정확 탐색과 영향 우선 규칙의 전체 상태 일치 차이는 -1.50%포인트였고 95% 범위는
-4.00~+1.00%포인트였다. 이 자료에서는 정확 탐색의 추가 이점을 확인하지 못했지만,
두 방법이 일반적으로 동등하다고 단정할 표본 규모도 아니다. 확인 1회와 2회에서 영향
우선과 가능한 순서 평균의 차이는 각각 +3.26%포인트와 +2.04%포인트였고 두 95% 범위는
0을 포함했다. 확인 0~3회 전체 곡선의 정규화 면적 차이도 +2.72%포인트였으나 95%
범위는 -1.03~+6.76%포인트였다. 따라서 3회 결과를 모든 확인 한도에서의 일반적
우위로 넓히지 않는다. 세 확인 한도와 네 방법에서 안전성 오류는 0건이었다.

결과 파일은 `docs/internal/results/kosmi-poster-evidence-v1/`에 있다. 원시 실행은
`runs/kosmi-transition-balance-20260902/`에 있으며, 결과표는 환자 단위 재추출까지
포함한 `scripts/build_kosmi_poster_measurements.py`로 다시 만든다.

### 1.5 처음의 큰 차이를 다시 확인한 과정

처음 만든 자료에서는 나이, 임신·수유 여부와 활동성 중증 감염까지 질문 후보에 넣었다.

정답과 같았다. 차이는 36.50%포인트였다.

현재 규칙이 30명 가운데 29명에게 나이를 먼저 물었다는 사실을 확인한 뒤 조건을

| 시작 입력에 넣은 기본 정보 | 가능한 순서 평균 | 현재 규칙 | 차이 |
|---|---:|---:|---:|
| 없음 | 40.17% | 76.67% | +36.50%p |
| 나이 | 84.56% | 88.00% | +3.44%p |
| 나이·임신/수유·활동성 감염 | 94.22% | 94.67% | +0.44%p |

초기 36.50%포인트에는 기본 문진에서 알 수 있는 정보를 먼저 되찾은 효과가 대부분
들어 있었다. 이 값은 최종 성능 수치로 사용하지 않는다. 자료 구성을 바꿨을 때 효과가
얼마나 달라지는지 보여 주는 민감도 결과로 남긴다.

## 2. 정보 연결 구조 실험

### 2.1 목적과 규모

공개 시험 자료에서는 기본 문진을 제공한 뒤 질문 순서 차이가 거의 사라졌다. 질문
순서가 실제로 작용하는 조건을 찾기 위해 시험과 환자 정보의 연결 모양을 통제했다.

| 항목 | 규모 |
|---|---:|
| 연결 모양 | 9종 |
| 모양마다 만든 구조 | 200개 |
| 전체 구조 | 1,800개 |
| 구조마다 계산한 정보 상태 | 32개 |
| 비교한 정보 선택 방법 | 12개 |
| 확인 횟수 하나마다 수행한 방법·상태 계산 | 691,200회 |
| 허용한 추가 확인 | 1회·2회·3회 |
| 세 확인 횟수의 전체 계산 | 2,073,600회 |

완전 공유, 완전 분리, 공유 중심, 사슬, 겹치는 쌍, 낮은 공유, 세 갈래, 단계형 중심,
부담 충돌 구조를 포함했다. 합성 구조 하나씩을 따로 세고 모양별 구성을 유지한 채
5,000번 다시 뽑아 결과 범위를 계산했다. 구조 1,800개는 합성 환자 1,800명이 아니다.
같은 구조를 확인 횟수 1·2·3회에 반복 적용했으므로 세 확인 횟수를 서로 다른 독립 표본으로
세지 않는다. 표의 691,200회는 확인 횟수 하나마다 수행한 선택 방법 계산 수다.

안내서에 적은 난수 시작값 `20260830`으로 확인 1회 실험 1,800개를 새 폴더에서 다시
계산했다. 구조, 정보 상태, 선택 방법별 결과와 연결 모양별 결과가 기존 결과와 모두
일치했다. 재현 명령에는 구조 생성과 무작위 선택에 쓴 두 난수값을 함께 적었다.

현재 단순 규칙과 복잡한 계획을 비교한 값이 아니다.

개발 구조와 비슷한 분포에서는 학습한 선택 방법이 평균 성능이 가장 높았지만, 조건을
바꾼 분포에서는 이점이 줄거나 순서가 바뀌었다. 앞으로 확인할 정보 조합을 계산한 방법은 사슬
구조에서 도움이 됐지만 전체 평균 차이는 2.00%포인트 안이었다. 기본 실행에는 확인
방법의 부담을 함께 보고 설명하기 쉬운 현재 규칙을 남겼다. 질문 순서 실험은 현재 규칙의
보편적 우위를 보여 주는 평가로 설계하지 않았다. 결과는 연결 구조에 따라 어느 방법이
유리해지는지 보여 준다.

## 3. 같은 정보를 얻는 확인 방법 선택

어떤 정보를 볼지와 그 정보를 어떻게 얻을지를 나눠 보기 위해 같은 합성 답을 주는 두
확인 방법을 만들었다.

| 확인 방법 | 합성 설정 |
|---|---|
| 기존 공식 결과 조회 | 새 검사와 방문 없음, 72시간 대기 |
| 새 비침습 검사 | 새 검사와 방문 필요, 8시간 대기 |

합성 환자 20명에서 정보 두 개씩을 숨긴 40개 사례를 만들었다. 부담 최소, 이동·비용
제한, 시간 긴급의 세 설정으로 실행했다.

| 환자 상황 | 선택 결과 |
|---|---:|
| 추가 부담을 줄이는 설정 | 기존 공식 결과 85/85회 |
| 이동과 비용이 부담되는 설정 | 기존 공식 결과 85/85회 |
| 시간이 급한 설정 | 새 검사 85/85회 |

여러 정보를 차례로 확인해 확인 방법 선택 횟수가 사례 수보다 많다. 환자 상황이 달라져도
어떤 정보를 확인했는지와 최종 시험 상태는 40개 사례 모두 같았다. 72시간과 8시간은
선택 규칙을 확인하려고 정한 값이다. 실제 의료 대기시간을 추정하는 데에는 쓰지 않는다.
각 85회는 합성 환자 20명에게 정보를 두 가지로 숨긴 40개 사례에서 나온 행동 수다.
같은 환자 안에서 선택이 반복돼 행동 수가 85회가 됐다. 환자 상황별로 정해 둔 선택
규칙이 85번 모두 그대로 적용됐는지 확인한 값이다. 이 값에 별도의 모집단 신뢰구간을
붙이지 않았다.

## 4. 환자가 허용하지 않은 방법 제거

새 검사와 추가 방문을 허용하지 않는 합성 환자에게 해당 확인 방법을 먼저 제거했다. 환자
20명, 숨길 정보 조합 2개, 자료를 얻을 수 있는 상황 2개를 조합한 80개 설정에 두
방법을 적용했다. 합성 환자 20명 안에서 숨긴 정보와 자료 이용 상황을 반복해 80개
설정을 만들었다.

| 결과 | 모든 확인 방법을 남김 | 허용하지 않은 방법을 제거 |
|---|---:|---:|
| 새 검사 제안 | 21회 | 0회 |
| 추가 방문 제안 | 56회 | 0회 |
| 설정 하나에 남은 확인 대기 시험 | 평균 0.88개 | 평균 1.24개 |
| 시험 다섯 건을 모두 정리한 설정 | 42/80개 | 32/80개 |
| 합성 누적 대기시간 | 58.31시간 | 67.61시간 |

새 검사와 추가 방문은 같은 행동에 함께 붙을 수 있어 두 횟수를 더하지 않는다. 금지한
방법을 빼자 새 검사와 추가 방문 제안은 사라졌고, 확인을 기다리는 시험은 평균 0.36개
늘었다. 시험 다섯 건을 모두 정리한 설정은 10개 줄었다.

환자 20명을 단위로 한 대응 재추출에서 미확정 시험 증가는 평균 0.36개였고 95% 범위는
0.21~0.53개였다. 시험 다섯 건을 모두 정리한 설정 비율은 12.5%포인트 줄었고 95%
범위는 -18.75~-6.25%포인트였다. 설정 80개를 독립 표본으로 놓고 계산한 범위가 아니다.

평가 코드에는 `현재 허용된 확인 방법으로 알아낼 수 있는 정보만 놓고 본 내부 목표 일치율`도
있다. 이 값은 79.5%에서 91.25%로 바뀌었다. 알아낼 수 없는 정보를 채점 대상에서
제외하므로 임상 정확도나 전체 추천 성능으로 해석할 수 없다. 사용자 제한을 무시한
결론을 높은 점수로 주지 않는지 확인하는 개발용 점검값이다.

## 5. 보조 평가

### 5.1 TREC 후보 검색 재현

TREC Clinical Trials 2021·2022에는 환자 설명과 관련 임상시험에 대한 전문가 표시가
있다. TrialGPT가 공개한 BM25와 MedCPT 순위 결합을 같은 자료에서 다시 실행했다.

| 자료 | 시험 문서 | 전문가가 관련 있다고 표시한 시험을 상위 500개 안에 남긴 비율 |
|---|---:|---:|
| TREC 2021 | 26,149건 | 83.59% |
| TREC 2022 | 26,581건 | 81.55% |

TrialGPT 공개 결과와의 차이는 두 해 모두 0.1%포인트보다 작았다. 이 실험은 많은 시험
가운데 관련 후보를 검색 결과 안에 남기는 단계만 확인한다. 조건 판정, 질문과 재판정은
포함하지 않는다.

### 5.2 TrialGPT 개별 조건 자료

개발 환자와 겹치지 않는 환자 33명, 환자와 시험의 조합 64개, 조건 654개에서 질문 전
한 번의 조건 판정을 비교했다.

| 방법 | 전문가가 붙인 답 이름과 일치 |
|---|---:|
| ClarifyTrial 조건 판정 | 517/654, 79.1% |
| 공개 TrialGPT 출력 | 581/654, 88.8% |

ClarifyTrial은 기록에 직접 적히지 않은 사실을 정보 부족으로 남기는 경향이 강했다.
TrialGPT 자료의 답 이름으로 채점하면 공개 TrialGPT 출력이 더 높다. 이 자료에는 다음에
확인할 정보, 답변 뒤 상태 변화와 여러 시험의 추천 순위가 표시돼 있지 않다. 질문 전
조건 하나의 답 이름을 맞춘 결과와 현재 주 평가를 직접 비교하지 않는다.

### 5.3 프로그램 연결과 구조화 조건

- 공식 합성 환자 10명을 ClinicalTrials.gov 검색부터 결과 저장까지 실행했다. 질환
  관련성 확인을 통과한 시험 25건에서 조건 472개를 처리했다. 각 단계가 이어지는지
  확인한 기록이며 추천 정확도 수치로 쓰지 않는다.
- 개발과 겹치지 않는 공개 시험 15건, 합성 환자 25명, 환자–시험 연결 75개에 구조화
  규칙을 적용했다. 코드만 쓴 실행과 언어모델을 추가한 두 실행이 모두 75/75로 같았다.
  객관적으로 구조화한 조건에서는 모델 호출을 늘릴 이유가 없다는 구현 근거로 사용한다.
- 전체 실행에서 모델 호출 오류와 응답 형식 오류를 각각 강제로 만들었다. 두 경우 모두
  정상 `result.json`은 만들지 않았고, `execution-error.json`과 그때까지의
  `trace.jsonl`을 남긴 뒤 실행을 중단했다.
- 같은 출력 폴더에 지난 성공 결과와 실패 기록을 넣어 둔 뒤 실패를 다시 만들었다. 이전
  `result.json`은 남지 않았고, 오류 파일과 실행 기록에는 이번 시도만 저장됐다. 실패 뒤
  정상 실행에서도 지난 오류 파일이 남지 않았다.

### 5.4 실제 모델 호출 흐름 한 사례

합성 환자 `source-chronic_pancreatitis-04` 한 명과 시험 다섯 건을 `gpt-5.6-sol`
중간 추론으로 두 번 실행했다. 두 실행은 같은 프롬프트를 사용했다. 처음에는 구조화
규칙으로 계산할 수 있는 조건도 조건 판단 모델에 보냈다. 개선 뒤에는 코드가 해당 조건을
먼저 끝내고, 모델은 다음 확인 문장을 작성할 때만 사용했다.

| 한 사례에서 기록한 값 | 개선 전 | 개선 후 |
|---|---:|---:|
| 전체 모델 호출 | 5회 | 2회 |
| 조건 판단 모델 호출 | 3회 | 0회 |
| 다음 확인 문장 모델 호출 | 2회 | 2회 |
| 전체 토큰 | 72,659 | 23,707 |
| 모델 응답시간 합 | 62.104초 | 43.485초 |
| 모델 판정을 구조화 규칙이 다시 고친 횟수 | 1회 | 0회 |

호출은 60.0%, 토큰은 67.4%, 한 사례의 모델 응답시간 합은 30.0% 줄었다. 질문으로
확인한 정보의 순서와 최종 시험 다섯 건의 상태는 전후와 각각의 코드 전용 실행에서
같았다.

개선 전에는 임신·수유 여부가 거짓이라는 근거를 모델이 정보 부족으로 남긴 한 건을 코드가
교정했다. 개선 뒤에는 이처럼 코드로 계산할 수 있는 조건을 조건 판단 모델에 보내지 않았다.

합성 환자 한 사례에서 역할 배치, 사용량 기록과 구조화 규칙 우선 처리가 이어지는지 본
결과다. 정확도 향상이나 일반 처리시간의 성능값이 아니다. 추적 가능한 결과는
`docs/internal/results/presentation-evidence-v2/model_role_routing_change.csv`에 있다.

## 6. 해석 범위

현재 결과로 확인한 내용은 다음과 같다.

- 기본 문진 뒤에도 남아 있던 미확정 시험 22건 가운데 14건이 한 번의 확인으로 정리됐다.
- 별도 방향별 평가에서는 확인 3회에 적격 복원 대상 30건 중 13건, 부적격 정리 대상
  90건 중 75건이 정리됐다. 영향 우선 규칙의 전체 상태 일치는 가능한 순서 평균보다
  5.73%포인트 높았고 환자 단위 95% 범위는 3.04~8.55%포인트였다.
- 질문 순서의 영향은 시험 여러 건이 같은 한 정보에 직접 연결된 구조에서 크게 나타났다.
- 사슬형 연결에서는 확인을 두세 번 허용했을 때 앞으로 확인할 정보 조합을 계산한
  방법이 현재 규칙보다 높았다.
- 환자 상황에 따라 같은 정보를 얻는 방법이 바뀌었다.
- 금지한 검사와 방문을 제거하자 해당 제안이 사라졌고 확인을 기다리는 시험이 늘었다.

다음 내용은 현재 수치로 판단할 수 없다.

- 실제 환자의 임상시험 참가 판정 정확도
- 실제 의료비, 검사 부담이나 대기시간 절감
- 처음 보는 질환과 전체 임상시험 조건에서 같은 효과 크기
- TrialGPT보다 높은 전체 추천 성능
