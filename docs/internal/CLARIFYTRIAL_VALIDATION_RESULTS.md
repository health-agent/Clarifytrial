## 2. 공개 시험 조건 기반 평가자료

팀이 공개한 ClinicalTrials.gov 시험 1,931건 가운데 모집 중·모집 예정 589건을 검색
대상으로 사용했다. 10개 질환에서 시험 5건씩 골라 50건의 일부 조건을 구조화했다.

| 항목 | 수 |
|---|---:|
| 질환 | 10개 |
| 공개 임상시험 | 50건 |
| 구조화 조건 | 202개 |
| 복합 조건 | 3개 시험·4묶음 |
| 합성 환자 | 50명 |
| 환자–시험 조합 | 250개 |
| 가상 환자 전체 상태에서 참가 가능 | 98개 |
| 가상 환자 전체 상태에서 참가 조건 불충족 | 152개 |

합성 환자 20명은 자료와 규칙을 확인하는 데 사용하고 30명은 별도 평가에 사용했다.
환자마다 1개·2개·3개 또는 5개 정보를 가렸다. 환자 답변, 병원 기록, 기존 공식 결과,
새 비침습 검사에 해당하는 확인 방법을 포함했다.

복합 수치 문장을 한 검사 기준으로 잘못 읽지 않도록 여러 조건이나 여러 수치가 섞인
문장은 자동 수치 구조화에서 제외했다. 나이와 검사값은 넓은 사람 범위 안에서 만들고,
개발 환자와 별도 평가 환자에 경계 안팎 값이 한쪽으로 몰리지 않도록 값 순서를 정했다.

구조화 범위는 최소·최대 나이, 단일 수치 비교, 명확한 상태 조건, 짧은 원문 조건과
원문에서 개수 관계가 분명한 네 묶음이다. 50개 시험의 전체 참가 조건이 아니며, 안전하게
옮기지 못한 예외와 시험군별 문장은 실행 조건에서 제외했다.

생성 결과를 같은 공개 시험 원본과 설정에서 다시 만들고 저장된 JSON과 전체 비교하는
검사를 통과했다.

## 3. 검색부터 질문 뒤 재판정까지 연결한 결과

별도 평가 환자 30명에게 시험 5개씩 연결했다. 각 환자에서 589건을 먼저 검색하고,
검색된 평가 대상에 조건 판단과 추가 확인을 최대 세 번 실행했다.

| 정보를 고른 방법 | 최종 상태 일치 | 후보 유지·제외 일치 | 환자당 확인 수 |
|---|---:|---:|---:|
| 추가 확인 없음 | 36/150, 24.0% | 60.0% | 0.00개 |
| 입력 파일에 적힌 순서 | 135/150, 90.0% | 100.0% | 1.97개 |
| 현재 가장 많은 시험에 연결된 정보 우선 | 143/150, 95.3% | 100.0% | 1.87개 |
| 남은 확인 횟수 전체를 계산 | 143/150, 95.3% | 100.0% | 1.87개 |

후보 유지와 현재 확인 상태를 함께 맞혀야 최종 상태 일치로 계산했다. 남겨야 할 시험을
잘못 제외한 수, 정보가 부족한데 참가 가능으로 확정한 수와 실행 오류는 모든 방법에서
0개였다.

### 실제 참가 가능 후보와 결국 제외될 후보

처음 자료에서 현재 확인이 끝난 시험만 보여 주면 보이지 않지만, 가상 환자의 전체 상태에서는 실제
참가 가능인 시험이 54개였다. ClarifyTrial은 54개를 모두 추가 확인 후보로 보존했다.

| 정보를 고른 방법 | 질문 뒤 실제 후보로 확정 | 결국 제외될 후보 정리 |
|---|---:|---:|
| 추가 확인 없음 | 0/54, 0.0% | 0/60, 0.0% |
| 입력 파일에 적힌 순서 | 39/54, 72.2% | 60/60, 100.0% |
| 현재 가장 많은 시험에 연결된 정보 우선 | 47/54, 87.0% | 60/60, 100.0% |
| 남은 확인 횟수 전체를 계산 | 47/54, 87.0% | 60/60, 100.0% |

입력 순서와 비교하면 남은 확인 횟수 전체를 계산한 방법이 좋았던 환자는 6명, 같았던
환자는 24명, 낮았던 환자는 0명이었다. 평균 최종 상태 일치 차이는 5.3퍼센트포인트였고
양측 부호검정 값은 `p=0.03125`였다.

현재 가장 많은 시험에 연결된 정보부터 고르는 방법과는 30명 모두 같았다. 따라서
복잡한 계산을 새로운 성능 우위로 해석하지 않는다.

## 7. TREC 관련 시험 검색

TrialGPT가 사용한 BM25와 MedCPT 검색을 같은 TREC 자료에서 다시 실행하고 두 순위를
결합했다.

| 자료 | 검색 방식 | 관련 시험을 상위 500개 안에 남긴 비율 | 순위 점수 |
|---|---|---:|---:|
| TREC 2021 | BM25 | 79.07% | 66.22% |
| TREC 2021 | MedCPT | 80.44% | 66.25% |
| TREC 2021 | 두 검색 결합 | **83.59%** | **69.97%** |
| TREC 2022 | BM25 | 78.75% | 66.98% |
| TREC 2022 | MedCPT | 78.95% | 66.83% |
| TREC 2022 | 두 검색 결합 | **81.55%** | **70.11%** |

TrialGPT 공개 결과와 다시 실행한 값의 가장 큰 차이는 0.1퍼센트포인트보다 작았다. 이
결과는 관련 시험 검색만 평가하며 참가 조건 판단과 최종 추천은 포함하지 않는다.

## 8. 한 번의 조건 판단

지시문 작성에 사용하지 않은 환자 33명·조건 654개에서 질문 전 판단을 TrialGPT 전문가
답과 비교했다.

| 방식 | 전문가 답 이름과 일치 |
|---|---:|
| ClarifyTrial 조건 판단 | 517/654, 79.1% |
| TrialGPT 공개 답 | 581/654, 88.8% |

개발 표본의 남은 오답 51개 중 47개는 `판단 가능`과 `정보 부족` 사이의 답 이름
차이였다. 두 답은 ClarifyTrial에서 모두 후보 유지로 이어진다. 답 이름만 맞추기 위한
추가 조정은 중단했고, 이 결과로 TrialGPT보다 높은 전체 성능을 주장하지 않는다.

## 10. 결과의 범위

- 환자 자료는 모두 합성이다.
- 202개 조건은 공개 시험 50건의 일부이며 전체 참가 조건이 아니다.
- 결정론적 전체 흐름 결과는 프로그램 규칙과 자료 연결을 확인한 값이다.
- 마지막 외부 모델 30명 실행과 호출·토큰 측정은 아직 하지 않았다.
- 강한 단순 정보 선택 방법과 같은 결과이므로 새 질문 알고리즘의 우월성을 주장하지 않는다.
- 질문·답변·재판정과 여러 모델 역할 자체는 선행연구에 있는 기능이다.
