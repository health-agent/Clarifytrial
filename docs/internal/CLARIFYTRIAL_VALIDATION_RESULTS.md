기준일: 2026-09-02

문서 보완일: 2026-09-05. 아래 '최종 포스터 원고의 수치 대응'은 기존 결과의 표기와
분모를 정리한 것이다. 새 실험이나 자동 검사를 실행한 기록이 아니다.

## 최종 포스터 원고의 수치 대응

현행 원고는 [2026-09-05 최종 HWP 내용 기록](CLARIFYTRIAL_KOSMI_POSTER_MANUSCRIPT.md)이다.
주 평가는 아래 1.4절의 15개 공개 시험·80개 조건·평가 환자 20명이며, 1.1~1.3절의
50개 공개 시험·30명·150개 평가와 구분한다.

여섯 방법의 예산별 점수는
`results/presentation-evidence-v2/budget_policy_scores.csv`, 방향별 분모와 환자 단위
비교는 `results/kosmi-poster-evidence-v1/`에서 확인한다. +5.73%p의 환자 단위 95%

같은 환자의 반복 관측을 독립 표본으로 세지 않았다. 최종 원고가 긴 구간 표기를
생략했어도 방법 간 동등성을 검증한 것으로 해석하지 않는다.

최종 표에 적힌 연결 구조 결과는 다음 중 **similar_heldout**에 해당한다. 원고에는
그 답 분포 조건이 아직 명시되지 않았다는 편집 검토 결과를 별도로 남겼다. 아래 수치는
재계산한 것이 아니라 기존 CSV를 읽어 확인한 것이다.

|---|---:|---:|---:|---:|

비슷한 답 분포는 similar_heldout, 바꾼 답 분포는 shifted_heldout이다. 출처는
`results/presentation-evidence-v2/simple_vs_random_subgroups.csv`와
`results/presentation-evidence-v2/subgroup_policy_differences.csv`다. 예컨대 공통 정보
2회의 30.1%p는 상태 일치율 약 70.4%와 40.3%의 차이다. 확인 3회에서는 각각
약 80.3%와 61.1%라 차이가 19.2%p다. 확인을 늘린 뒤 양쪽 성능은 올라갔고 격차는
줄어든 것으로, 영향 우선 성능 자체가 30.1%에서 19.2%로 떨어졌다는 뜻이 아니다.

원고의 구조 이름과 `interactive/stress.py`의 대응은 다음과 같다.

| 원고 표현 | 코드 이름 | 현재 통제 구조의 시험별 필요 정보 |
|---|---|---|
| 공통 정보 구조 | fully_shared | A / AB / AC / AD / AE |
| 독립 정보 구조 | fully_separated | A / B / C / D / E |
| 연쇄 정보 구조 | chain | AB / BC / CD / DE / EA |

현재 chain은 이웃 시험이 한 정보씩 겹치는 닫힌 고리다. 이것은 이 실험에서 만든
특정 구조의 설명이며, 모든 연쇄 구조가 반드시 한 정보씩만 공유한다는 일반 정의가
아니다. 9종 1,800개 전체 중 세 가지 대표 구조를 최종 표에 제시했다. 주 비교는
확인 2회·3회이고, 1회는 2.3절의 보조 진단으로 보존한다.

환자 제약의 80개 설정은 20명 × 가림 2개 × 자료 이용 상황 2개다. 같은 설정에
경로 제한 전후를 적용했다. `results/presentation-evidence-v2/burden_ablation_three_steps.csv`의
1단계와 2단계를 비교하면 미정 시험 총합 70→99건, 설정당 평균 0.875→1.2375건,
시험 5건을 모두 정리한 설정 42→32개다. 최종 표의 0.88→1.24는 이를 반올림한 값이다.
검사 21회와 방문 56회는 중복될 수 있는 제안 항목이므로 합산하지 않는다.

## 평가 범위

이번 평가는 환자 정보가 모자란 시험이 질문 뒤 어떻게 바뀌는지, 어느 정보 연결
구조에서 질문 순서가 영향을 주는지, 환자에게 허용된 방법을 지키는지 살폈다. 공개
임상시험에서 코드로 계산할 수 있는 조건을 고르고 합성 환자의 전체 상태를 따로 만든
뒤, 시작 입력에서는 일부 정보만 보이지 않게 했다.

시험 하나에는 두 결과가 저장된다. 계속 확인할 후보인지와 현재 자료로 참가 조건 확인을
마쳤는지를 따로 계산한다. 아래의 `시험 상태 일치`는 두 결과가 모두 미리 만든 전체
환자 상태에서 계산한 결과와 같을 때 한 건으로 센 값이다.

실제 환자 모집 결과, 의료비, 임상적 참가 판정 정확도는 이 평가에 포함하지 않았다.

## 1. 공개 시험 50건의 질문 전후 변화

### 1.1 자료와 실행 조건

| 항목 | 규모 |
|---|---:|
| 질환 | 10개 |
| 공개 임상시험 | 50건 |
| 구조화한 조건 | 202개 |
| 합성 환자 | 50명 |
| 자료 제작·조정 환자 | 20명 |
| 최종 평가 환자 | 30명 |
| 환자마다 연결한 시험 | 5건 |
| 최종 평가의 환자–시험 연결 | 150건 |
| 환자마다 허용한 추가 확인 | 최대 1회 |

질환은 방광암, 폐섬유증, 급성 췌장염, 갑상선 안병증, 신증후군, 편두통,
망막박리, 만성 췌장염, 폐암과 난소암이다. 숫자 범위를 계산할 때는 환자 30명을 한 명씩
세었다. 한 환자에게 연결된 시험 다섯 건을 환자 다섯 명처럼 세지 않았다.

나이, 임신·수유 여부, 활동성 중증 감염은 기본 문진 정보로 보고 시작 입력에 넣었다.
시험 원문의 자유 문장에 남아 있던 나이 조건 다섯 개도 구조화한 나이와 같은 정보로
묶었다. 수정 전에는 그중 한 조건이 실제 질문으로 다시 선택됐고, 자료를 다시 만든
뒤에는 자유 문장 나이 조건과 중복 질문이 모두 0건이 됐다.

모든 실행은 코드로만 진행했다. 외부 모델 호출과 토큰 사용은 0이었다.

### 1.2 한 번의 확인으로 바뀐 시험

| 결과 | 값 |
|---|---:|
| 시작할 때 추가 정보가 필요했던 환자-시험 조합 | 22/150개 |
| 실제 질문 수 | 14회 |
| 질문을 받은 환자 | 14/30명 |
| 어느 시험 상태도 바꾸지 못한 질문 | 0회 |
| 한 건 이상 정리된 환자가 나온 질환 | 10/10개 |
| 확인 완료로 바뀐 시험 | 14건 |
| 조건 불충족으로 정리된 시험 | 0건 |
| 시작 당시 미확정 시험 가운데 정리된 비율 | 14/22, 63.6% |
| 한 번의 확인 뒤에도 기다리는 시험 | 8건 |
| 이미 아는 나이를 다시 물은 질문 | 0회 |

환자-시험 조합 150개 가운데 28개는 세 기본 정보를 더하기 전에도 처음 환자 자료만으로 상태가
정리돼 있었다. 기본 문진 세 항목을 넣자 명확히 제외할 수 있던 68건과 참가 가능 후보
32개가 추가로 정리됐다. 질문 전까지 상태가 정해진 조합은 모두 128개였다. 위 표의
22개는 그 뒤에도 추가 정보가 남은 후보만 센 값이다. 63.6%는 전체 150개 조합 가운데
이 조건을 만족한 22개에만 적용된다. 따라서 `14/22`는 세 기본 항목을 먼저 제공하고도
남은 22건에서 질문, 답 반영과 재판정이 이어지는지 본 값이며, 전체 환자-시험 연결의
일반 회복률이 아니다.

질문이 필요하지 않은 환자에게는 확인 횟수를 억지로 채우지 않았다. 실제 질문을 받은
14명은 모두 시험을 한 건 이상 정리했다. 따라서 선택한 질문 14번 가운데 어느 시험의
상태도 바꾸지 못한 질문은 없었다. 이번 자료에서 정리된 14건은 전부 참가
가능성이 남아 있던 후보의 확인 완료였다. 제외 조건을 확인해 정리한 사례는 없었다.
따라서 이 수치만으로 제외 후보 정리 능력까지 평가했다고 볼 수 없다.

한 환자에게 연결한 시험 다섯 건을 먼저 묶어 질문 전후를 비교했다. 환자 30명을 통계
단위로 보면 시험 상태 일치율은 평균 9.33%포인트 증가했다. 질환 구성을 유지한 환자
단위 5,000회 재추출의 95% 범위는 6.00~12.67%포인트였고, 개선 14명·동일 16명·악화
0명이었다. 이 범위는 합성 환자 구성에 대한 민감도이며 실제 환자 집단의 효과 범위가
아니다.

한 건 이상 정리된 환자는 평가에 넣은 10개 질환 모두에서 최소 한 명씩 나왔다. 특정
질환 한 곳에만 결과가 몰리지 않았음을 확인하는 범위 정보이며, 처음 보는 질환으로 같은
효과가 이어진다는 뜻은 아니다.

### 1.3 어떤 정보를 먼저 물었는가

현재 규칙은 그 순간 미확정 시험과 조건에 많이 연결된 정보를 우선한다. 비교 기준은
환자에게 남아 있는 정보의 가능한 순서를 모두 실행한 평균이다. 정보가 네 개 남아 있으면
24개 순서를 전부 계산하므로 무작위 추출 오차가 없다.

| 한 번 확인한 뒤의 결과 | 가능한 순서 전체 평균 | 현재 규칙 |
|---|---:|---:|
| 시험 상태 일치 | 94.22% | 94.67% |
| 환자별 비교 | 기준 | 개선 1명 · 동일 29명 · 하락 0명 |

차이는 0.44%포인트였다. 질환 구성을 유지한 환자 단위 5,000회 재추출의 95% 범위는
0.00~1.33%포인트였다. 양측 정확 부호 검정의 p값은 1.0이었다. 기본 문진이 들어간
최종 자료에서는 질문 순서 자체의 우위를 확인하지 못했다.

남은 확인 횟수 0~5회를 모두 합친 곡선에서도 차이는 0.09%포인트였고 95% 범위는
0.00~0.27%포인트였다. 가능한 조합을 더 깊게 계산한 방법과 현재 규칙의 결과도 같았다.
복잡한 계획 계산을 기본값으로 둘 근거는 나오지 않았다.

### 1.4 적격·부적격 방향을 함께 본 보완 평가

기본 문진을 제공한 최종 자료의 미정 22건은 전체 정보 기준 적격 사례에만 해당했다.
따라서 `확인 완료 14건, 조건 불충족 0건`은 두 방향의 성능 차이가 아니라 평가 대상의
구성에서 나온 결과다. 이를 보완하기 위해 별도 공개 조건 자료에서 적격 복원과 부적격
정리를 함께 측정했다.

|---|---:|
| 질환 | 3개 |
| 공개 임상시험 | 15건 |
| 구조화한 조건 | 80개 |
| 자료 제작·조정 합성 환자 | 10명 |

### 5.1 TREC 후보 검색 재현

TREC Clinical Trials 2021·2022에는 환자 설명과 관련 임상시험에 대한 전문가 표시가
있다. TrialGPT가 공개한 BM25와 MedCPT 순위 결합을 같은 자료에서 다시 실행했다.

| 자료 | 시험 문서 | 전문가가 관련 있다고 표시한 시험을 상위 500개 안에 남긴 비율 |
|---|---:|---:|
| TREC 2021 | 26,149건 | 83.59% |
| TREC 2022 | 26,581건 | 81.55% |

TrialGPT 공개 결과와의 차이는 두 해 모두 0.1%포인트보다 작았다. 이 실험은 많은 시험
가운데 관련 후보를 검색 결과 안에 남기는 단계만 확인한다. 조건 판정, 질문과 재판정은
포함하지 않는다.

### 5.2 TrialGPT 개별 조건 자료

개발 환자와 겹치지 않는 환자 33명, 환자와 시험의 조합 64개, 조건 654개에서 질문 전
한 번의 조건 판정을 비교했다.

| 방법 | 전문가가 붙인 답 이름과 일치 |
|---|---:|
| ClarifyTrial 조건 판정 | 517/654, 79.1% |
| 공개 TrialGPT 출력 | 581/654, 88.8% |

ClarifyTrial은 기록에 직접 적히지 않은 사실을 정보 부족으로 남기는 경향이 강했다.
TrialGPT 자료의 답 이름으로 채점하면 공개 TrialGPT 출력이 더 높다. 이 자료에는 다음에
확인할 정보, 답변 뒤 상태 변화와 여러 시험의 추천 순위가 표시돼 있지 않다. 질문 전
조건 하나의 답 이름을 맞춘 결과와 현재 주 평가를 직접 비교하지 않는다.

### 5.3 프로그램 연결과 구조화 조건

- 공식 합성 환자 10명을 ClinicalTrials.gov 검색부터 결과 저장까지 실행했다. 질환
  관련성 확인을 통과한 시험 25건에서 조건 472개를 처리했다. 각 단계가 이어지는지
  확인한 기록이며 추천 정확도 수치로 쓰지 않는다.
- 개발과 겹치지 않는 공개 시험 15건, 합성 환자 25명, 환자–시험 연결 75개에 구조화
  규칙을 적용했다. 코드만 쓴 실행과 언어모델을 추가한 두 실행이 모두 75/75로 같았다.
  객관적으로 구조화한 조건에서는 모델 호출을 늘릴 이유가 없다는 구현 근거로 사용한다.
- 전체 실행에서 모델 호출 오류와 응답 형식 오류를 각각 강제로 만들었다. 두 경우 모두
  정상 `result.json`은 만들지 않았고, `execution-error.json`과 그때까지의
  `trace.jsonl`을 남긴 뒤 실행을 중단했다.
- 같은 출력 폴더에 지난 성공 결과와 실패 기록을 넣어 둔 뒤 실패를 다시 만들었다. 이전
  `result.json`은 남지 않았고, 오류 파일과 실행 기록에는 이번 시도만 저장됐다. 실패 뒤
  정상 실행에서도 지난 오류 파일이 남지 않았다.

### 5.4 실제 모델 호출 흐름 한 사례

합성 환자 `source-chronic_pancreatitis-04` 한 명과 시험 다섯 건을 `gpt-5.6-sol`

규칙으로 계산할 수 있는 조건도 조건 판단 모델에 보냈다. 개선 뒤에는 코드가 해당 조건을

합성 환자 한 사례에서 역할 배치, 사용량 기록과 구조화 규칙 우선 처리가 이어지는지 본
결과다. 정확도 향상이나 일반 처리시간의 성능값이 아니다. 추적 가능한 결과는
`docs/internal/results/presentation-evidence-v2/model_role_routing_change.csv`에 있다.

|---|---:|---:|---:|
| 검증 표시가 정상인 내용 오류 | 87.11% | 88.89% | 25/2,304관측 |
| 가린 값에 의존하는 실패 | 88.37% | 90.32% | 0/2,304관측 |

첫 조건의 한 단계도 25/2,304관측에서 잘못 확정/제외했다. 새 방법의 전체 일치율이
높아져도 잘못된 확정·제외가 없어지지 않는다. 방문을 금지하면 두 남은 예산 방법의
오류는 27/2,304관측이었다. 날짜·출처 검사는 내용의 진실성을 보증하지 않는다.
이 반례를 독립 검사로 추가했다. 여러 자료의 대조나 임상가 검토 없이 검증 표시만으로
잘못된 값을 알아낼 수 있다는 주장은 기각한다.

값에 의존하는 실패에서 차이는 +1.95%p(95% 범위 +1.30~+2.60)였지만 한 가지
중심화한 합성 결측 기전에만 해당한다. 일반적인 비무작위 결측에 강건함을 입증하지 않는다.

선택한 조건 밖의 원문을 잃지 않도록 각 시험에 `scope`를 추가했다. 포함한 원문 위치를
정확히 대조하고, 나머지 비어 있지 않은 원문 행 번호를 모두 남긴다. 행에는 제목과 설명도
있어 미지원 임상 조건 수로 부르지 않는다. 모든 시험의 `full_protocol_confirmation_allowed`는
`false`다. 부분조건의 충족이 전체 프로토콜 확인으로 바뀌지 않도록 범위를 명시했다.
이 메타데이터 외에 기존 평가의 시험·조건·값·분할이 바뀌지 않았음을 확인했다.
추가 경계값·내용 오류 반례·원문 범위 검사를 포함한 새 대상 31개는 로컬에서 0.31초에
통과했다. 앞선 40/56개와 겹치므로 통과 수를 단순히 합하지 않는다.

## 10. 범위·대안·예외를 보존한 원문 확장 — 탐색 분석 완료

같은 48개 시험과 기존 분할을 유지하면서 평가 쪽 원문을 더 읽었다. 새 독립 시험 검증이
아니며 이전 결과를 본 뒤 범위를 넓힌 탐색 분석이다. 개발 쪽은 24건·비교식 30개,
평가 쪽은 24건·비교식 93개다. 이 93개에는 같은 사실의 여러 경계값과 이진 임상 표지의
반복 비교가 포함된다. 독립된 임상 조건 93개로 세지 않는다. 조건 하나만 다룬 평가 시험은
19건에서 8건으로 줄었다. 연구자가 원문에서 선언한 30개 논리 묶음을 추가했다.

자료는 `data/paper_source_benchmark_v2/protocol_subsets.json`, 선언과 변환은
`scripts/build_paper_protocol_extensions.py`에 있다. 범위, 세 갈래 신장 기능 대안,
LVEF에 따른 NT-proBNP 기준, 간 전이에 따른 ALT/AST 예외를 모두/하나 이상 관계로
보존했다. 제외 조건 묶음은 드모르간 법칙에 맞춰 잎의 의미와 연결 연산자를 함께
뒤집었다. 혈압은 진료실과 가정 측정을 다른 정보로 유지했다. 이진 표지는 합성 값이며
실제 임상가가 주석한 환자 진단이 아니다.

원문에는 ‘조절되지 않는 당뇨’라는 설명과 `HbA1c <8.5%`가 함께 있는 사례가 있었다.
이를 `>8.5%`로 고치지 않고 해석 보류로 남겼다. ALT/AST의 슬래시 축약, 직접 빌리루빈
정상 여부의 대안도 임의로 둘 다 충족 또는 생략으로 바꾸지 않았다. 부호·값과 혈구 수의
단위 변환을 대조하는 방어 코드를 추가했지만, 이 코드는 대상·시점·개념 연결의 의료적
정확성을 판정하는 NLP 검증기가 아니다. 자유 문장 자동 구조화 성능도 측정하지 않았다.

원문 행에 수치가 포함됐다는 이유로 그 행의 모든 임상 의미를 지원한다고 표시하지
않도록 범위 표시에 ‘일부만 표현한 행’을 추가했다. 시간·단계·방법·치료력 등 같은 행의
다른 의미가 남을 수 있으며 전체 프로토콜 확인은 계속 허용하지 않는다.

### 계산과 비교

확장된 특징에서 합성 벡터를 다시 생성했다. 288개 기본 벡터와 값 분포 변형, 두 가림,
방문 0/1, 예산 1/2/3, 다섯 비교군, 여섯 품질·분포 설정의 **103,680회**를 실행했다.
이전 버전과 특징·환자 값·조건의 범위가 달라 점수를 직접 증감으로 비교하지 않는다.
개발 합성 특징의 주변분포와 경로 성공률 가정은 같은 방식으로 설정했다.

같은 사실의 값들이 모든 공개 비교식에서 같은 결과를 만들면 확률을 합쳐 계획에서만
같은 가지로 묶었다. 실제 반환값과 판정 엔진의 입력은 원래 값을 유지했다. 이 축약은
독립 주변분포·값에 무관한 경로 실패라는 **계획 모형 안의** 기대값을 보존한다.
실제 생성기의 상관이나 값 의존 실패에서 최적성이 보장된다는 뜻이 아니다. 기본 옛
실행에는 축약을 자동 적용하지 않고 `--compact-planning`으로 선택한다.

### 시험별 차이와 재표집 단위

저장한 행동 기록에서 관측을 재구성하고 원문 비교식을 별도로 계산해 기존 집계와
일치하는지 확인했다. 불완전한 답·방문 허용에서 새 방법은 24개 시험 중 7개에서 개선,
15개에서 같음, 2개에서 하락했다. `NCT07214376`은 -22.92%p인 반면 같은 검색 층의
`NCT07188805`와 `NCT07490067`은 +19.79%p와 +18.75%p였다. 여러 시험의 확인 수를
최대화하면 특정 복잡한 후보의 확인은 줄일 수 있었다.

환자·시험 교차 배열의 행과 열을 따로 뽑는
[Owen의 pigeonhole bootstrap](https://doi.org/10.1214/07-AOAS122)을 참고해, 검색 층을
유지한 채 환자와 시험을 각각 5,000회 재표집하는 추가 민감도를 계산했다. 두 가림은
먼저 환자–시험 셀에서 평균냈다. 새 방법과 한 단계의 전체 차이 범위는
**-1.69~+4.38%p**로 0을 포함했다. 시험 하나씩을 뺀 평균 차이는 +0.68~+2.54%p였다.

이는 원래 네 후보를 대상으로 선택한 행동을 고정하고 결과 배열의 가중치를 바꾼
민감도다. 재표집한 시험 목록에서 질문 선택을 다시 실행하지 않았다. 층당 시험도 네 건이며
시험은 무작위 모집단 표본이 아니다. 새 시험 집합의 성능 구간이나 임상 모집단의
빈도론적 포함률을 검증한 것으로 해석하지 않는다. 환자만 뽑은 양의 구간으로 다른
시험에도 우수하다고 결론내릴 수 없다는 판단을 보강한다.

## 11. 자유 문장 준비의 논리 보존 — 구성요소 평가, 2026-10-23

### 재현한 문제와 수정

실제 `structure_trial_protocol`에 `eGFR >=30 ... or HbA1c <7%`를 포함 조건 두 개로
넣으면 기존 코드는 둘 다 필수로 생성했다. eGFR 50·HbA1c 8인 합성 사례는 OR를
만족하지만 제외됐다. 같은 술어를 AND로 묶은 제외 조건에서도 한 가지만 만족하는
사례가 제외됐다. 이 재현은 수동 모델 제안을 사용했으며 언어모델의 발생 오류율이 아니다.

지역 `criterion_key`와 원문 인용의 `logic_groups`를 제안 계약에 추가했다. 논리 제안은
제외 조건을 미리 부정하지 않은 원문 술어다. 코드가 참조·포함 범위를 확인하고 지원하는
문법에서 관계를 다시 읽어 포함/제외 의미를 적용한다. AND/OR, 명시한 괄호, 평평한
최소 개수 목록, 같은 측정의 범위와 ECOG 열거를 지원한다. 모델 관계가 원문과 다르면
지원 문법의 원문을 따른다. 모호한 혼합·미표현 IF·예외·숫자 하나에 흡수된 임상 조건은
지원하지 않는다. 임의 임상 문장의 의미나 누락된 독립 조건을 증명하는 파서는 아니다.

다른 수치의 비교 부호를 빌리는 검증, `mg/dL`를 `g/dL`로 인정하는 부분 문자열 검증과
체표면적 보정 여부의 혼동도 수정했다. 기존 캐시가 목록 기반 결과를 재사용하지 않도록
검증 버전을 `trial-protocol-source-logic-v7`로 올렸다.

### 자료와 평가 단위

### 선택과 참고 해석

합성 문장에 맞춘 지원 문법의 결과를 공개 문구에 그대로 적용할 수 있는지 검사했다.

고정했다. 결과를 이미 보았던 시험·저자 선언을 다시 쓰는 탐색 연구이며 새 독립 NLP

만들었다. 값은 각 경계와 그 위·아래, 누락에서 생성했다. 큰 두 묶음은 고정 난수로

아니다. 따라서 아래 불일치를 실제 환자의 오판 건수로 부르지 않는다.

환자 측 개념 표기는 모델 실행 전에 명시적으로 고정했다. 문맥·개념·단위가 맞지 않으면
기존 엔진이 보류한다. 정답을 맞추려고 모델 응답을 본 뒤 개념명을 바꾸지 않았다.
