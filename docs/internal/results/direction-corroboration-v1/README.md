# 조건별 결론 대조 — 탐색 연구 완료

2026-10-23. 같은 공개 시험 부분조건 24건·93개 비교식, 합성 기본 벡터 288개·두 가림을
재사용했다. 새 외부 환자군·독립 임상 주석이 아니다. 확인 3회·방문 최대 1회에서
오류 확률 .05/.15 × 독립/완전 공유 × 5방법의 **11,520회** 재생이다. 각 설정의
시험 관측 분모는 2,304, 실제 방문은 576개 환자–가림 설정의 합계다.

## 바꾼 질문과 방법

정확한 값 50/55는 다르지만 `>=30`의 결론은 같다. 값을 하나로 합치거나 참값을 고르지
않고, 두 보고가 같은 조건을 지지/위반할 때 그 조건만 정리한다. 같은 쌍도 `>=52`는
미정이다. 일반 날짜·출처·검증·단위, 명시한 측정 범위·자료원 계열과 현재 충돌 검사는
유지한다. API의 기본값은 기존 정확한 값 대조이고 방향 대조는 명시해서 쓰는 연구 기능이다.

기존 고정 오류 변환은 두 자료가 모두 틀리면 같은 값으로 틀린다. 후속 실험은 오류 시
참값을 제외한 다른 격자 값을 균등하게 뽑았다. 두 자료의 서로 다른 오답도 허용한다.
공유 조건에서는 오류 발생과 잘못된 값 모두 공유한다. 실제 오류 확률·의료적 분포나
자료원 독립성을 추정한 모형이 아니다. 초기에는 올바르게 대조된 두 기록을 주고 새
획득에만 오류를 넣었다. 앞의 고정 변환 결과와 점수를 직접 잇지 않는다.

- `trust_first`: 기존 실패 고려 남은 예산 계획으로 첫 충분한 보고를 사용한다.
- `exact_sources`: 독립 보고 채널을 아는 계획으로 두 값이 정확히 같을 때만 사용한다.
- `direction_same_trace`: 바로 위와 **완전히 같은 행동·반환**에서 조건별 결론만 비교한다.
- `direction_two_step`: 방향 대조를 아는 두 단계 선택을 매번 다시 실행한다.
- `direction_sources`: 방향 대조를 아는 남은 예산 전체 선택이다.

첫 기록은 내용 오류 채널을 모형화하지 않는다. 따라서 첫 기록 대비는 확인 정책과 정보
모형이 함께 다른 비교다. 대조 방식 간에는 같은 독립 오류 사전과 개발 분포를 제공한다.
공유 오류 설정은 계획기의 독립 가정을 위반하는 스트레스다. 참값·오류 플래그·미래 답은
선택기에 전달하지 않았다. 완료한 보고 쌍은 두 값을 보존하며 술어별 방향만 계산한다.

## 결과

표의 각 칸은 **올바른 상태 / 잘못된 결론**의 수다. 미정은 둘에 포함하지 않았다.
초기 올바른 상태 729개는 모든 방법에 공통으로 포함되므로 새 결론의 오류 비율도 별도 기록했다.

| 오류 설정 | 첫 기록 | 정확한 값 | 같은 행동·방향 판정 | 방향·두 단계 | 방향·남은 예산 |
|---|---:|---:|---:|---:|---:|
| 독립 .05 | 1,886 /26 | 1,294 /0 | 1,324 /0 | 1,323 /0 | 1,323 /0 |
| 완전 공유 .05 | 1,887 /38 | 1,354 /25 | 1,354 /25 | 1,357 /26 | 1,355 /25 |
| 독립 .15 | 1,829 /84 | 1,205 /2 | 1,271 /2 | 1,271 /2 | 1,273 /2 |
| 완전 공유 .15 | 1,820 /116 | 1,317 /66 | 1,317 /66 | 1,325 /69 | 1,320 /65 |

독립 .05의 같은 행동 비교는 +30개=+1.30%p(환자 단위 95% 부트스트랩 .69–2.08),
방향 재계획은 정확한 값 대비 +29개=+1.26%p(.65–2.04)였다. 환자·시험 교차 재표집
민감도는 각각 .48–2.34, .22–2.47%p다. 시험은 목적 표집한 고정 목록이므로 이 범위를
임상 모집단의 일반화 구간으로 부르지 않는다. 독립 .15의 재계획 차이는 +68개=+2.95%p,
환자 범위 2.04–3.99, 교차 민감도 .95–5.43%p였다.

실제 방문은 독립 .05에서 정확한 값/같은 행동 420회, 방향 두 단계 428회, 남은 예산
393회였다. 행동은 각각 1,294/1,294/1,244/1,261회다. 첫 후보 기회 324개 중 새로
확인한 수는 정확한 값 175, 같은 행동 186, 두 단계/남은 예산 189개였다.

방향 재계획은 같은 행동 판정보다 독립 .05에서 올바른 상태가 **한 개 적었다**. 두 단계와는
총수가 같았다. 독립 .15에서는 각각 두 개 늘었고, 완전 공유 .15에서는 두 단계보다 다섯 개
적었다. 깊은 계획의 일반 우위나 비열등성을 주장하지 않는다. 주된 확인량 차이는 판정
기준에서 나왔고 재계획은 부담·첫 후보·후보별 결과를 바꿨다.

![조건 방향 대조의 확인·오류·방문](direction_tradeoff.png)

완전 공유 .05에서 새 결론 중 오류의 비율은 첫 기록 38/1,196=3.18%, 방향 남은 예산
25/651=3.84%였다. 오류 총수가 적다는 것과 새 결론의 오류 비율이 낮다는 것은 다르다.
독립 .15에서도 오판 두 개가 남았다. 같은 행동에서 방향 기준만 완화한 비교는 이 표본에서
오판을 추가하지 않았으나, 이를 안전성 보장으로 사용하지 않는다. 검사에 넣은 별도 반례는
참값 50을 20/25로 잘못 보고하면 `>=30`을 둘 다 잘못 위반으로 판단한다. 정확한 값
대조는 보류하고 방향 대조는 받아들인다. 따라서 이 완화는 원리적으로 위험이 추가될 수 있다.

## 계산과 재현

모든 재생에서 별도 원문 행·트리 채점, 계획용 보고 쌍과 실제 근거 가드/판정 결과를
대조했다. 행동 고정 비교는 전체 trace가 같은지도 확인했다. 관련 검사 **105개 통과**에는
메타데이터·계열·범위, 제외 조건, 현재 충돌, 조건별 다른 보류, 비균등 주변분포에서
잠재 값·두 보고의 완전 열거와 계획 기대값 대조, 기존 고정 채널 정책의 보존을 포함한다.

서버 `exitguide-n100`에서 작업에만 `MemoryMax=2G`, `CPUQuota=100%`를 적용해 실행했다.
종료 코드 0, 경과 6분 00.47초, 최대 RSS 189,144KiB(약 185MiB)였다. 무관한 서비스는
유지했고 현재 실행 중인 연구 계산은 없다. 로컬에서는 가벼운 검사와 표·그림을 생성했다.

```powershell
python scripts/run_direction_corroboration_research.py --output runs/direction-corroboration --patients 48 --resamples 5000 --error-probabilities .05 .15 --channel uniform_wrong
python scripts/plot_direction_corroboration_research.py --results runs/direction-corroboration
```

합성 환자의 두 가림을 묶고 여섯 검색 층을 유지해 5,000번 재표집했으며, 파생 관측을
새 환자로 더하지 않는다. 교차 재표집은 원래 행동을 고정한 가중치 민감도다.
