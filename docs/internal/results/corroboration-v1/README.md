# 자료원 대조의 오류와 확인 비용 — 탐색적 합성 연구

2026-10-23 실행. 같은 평가 시험 24건의 부분 표현, 합성 벡터 288개·두 가림을 재사용한다.
모든 참값·기록·자료원 식별·오류·방문은 합성이다. 두 자료원 확인은 연구용 검토 정책이며
시험 원문이 요구하는 임상 표준이 아니다. 초기 기록은 이미 올바르게 대조된 것으로
두고, 새로 얻는 기록에만 오류를 넣었다. 전체 임상 적격이나 실제 비용을 측정하지 않았다.

주 비교 55,296회, 오류 변경 폭 민감도 55,296회를 실제 근거 처리·별도 참고 식·계획
상태와 대조했다. 고정 원문·환자에 조건부인 탐색 평가다. 결과 기준은
[검증 결과 13절](../../CLARIFYTRIAL_VALIDATION_RESULTS.md)이다.

| 오류 설정 | 첫 기록의 일치 / 오류 | 자료원 대조·남은 예산의 일치 / 오류 | 실제 방문: 첫 기록 / 대조 | 새 첫 후보: 첫 기록 / 대조 |
|---|---:|---:|---:|---:|
| 독립 | 81.60% /29 | 56.16% /0 | 403 /392 | 299 /174 |
| 절반 공유 | 81.51% /33 | 57.12% /12 | 405 /392 | 299 /181 |
| 완전 공유 | 81.64% /43 | 58.59% /27 | 400 /395 | 297 /187 |
| 복사된 자료원 | 81.64% /43 | 31.64% /0 | 400 /0 | 297 /0 |

확인 3회·방문 최대 1회 기준이다. 상태의 분모는 2,304, 방문은 576개 환자–가림 설정,
새 후보 기회는 324설정이다. 독립 설정의 잘못 확정/제외는 첫 기록 15/14, 대조 0/0이었다.
완전 공유의 대조에서도 7/20개가 남았다. 관측된 0을 위험이 없다는 증명으로 쓰지 않는다.

새로 내린 결론만 보면 독립 첫 기록은 29/1,180=2.46%, 대조는 0/565가 잘못됐다.
완전 공유에서는 첫 기록 43/1,195=3.60%, 대조 27/648=4.17%였다. 오류 총수가 줄어도
새 결론 중 오류 비율은 높아질 수 있다. 복사본 대조는 새 결론이 없어 이 비율을 0으로
쓰지 않는다. `risk_coverage.csv`에 같은 분모와 비율을 보존했다.

파일 수만 세면 복사본에서도 58.59%·오류 27개를 ‘대조’로 인정했다. 자료원 계열을
구분하면 새 정보를 얻을 다른 경로가 없어 추가 행동을 중단했다. 31.64%는 처음부터
정리된 729관측이며 새로 확인한 성과가 아니다. 대조의 효과와 보류·경로 부재를 구분한다.

자료원 두 단계 선택의 독립 결과는 56.21%·오류 0·방문 401·행동 1,317회였다. 남은
예산 계획은 56.16%·오류 0·방문 392·행동 1,332회였다. 더 깊은 계획의 보편적 우위를
보이지 않았다. `source_budget_bounds.csv`의 독립 사후 상한은 1,361/2,304=59.07%,
실제는 1,294개로 차이는 67개다. 상한은 미래 답·참값을 사용한 사후 채점이며 선택기에
전달하지 않았다. 한 행동이 한 경로의 반환 하나인 모형에서, 두 보고가 필요한 새 정보는
세 행동 안에서 최대 하나만 대조할 수 있다. 여러 자료를 한 번에 받는 경로는 모델링하지 않았다.

합성 자료원 오류 확률은 각 5%, 충분한 기록 확률은 0.70/0.95다. 공유 스위치로 오류
상관을 0/0.5/1로 만들되 주변 오류율은 기대상 같게 했다. 오류값은 두 칸 이동하고,
이동이 항등이 되는 이진 격자에서는 한 칸 이동한다. 동일 오류가 같은 잘못된 값으로
나오는 이 모형에서 두 값 일치 후 오류 확률은 독립 0.28%, 절반 공유 2.76%, 완전 공유
5%다. 이 값은 자료원 값 수준의 수학적 조건부 확률이며 위 시험 판정 오류율이 아니다.

한 칸 이동 민감도에서는 대조 오류가 독립 0, 완전 공유 11개였다. 같은 5% 빈도라도
오류값의 변환 방식이 결과를 바꿨다. 첫 번째 오류 주입의 이진 항등 문제도 고쳐 기존 연구를
17,280회 재실행했다. 그 고정 코호트에는 실제로 선택된 이진 오류 반환이 없어 기존
집계 30행은 모두 같았다. 이전 원시 결과를 덮어쓰지 않았다.

`summary.json`·`policy_metrics.csv`는 주 비교, `shift1_*`는 변경 폭 민감도,
`corrected_error_*`는 기존 오류 실험의 수정 실행이다. `examples.json`은 사후에 고른
공유 오류·복사본의 합성 반례, `agreement_identity.json`은 정의한 오류 모형의 항등식이다.
원시는 `runs/corroboration-shift2-20261023/`, `runs/corroboration-full-20261023/`,
`runs/paper-value-error-fixed-20261023/`에 있다. 고정 source/scope ID가 실제 독립성을
보장하지 않으며 실제 측정의 변동·자료원 품질을 추정하지 않았다.

첫 기록 비교군은 내용 오류를 모형화하지 않는 기존 정책이다. 대조 계획은 명시한
합성 오류 확률도 쓰므로 확인 규칙과 정보 모형이 함께 다른 비교다. 두 단계/남은
예산 대조는 같은 정보·규칙 아래의 선택 방법 비교다.

`questions` 열은 대조 API가 생성한 자료원 질문의 진단 수다. 첫 기록 전략의 전체 문진
질문을 측정한 열이 아니므로 방법 간 문진 부담으로 비교하지 않는다. 실제 선택한 경로
시도와 방문을 부담 지표로 썼다.

## 재현

```powershell
python scripts/run_corroboration_research.py --output runs/corroboration --patients 48 --resamples 5000 --error-shift 2
python scripts/run_corroboration_research.py --output runs/corroboration-shift1 --patients 48 --resamples 5000 --error-shift 1
python scripts/run_paper_acquisition_research.py --source data/paper_source_benchmark_v2/protocol_subsets.json --output runs/corrected-error --patients 48 --bootstrap 5000 --settings verified_value_error --compact-planning
python scripts/analyze_corroboration_research.py --run runs/corroboration --sensitivity runs/corroboration-shift1 --corrected runs/corrected-error --output runs/corroboration-analysis
python scripts/plot_corroboration_research.py --results runs/corroboration-analysis
```

비교 계산은 기존 서버에서 작업별 메모리 2GiB·CPU 한 코어 상한으로 실행했다. 초기
기록의 오류, 생리적 변화, 실제 품질 추정·임상가 검증·전체 자유 문장 흐름은 이 평가
범위가 아니다. 연구용 선택과 실제 앱의 기본 판정 정책을 구분한다.

이 결과는 의학적 조언이 아닌 참고용입니다. 임상시험 참가 가능성은 해당 시험의 최신 기준과 전체 자료를 바탕으로 다시 확인해야 합니다.
