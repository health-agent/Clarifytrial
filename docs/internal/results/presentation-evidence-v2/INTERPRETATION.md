# 질문 순서 확대 실험 해석

평가 대상은 이미 정해진 부족 정보 가운데 무엇을 먼저 확인할지 고르는 순서다. 임상 판단 정확도는 이 실험에서 재지 않았다.
공개 환자 사례, 공개 조건 값 전수 계산, 합성 연결 구조 실험은 서로 다른 자료이므로 결과를 합쳐 하나의 점수로 만들지 않는다.

## 발표 주 결과: 세 기본 항목을 받은 뒤 질문 1회

환자-시험 조합 150개 가운데 처음에 결론이 나지 않은 조합은 22건이었다. 질문 한 번 뒤 14건(63.6%)이 정리됐다. 참가 조건 충족으로 정리된 시험은 14건, 조건 불충족으로 정리된 시험은 0건이었다.
환자 14/30명에서 한 건 이상 정리됐고, 새로 잘못 확정된 시험은 0건이었다.
한 건 이상 정리된 환자는 평가에 포함한 질환 10/10개에서 나왔다. 한 질환에만 몰린 결과가 아니었음을 확인하는 범위 정보이며 새 질환으로의 일반화 근거는 아니다.
실제로 선택한 질문 14건의 구성은 검사 수치 2건, 과거 수술·치료 3건, 의료기관 등록 조건 1건, 증상 빈도·환자 기록 1건, 진단·병리 조건 7건이었다.
이 보조 설정에서는 나이·임신 또는 수유·활동성 감염을 먼저 제공하면서 제외될 시험이 시작 단계에서 모두 정리됐다. 따라서 남은 미확정 시험은 미리 만든 전체 환자 상태에서 참가 조건을 충족하는 후보였고, 14건은 이 자료 구성에서 확인된 전이지 실제 환자 집단의 참가 증가율이 아니다.
14/22는 세 기본 항목을 먼저 제공하고도 남은 22건에서 질문, 답 반영과 재판정이 이어지는지 본 값이다. 숫자 범위를 계산할 때는 환자 30명을 한 명씩 세었고, 한 환자의 시험 다섯 건을 환자 다섯 명처럼 세지 않았다.
환자 안의 시험 다섯 건을 먼저 묶어 비교한 상태 일치율 증가는 +9.3%p였다. 환자 구성을 다시 뽑은 95% 범위는 +6.0%p~+12.7%p였고, 개선 14명, 동일 16명, 악화 0명이었다.

### 질문 순서 자체의 추가 차이

나이·임신 또는 수유·활동성 감염을 시작 자료에 모두 넣은 뒤 남은 정보만으로 한 번 더 확인했다.
확인 1회 결과는 가능한 순서 전체 평균 94.2%, 영향 우선 94.7%였다. 차이는 +0.4%p (95% 범위 +0.0%p~+1.3%p, 개선 1명, 동일 29명).
추가 확인을 하지 않으면 85.3%였다. 세 기본 항목을 받은 뒤에도 질문 한 번으로 남은 판단을 더 정리했지만, 어떤 질문을 먼저 고르는지에 따른 차이는 작았다.
확인 0~5회 전체 곡선 차이는 +0.09%p였다. 선택한 공개 조건에서는 세 기본 확인 항목이 주효과의 대부분을 설명했다.

## 민감도 분석: 처음에 정보를 넓게 가린 조건

나이·임신 또는 수유·활동성 감염까지 일부러 가린 10개 질환 합성 환자 50명에서 확인 순서를 비교했다.
- 가능한 모든 순서의 평균: 0회 18.7%, 1회 40.2%, 2회 61.2%, 3회 83.3%, 4회 92.7%, 5회 100.0%.
- 파일에 적힌 순서: 0회 18.7%, 1회 62.7%, 2회 85.3%, 3회 94.0%, 4회 99.3%, 5회 100.0%.
- 여러 시험에 함께 필요한 정보 우선: 0회 18.7%, 1회 76.7%, 2회 88.0%, 3회 95.3%, 4회 99.3%, 5회 100.0%.
- 남은 확인 횟수 전체를 계산: 0회 18.7%, 1회 76.7%, 2회 88.0%, 3회 95.3%, 4회 99.3%, 5회 100.0%.

같은 평가용 환자 30명의 확인 기회 0~5회 곡선을 먼저 합친 대응 비교:
- 여러 시험에 필요한 정보 우선, 같으면 확인 부담 비교 대 가능한 정보 순서 전체 평균: +16.4%p (95% 범위 +12.8%p~+20.0%p).
- 여러 시험에 필요한 정보 우선, 같으면 확인 부담 비교 대 입력 순서: +3.6%p (95% 범위 +2.0%p~+5.2%p).
- 앞으로 확인할 정보 조합 계산 대 여러 시험에 필요한 정보 우선, 같으면 확인 부담 비교: +0.0%p (95% 범위 +0.0%p~+0.0%p).

확인 기회가 한 번일 때 시험 5개 중 판단을 끝낸 수는 영향 우선 3.83개, 무작위 순서 2.01개였다.
처음부터 판단할 수 있었던 시험을 빼면 실제 확인 한 번으로 새로 정리된 시험은 각각 2.90개와 1.07개였다.
처음 정보를 넓게 숨긴 조건에서 확인 횟수 상한을 5회로 두자 두 방식 모두 시험 5개의 판단을 끝냈다. 영향 우선은 평균 2.07회에 멈췄고, 가능한 순서 전체 평균은 2.77회였다 (차이 -0.70회, 환자 구성 95% 범위 -0.90~-0.53회).
- 확인 1회: 선택한 10개 질환 모두에서 무작위 순서보다 높음 (질환 방향 부호검정 p=0.001953).
- 확인 0~5회 곡선 면적: 선택한 10개 질환 모두에서 무작위 순서보다 높음 (질환 방향 부호검정 p=0.001953).
질환별 방향은 선택한 10개 질환 안의 민감도 점검이며, 새 질환이나 새 시험군으로의 일반화를 뜻하지 않는다.

주평가에서 현재 규칙이 30명 중 29명에게 나이를 먼저 확인했으므로, 나이를 처음부터 제공한 같은 환자들로 민감도 분석을 했다.
남은 정보 한 번을 확인했을 때 무작위 순서는 84.6%, 영향 우선은 88.0%였다. 차이는 +3.4%p (환자 구성 95% 범위 +1.1%p~+6.1%p, 개선 5명, 동일 25명, 악화 0명).
나이를 먼저 제공한 뒤에도 5명에서 차이가 남았지만 평균 차이는 +3.4%p로 줄었다. 주평가의 큰 차이는 공통 나이 항목의 영향을 많이 받았다.

이 수치는 공개 시험의 일부 구조화 조건과 합성 환자로 질문 순서만 검사한 값이며 임상 성능이 아니다.

## 기본 질문 순서 결정

현재 영향 범위만 따르는 방식과, 영향 범위가 같을 때 확인 부담까지 보는 방식을 비교했다.
- 공개 조건 값 전수 계산: 1회 회복 -1.25%p, 합성 확인 부담 점수 8.4% 감소; 2회 회복 -0.62%p, 합성 확인 부담 점수 5.4% 감소; 3회 회복 +0.22%p, 합성 확인 부담 점수 3.6% 감소.
- 합성 연결 구조 1,800개: 1회 회복 -0.19%p, 합성 확인 부담 점수 16.5% 감소; 2회 회복 +0.01%p, 합성 확인 부담 점수 23.6% 감소; 3회 회복 -0.06%p, 합성 확인 부담 점수 16.0% 감소.
회복 차이는 예산에 따라 방향이 바뀌었고 합성 연결 구조에서는 0.2%포인트 안이었다. 확인 부담은 모든 횟수에서 낮았으므로, 영향 범위를 먼저 보고 점수가 같을 때 부담을 가르는 규칙을 기본값으로 둔다.
숨은 답 분포를 쓰지 않고 앞으로 확인할 정보 조합을 계산하는 방법과 개발자료의 답 분포를 쓰는 의사결정나무는 비교·연구용 선택지로 남긴다.
