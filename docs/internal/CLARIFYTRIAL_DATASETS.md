# ClarifyTrial 실험자료 구성

기준일: 2026-08-25

## 1. 자료 전체 관계

```text
공개 임상시험 문서
→ 관련 시험 검색 자료
→ 조건별 판단 자료
→ ClarifyTrial용 합성 환자와 숨긴 정보
→ 질문·답변·재판정 평가
```

각 자료는 서로 다른 문제를 평가한다. 검색 자료의 관련성 정답을 참가 조건 정답으로
사용하지 않고, 조건 판단 자료를 질문 정답으로 변환하지 않는다.

## 2. 자료별 역할

| 자료 | 입력 | 정답 | ClarifyTrial에서의 역할 |
|---|---|---|---|
| TREC Clinical Trials 2021·2022 | 환자 설명과 수만 건의 시험 | 환자와 시험의 관련성 | 관련 시험 검색 |
| TrialGPT Criterion Annotations | 환자 기록과 시험 조건 | 조건별 판단과 근거 | 한 번의 조건 판단 |
| ClinicalTrials.gov | 실제 시험 원문 | 공식 정답 없음 | 조건 원문과 모집 상태 |
| ClarifyTrial 합성 환자 | 구조화 환자 상태와 가린 정보 | 질문 뒤 시험 상태 | 질문·재판정 |
| 환자 부담 합성 상황 | 확인 방법과 환자 제한 | 허용 경로와 선택 결과 | 확인 방법 선택 |
| 팀 공개 시험 1,931건 | 여러 질환의 시험 원문 | 환자-시험 정답 없음 | 넓은 후보 검색 |

## 3. TREC Clinical Trials 2021·2022

TREC 자료에는 환자 설명, 임상시험 ID와 전문가 관련성 등급이 있다. ClarifyTrial은
TrialGPT가 사용한 BM25와 MedCPT 검색 결과를 합쳐 관련 시험이 검색 결과에 남는지
평가한다.

| 항목 | 2021 | 2022 |
|---|---:|---:|
| 시험 문서 | 26,149건 | 26,581건 |
| 평가 깊이 | 상위 500개 | 상위 500개 |
| 결합 검색 관련 시험 유지 | 83.59% | 81.55% |

TREC는 질문·답변 자료가 아니다. 처음에는 보이지 않다가 질문 뒤 공개되는 환자 정보,
알맞은 질문과 종료 시점 정답이 없다.

## 4. TrialGPT 조건 판단 자료

- 조건 행: 1,015개
- 환자: 53명
- 환자-시험 조합: 105개
- 임상시험: 103개

각 행에는 환자 기록, 참가 조건, TrialGPT 판단, 전문가 판단과 근거가 있다. 선정 조건과
제외 조건을 각각 `충족`, `미충족`, `정보 부족`으로 평가할 수 있다.

이 자료는 한 번의 조건 판단을 평가한다. 질문 뒤에 나올 환자 답, 어떤 정보를 먼저
물어야 하는지, 확인 방법과 환자 부담 정답은 포함하지 않는다.

## 5. ClinicalTrials.gov 원문

### 개발용 조건

- 질환: 제2형 당뇨병, 유방암, 주요우울장애
- 공개 시험: 15건
- 구조화 조건: 80개
- 용도: 조건 표현, 질문 정책과 코드 개발

### 현재 평가용 조건

- 공개 시험: 15건
- 구조화 조건: 92개
- 질환별 시험: 5건
- 기존 개발 시험과 중복: 0건
- 용도: 별도 합성 환자의 질문·재판정 평가

조건에는 원문 시험 ID, 선정·제외 구분, 수치·기간·상태, 비교 방향과 단위를 저장한다.
공식 원문과 구조화한 값이 다르면 평가자료에서 제외한다.

## 6. ClarifyTrial 합성 환자

현재 평가자료는 세 질환에서 총 60명의 합성 환자를 포함한다.

| 구분 | 환자 수 | 용도 |
|---|---:|---|
| 개발 환자 | 30명 | 조건 표현과 질문 방법 결정 |
| 별도 평가 환자 | 30명 | 방법을 고정한 뒤 결과 계산 |

환자마다 같은 임상값을 가진 두 기록을 만든다.

1. 판단에 필요한 근거가 충분한 기록
2. 값이 빠졌거나 출처·날짜·확인 상태가 부족한 기록

총 기록 상태는 120개다. 별도 평가의 중심 결과는 개발에 사용하지 않은 환자 30명의
정보 부족 기록에서 계산한다.

### 환자 한 명의 정답 구조

```text
전체 환자 사실
현재 공개할 사실
가려 둘 사실
각 사실의 자료 출처와 날짜
각 사실을 확인할 수 있는 방법
질문 뒤 공개할 답
처음 시험 판단
답을 반영한 뒤 시험 판단
```

각 시험 판단은 다음 필드로 나뉜다.

- 후보 유지 또는 제외
- 현재 확인 완료, 추가 확인 필요 또는 참가 조건 불충족
- 판단에 사용한 환자 사실과 시험 조건
- 아직 필요한 사실

## 7. 합성 환자 생성 규칙

1. 실제 공개 시험에서 객관적으로 계산 가능한 조건을 고른다.
2. 조건을 만족하거나 위반하도록 수치, 날짜와 상태를 먼저 정한다.
3. 전체 상태로 시험별 결과를 코드로 계산한다.
4. 판단에 영향을 주는 정보 일부를 가린다.
5. 가린 정보마다 가능한 확인 방법과 답을 별도 저장한다.
6. 새 정보를 넣은 뒤 예상 시험 상태를 다시 계산한다.
7. 모든 자동 검사에 통과한 사례만 평가에 사용한다.

언어모델은 정해진 상태를 문장으로 다듬을 수 있지만 상태표에 없는 수치, 날짜, 검사,
치료와 생활습관을 추가할 수 없다. 한 문장짜리 환자 설명을 늘리며 만든 허구의 생활
정보는 정답으로 사용하지 않는다.

## 8. 여러 정보가 동시에 부족한 사례

환자마다 시험 판단에 영향을 주는 정보 5개를 두고 확인 횟수를 최대 3회로 제한한다.
같은 정보가 둘 이상의 시험에 영향을 주는 사례를 포함해 질문 순서의 차이를 측정한다.

다음 두 상태를 모두 검사한다.

- 값은 보이지만 최근 날짜·출처·확인 상태가 부족함
- 핵심 값 자체가 처음 입력에서 빠짐

별도 견고성 평가에서는 환자마다 정해 둔 답 하나를 얻을 수 없게 한다. 선택한 기록이
없거나 환자가 답을 모르는 경우를 하나의 `정보를 얻지 못함` 상태로 처리하고, 같은
정보를 반복하지 않고 다음 정보로 넘어가는지 확인한다. 기록 없음과 환자 모름처럼
실패 원인을 나눈 평가는 아직 추가하지 않았다.

가려 둔 답은 질문 선택 코드에 전달하지 않는다. 질문이 실행되거나 기존 기록을
확인하는 행동이 선택된 뒤에만 합성 환경에서 공개한다.

## 9. 환자 부담 합성 상황

기존 합성 환자의 임상값은 그대로 두고 환자 상황과 자료 가용성만 바꾼다.

- 환자 상황 3개: 추가 부담이 낮음, 이동·비용 제약, 시간 긴급
- 자료 구조 2개: 기존 자료 중심, 새 확인 필요
- 정보 부족 상태 2개
- 전체 상황: 360개
- 비교 방식: 5개
- 전체 실행: 1,800회

확인 방법마다 비용 범주, 대기시간, 방문, 신체·심리 부담, 의료 위험과 승인 필요 여부를
따로 기록한다. 실제 금액이나 실제 환자 선호를 만들어내지 않는다.

## 10. 팀 공개 시험 1,931건

- 공개 위치: https://github.com/Seohvvan/Healthcare/blob/main/data/trials.jsonl
- 확인일: 2026-08-24
- 고유 NCT ID: 1,931개
- 참가 조건 원문이 있는 시험: 1,931개
- 원자료: ClinicalTrials.gov API v2
- 고정한 공개 버전: 커밋 `01b3dd9ee6ca65acd485fa686edda0a08eecc50e`
- 파일 SHA256: `95e2551741b82db9e0729e8081af85fe0de559c9cad850b41d849f315bbf889c`
- 현재 모집 중·모집 예정: 589건

이 파일은 후보 검색 범위를 넓히는 데 사용한다. 환자-시험 관련성 정답, 조건별 판단
정답과 질문 정답은 없다. 프로그램은 `RECRUITING`, `NOT_YET_RECRUITING`,
`ENROLLING_BY_INVITATION`만 현재 후보 검색에 넣고, `COMPLETED`와
`ACTIVE_NOT_RECRUITING`은 제외한다.

수집에 사용한 질환 검색어와 정확한 원자료 시각은 파일에 들어 있지 않다. 같은 결과를
다시 만들 수 있도록 현재 공개 커밋과 파일 해시를 고정했다. 최종 결과를 낼 때는 모집
상태가 바뀔 수 있으므로 같은 NCT ID를 공식 API에서 다시 확인한다.

### 정밀 평가 후보 50건

`configs/team_trial_expansion_v1.json`에 10개 질환군과 질환 이름 변형을 정했다. 모집 가능한
589건에서 질환군마다 5건을 선택하되 다음 조건 종류가 새로 추가되는 시험을 우선했다.

- 수치 기준
- 최근 며칠·몇 달 같은 기간 기준
- 약물과 과거 치료
- 수술과 병리 결과
- 임신과 피임
- 환자가 직접 답할 수 있는 조건
- 혈액검사와 영상검사

현재 선택 결과는 50건이며 수치 기준 49건, 기간 기준 41건, 치료 조건 47건, 수술·병리
41건, 임신·피임 43건, 환자 답변 조건 48건, 검사 자료 조건 37건이 포함됐다. 이 값은
원문에 해당 표현이 있는 시험 수이며 조건별 정답 수가 아니다. 선택 결과는
`runs/team-trial-expansion/selection.json`에 저장된다.
