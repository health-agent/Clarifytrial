# ClarifyTrial 실험자료 구성

기준일: 2026-08-25

## 1. 자료가 맡는 문제

| 자료 | 무엇을 평가하는가 | 들어 있지 않은 정답 |
|---|---|---|
| TREC Clinical Trials 2021·2022 | 수만 건에서 관련 시험 검색 | 참가 조건 판단, 질문 순서 |
| TrialGPT Criterion Annotations | 환자 기록과 시험 조건 하나의 판단 | 질문 뒤 답, 확인 방법과 종료 시점 |
| 팀 공개 시험 1,931건 | 여러 질환의 현재 후보 검색 | 환자–시험 참가 가능 정답 |
| 공개 시험 조건 기반 합성 평가자료 | 후보 보존, 정보 선택, 답변 반영과 재판정 | 실제 등록과 치료 결과 |
| 환자 부담 합성 상황 | 이동·비용·시간에 따른 확인 방법 | 실제 금액과 실제 환자 선호 |

검색 자료의 관련성 정답을 참가 조건 정답으로 사용하지 않는다. TrialGPT 조건 답을
질문 순서 정답으로 바꾸지도 않는다.

## 3. 공개 시험 조건 기반 합성 평가자료

저장 위치: `data/public_protocol_benchmark_v1/`

| 항목 | 수 |
|---|---:|
| 질환 | 10개 |
| 공개 임상시험 | 50건 |
| 구조화 조건 | 202개 |
| 복합 조건 | 3개 시험·4묶음 |
| 합성 환자 | 50명 |
| 환자–시험 조합 | 250개 |
| 개발 환자 | 20명 |
| 별도 평가 환자 | 30명 |
| 가상 환자 전체 상태에서 참가 가능 | 98개 |
| 가상 환자 전체 상태에서 참가 조건 불충족 | 152개 |

### 구조화한 조건

- ClinicalTrials.gov의 최소·최대 나이 칸
- 문장 전체가 분명한 임신·수유 및 중대한 활동성 감염 제외 조건
- 하나의 수치와 하나의 비교 방향이 분명한 조건
- 별도 해석 없이 참·거짓을 정할 수 있는 짧은 원문 조건
- 원문에서 `둘 중 하나`, `셋 중 둘`, `넷 중 둘`로 명시한 네 묶음

시험 원문 2,118개 비어 있지 않은 줄 가운데 130개 줄이 구조화 조건에 직접 연결된다.
구조화 조건은 50개 시험의 전체 참가 조건이 아니다. 예외, 시험군별 적용 범위와 여러
뜻이 섞인 긴 문장은 임의로 잘라 넣지 않았다.

각 조건에는 시험 번호, 원문 문구, 원문 줄 번호, 선정·제외 구분, 비교 방향, 수치·단위,
필요한 환자 사실과 조건 사이의 논리 관계를 저장한다.

### 합성 환자

환자마다 전체 상태를 먼저 만든 뒤 1개, 2개, 3개 또는 5개 정보를 가렸다.

```text
가상 환자의 전체 상태
→ 전체 상태에서 시험별 결과 계산
→ 미리 정한 사실 일부 가리기
→ 처음 화면의 시험별 결과 계산
→ 가린 답과 확인 방법을 별도 저장
→ 질문 뒤 예상 결과 계산
```

가린 정보는 환자 답변, 병원 기록, 기존 공식 결과와 새 비침습 검사를 포함한다. 급성
췌장염과 폐암에는 새 검사와 기존 공식 결과 경로가 실제 평가에 나타나도록 해당 사실을
미리 정한 위치에 배치했다. 이 배치는 환자 결과값과 무관하게 확인 방법 범위를 고르게
시험하기 위한 규칙이다.

여러 수치나 여러 조건이 한 문장에 섞이면 자동 수치 조건에서 제외한다. 임상값은 넓은
사람 범위 안에서 만들며, 개발 환자와 별도 평가 환자에 경계 안팎 값이 한쪽으로 몰리지
않도록 설정 파일의 값 순서를 모든 질환에 똑같이 적용한다. 전체 상태에서 참가 가능한
비율은 개발 44/100, 별도 평가 54/150으로 한쪽만 지나치게 쉬운 구성을 피했다.

질문 선택 코드에는 가려 둔 답을 전달하지 않는다. 확인 행동이 실행된 뒤에만 저장된
답을 공개한다. 답에 없는 수치, 날짜, 검사와 생활 정보를 새로 만들지 않는다.

### 두 파일의 역할

| 파일 | 내용 |
|---|---|
| `trial_set.json` | 시험, 조건, 원문 위치와 조건 사이의 논리 관계 |
| `patient_pairs.json` | 가상 환자의 전체 상태, 가린 시작 상태, 답, 확인 방법과 전후 판단 |

같은 공개 원본과 설정으로 자료를 다시 만들고 두 파일 전체가 같은지 검사한다.

## 4. TREC Clinical Trials 2021·2022

TREC에는 환자 설명, 시험 ID와 전문가 관련성 등급이 있다. TrialGPT 공개 방식의 BM25와
MedCPT 검색 순위를 합쳐 관련 시험이 상위 500개 안에 남는지 평가했다.

| 항목 | 2021 | 2022 |
|---|---:|---:|
| 시험 문서 | 26,149건 | 26,581건 |
| 평가 깊이 | 상위 500개 | 상위 500개 |
| 결합 검색 관련 시험 유지 | 83.59% | 81.55% |

TREC에는 처음에는 가려졌다가 질문 뒤 나오는 환자 정보, 알맞은 질문과 종료 시점 정답이
없다.

## 5. TrialGPT 조건 판단 자료

- 조건: 1,015개
- 환자: 53명
- 환자–시험 조합: 105개
- 임상시험: 103개

각 행에는 환자 기록, 참가 조건, TrialGPT 판단, 전문가 판단과 근거가 있다. 이 자료는
질문 전 한 번의 조건 판단을 평가한다. 질문 뒤 나올 환자 답, 어떤 정보를 먼저 확인할지,
확인 방법과 환자 부담 정답은 포함하지 않는다.

공개 답과 전문가 답의 경계가 애매한 사례가 있어, ClarifyTrial의 중심 평가는 조건 답
이름만 아니라 후보 유지·현재 확인·질문 뒤 변화로 분리한다.

## 6. 환자 부담 합성 상황

기존 합성 환자의 임상값은 유지하고 환자 상황과 자료 가용성만 바꾼다.

- 환자 상황: 추가 부담이 낮음, 이동·비용 제약, 시간 긴급
- 확인 방법: 환자 답변, 내부 기록, 외부 기록, 기존 공식 결과, 새 검사, 의료진 판단
- 저장 항목: 대기시간, 방문, 비용 범주, 신체·심리 부담, 위험과 승인 필요 여부
- 전체 상황: 360개

실제 금액이나 환자 선호를 만들어내지 않는다. 이 자료는 확인 방법 선택 코드가 입력된
제약을 지키는지 검사한다.

## 7. 과거 자료의 역할

`data/broad_rescue_maturity_v1`의 합성 시험 50건과 합성 환자 50명은 전체 프로그램과
지표를 먼저 점검한 자료다. 현재 성능 수치에는 사용하지 않는다. 기존 3개 질환·15개
시험 자료도 기능 회귀 검사와 과거 비교를 위해 보존한다.

## 8. 재생성 순서

```powershell
.\.venv\Scripts\clarifytrial.exe prepare-team-trials
.\.venv\Scripts\clarifytrial.exe select-team-evaluation-trials `
  --trials .research-cache\team-trials\trials.jsonl `
  --output runs\team-trial-expansion\selection.json
.\.venv\Scripts\clarifytrial.exe build-public-protocol-benchmark `
  --output runs\public-protocol-benchmark-rebuild
.\.venv\Scripts\clarifytrial.exe audit-public-protocol-benchmark
```

외부 자료의 원본, 받은 날짜와 이용 조건은 [DATA_SOURCES.md](../../DATA_SOURCES.md)에 있다.
