# ClarifyTrial 실험자료 구성

임상시험 검색, 개별 조건 판단, 질문 순서와 환자 부담은 서로 다른 정답이 필요하다.
한 자료로 모든 성능을 계산하지 않는다.

## 1. 자료가 서로 연결되는 방식

임상시험 원문과 환자 기록은 처음에는 별개의 자료다. 실험에서는 환자 한 명과 시험
여러 건을 연결하고, 각 시험의 조건을 환자 정보와 비교해 기대 결과를 만든다.

```text
임상시험 원문
→ 계산 가능한 참가 조건 일부를 구조화
                          ┐
                          ├→ 환자와 시험을 연결 → 조건별 기대 결과
합성 환자의 전체 상태   ┘                         → 숨길 정보와 확인 방법
→ 일부 사실을 감춘 시작 입력                     → 질문 뒤 기대 결과
```

한 환자가 가진 정보 수와 전체 임상시험 수가 같을 필요는 없다. 중요한 단위는
`환자 한 명 + 시험 한 건 + 그 시험의 개별 조건`이다.

## 2. 세 가지 예

| 환자 전체 상태 | 시험 조건 | 시작 입력에서 감춘 것 | 처음 기대 결과 | 확인 뒤 기대 결과 |
|---|---|---|---|---|
| 당화혈색소 7.2%, 오늘 검사 | 최근 14일 이내 당화혈색소 6.5% 이상 | 검사값과 날짜 | 후보 유지, 추가 확인 필요 | 후보 유지, 현재 확인 완료 |
| 혈소판 70,000/µL | 혈소판 100,000/µL 이상 | 혈소판 수치 | 후보 유지, 추가 확인 필요 | 후보 제거, 참가 조건 불충족 |
| 과거 전신치료 1회 | 전신치료 2회 이상이면 제외 | 치료 횟수의 공식 기록 출처 | 후보 유지, 추가 확인 필요 | 후보 유지, 현재 확인 완료 |

첫 번째와 세 번째는 질문 뒤 실제 후보로 확정되는 사례다. 두 번째는 처음에는 정보가
없어 후보로 남지만 답을 확인하면 제외되는 사례다. 두 방향을 모두 넣어야 후보를 무조건
많이 남기는 방식이 좋은 점수를 받지 않는다.

## 3. 공개 임상시험 모음

### 팀 공개 시험 1,931건

ClinicalTrials.gov에서 받은 공개 시험을 한 줄에 한 건씩 저장한 자료다. 현재 모집 중,
모집 예정 또는 초대 등록 중인 589건을 검색에 사용한다.

한 줄에는 시험 번호, 제목, 질환, 요약, 참가 조건 원문, 성별, 나이, 모집 상태와 단계가
있다. 환자별 관련성 정답이나 참가 가능 정답은 없다. 따라서 이 자료만으로 전체 추천
정확도를 계산할 수 없다.

### 정밀 평가 시험 50건

589건 가운데 10개 질환에서 시험 5건씩을 골랐다. 공개 원문에서 코드가 객관적으로
계산할 수 있는 조건 202개를 구조화했다.

- 최소·최대 나이
- 단일 수치와 비교 방향
- 명확한 예·아니오 상태
- 짧고 뜻이 분명한 조건
- 원문에서 `모두`, `하나 이상`, `일정 개수 이상` 관계가 명시된 일부 묶음

202개는 시험 50건의 전체 참가 조건이 아니다. 복잡한 예외, 시험군마다 다른 조건,
담당자의 임상 판단이 필요한 문장은 포함하지 않았다.

## 4. 공개 시험 기반 합성 환자

합성 환자 50명은 다음 순서로 만들었다.

1. 질환과 연결 시험 5건을 정한다.
2. 조건에 필요한 환자 사실의 전체 값을 만든다.
3. 각 시험이 전체 상태에서 후보인지 부적합인지 계산한다.
4. 시작 입력에서 사실 1개, 2개, 3개 또는 5개를 감춘다.
5. 감춘 답과 확인 가능한 방법을 실행 프로그램과 분리해 저장한다.

환자 20명은 자료 제작과 정책 조정에 사용했고, 나머지 30명은 최종 전체 흐름 점검에
사용했다. 환자마다 시험 5건을 연결하므로 최종 점검에는 150개 시험 판단이 있다.

### 두 가지 정보 부족

| 종류 | 시작 입력 | 확인할 내용 |
|---|---|---|
| 값이 없음 | 검사명이나 병력 자체가 보이지 않음 | 값 또는 상태가 무엇인지 |
| 값은 있으나 근거가 부족함 | 수치는 보이지만 날짜, 자료 출처 또는 공식 확인이 없음 | 현재 단계에서 쓸 수 있는 최신·공식 근거인지 |

값이 없는 사례는 필요한 질문을 찾는 능력을 본다. 근거가 부족한 사례는 참가 가능성과
현재 확인 완료를 분리하는 능력을 본다.

## 5. 기존 평가와 겹치지 않는 새 시험 자료

기존 시험 50건과 겹치지 않는 5개 질환의 공개 시험 30건을 따로 골랐다.

| 구분 | 시험 | 구조화 조건 | 합성 환자 | 환자–시험 판단 |
|---|---:|---:|---:|---:|
| 개발용 | 15건 | 63개 | 25명 | 75개 |
| 최종 평가용 | 15건 | 53개 | 25명 | 75개 |

각 질환에서 시험 6건을 정한 뒤 앞의 3건은 개발용, 뒤의 3건은 최종 평가용으로
고정했다. 최종 평가의 기대 결과는 실행 프로그램의 판정 함수를 사용하지 않고,
구조화한 비교 연산자와 합성 값을 별도 계산해 만들었다.

이 분리는 같은 시험과 조건을 보며 프로그램을 고친 뒤 그 자료에서 다시 점수를 내는
문제를 줄인다. 다만 환자와 정답이 여전히 합성이며, 객관적으로 구조화한 일부 조건만
평가한다.

## 6. TREC Clinical Trials 2021·2022

TREC Clinical Trials는 환자 설명과 관련 임상시험을 전문가가 표시한 공개 검색
평가자료다.

| 자료 | 환자 설명 | 시험 문서 | 전문가 판정 행 |
|---|---:|---:|---:|
| 2021 | 75개 주제 | 26,149건 | 35,832개 |
| 2022 | 50개 주제 | 26,581건 | 35,394개 |

사용 목적은 수만 건의 시험에서 관련 시험을 검색 결과 위쪽에 남기는지 확인하는 것이다.
질문 생성, 개별 참가 조건 판단과 질문 뒤 상태 변화는 평가할 수 없다. 전문가가 판단하지
않은 환자–시험 조합을 자동으로 관련 없음으로 취급하지 않는다.

## 7. TrialGPT 조건 판단 자료

TrialGPT Criterion Annotations에는 다음 세 항목이 한 줄에 들어 있다.

1. 환자 기록
2. 임상시험의 선정 조건 또는 제외 조건 하나
3. 전문가 답과 TrialGPT 공개 답

전체 규모는 조건 1,015개, 환자 53명, 환자–시험 조합 105개다. 조건 원문이 비어 있는
1개 행은 모델 실행에서 제외한다.

이 자료로 평가할 수 있는 것은 질문하기 전 한 번의 조건 상태와 근거 선택이다. 여러
시험의 추천 순위, 어떤 질문을 먼저 할지, 답을 받은 뒤 언제 멈출지는 정답이 없다.

공개 파일의 `training` 열은 공식 설명이 없고, 값이 공개 TrialGPT 답과 전문가 답의
일치 여부를 거의 그대로 반영한다. 학습 자료와 최종 평가자료를 나누는 열로 사용하지
않는다. 환자를 기준으로 개발과 평가를 분리했다.

## 8. 환자 부담 합성 상황

같은 정보를 얻는 여러 방법을 비교하기 위해 360개 합성 상황을 만들었다. 다음 값이
조합돼 있다.

- 이미 병원 기록에 있는지, 외부 기관에 있는지, 새로 만들어야 하는지
- 환자에게 질문해도 되는 정보인지
- 새 검사나 추가 방문이 필요한지
- 예상 대기, 이동, 직접 비용과 신체·심리 부담
- 시간이 급한지
- 환자가 새 검사, 추가 방문 또는 특정 절차를 허용하는지

이 자료의 정답은 입력된 제한을 지키는 확인 방법이다. 실제 환자가 각 부담을 얼마나
중요하게 생각하는지나 실제 검사비를 추정하는 자료는 아니다.

## 9. 자료별 가능한 평가

| 자료 | 평가할 수 있는 것 | 평가할 수 없는 것 |
|---|---|---|
| 공개 시험 1,931건 | 검색 프로그램 입력과 모집 상태 필터 | 환자별 참가 가능 정답 |
| 공개 시험 기반 합성 자료 | 질문 전후 후보 보존, 확정, 제외와 전체 실행 | 실제 환자 정확도와 전체 프로토콜 판단 |
| 새 시험 합성 자료 | 개발과 분리한 구조화 조건 최종 평가 | 자유 문장 임상 추론 일반화 |
| TREC | 관련 시험 검색 순위 | 조건 판단과 질문 정책 |
| TrialGPT 조건 자료 | 개별 조건의 답과 근거 | 대화, 다음 행동과 여러 시험 전체 추천 |
| 환자 부담 합성 상황 | 입력된 제한을 지키는 확인 방법 | 실제 환자 선호와 임상 편익 |

## 10. 파일 위치와 재생성

| 자료 | 위치 |
|---|---|
| 공개 시험 기반 평가 | `data/public_protocol_benchmark_v1/` |
| 새 시험 평가 | `data/independent_new_trial_benchmark_v1/` |
| 자연어 예비자료 | `data/natural_evaluation_v1/`, `data/natural_evaluation_v2/` |
| 자료 제작 설정 | `configs/` |
| 외부 원본과 큰 검색 파일 | `.research-cache/` — Git에 포함하지 않음 |

재생성 명령과 점검 순서는 [실행과 실험 안내](CLARIFYTRIAL_V5_DEVELOPED_EXPERIMENT_GUIDE.md),
공개 주소와 이용 조건은 [자료 출처](../../DATA_SOURCES.md)에 있다.
