# ClarifyTrial 실험자료

환자 기록은 모두 합성 자료다. 임상시험 조건은 공개 원문에서 가져왔다. 검색, 질문
전후의 변화, 정보 연결 구조와 환자 제한은 필요한 정답이 달라 별도 자료로 평가한다.

## 전체 구성

| 자료 | 규모 | 확인한 내용 |
|---|---:|---|
| 공개 시험 원문 | 1,931건, 검색 대상 589건 | 후보 시험 검색과 참가 조건 원문 입력 |
| 공개 시험 질문 평가 | 질환 10개, 시험 50건, 조건 202개, 합성 환자 50명 | 기본 문진 뒤 남은 미확정 시험의 질문 전후 변화 |
| 적격·부적격 방향별 평가 | 질환 3개, 시험 15건, 조건 80개, 초기 독립 합성 환자 20명 | 적격 복원과 부적격 정리를 같은 확인 예산에서 함께 측정 |
| 정보 연결 구조 | 9종 × 200개, 모두 1,800개 | 어느 연결 모양에서 질문 순서가 영향을 주는지 |
| 확인 방법 통제 실험 | 합성 환자 20명, 가린 사례 40개 | 환자 상황에 따라 같은 정보를 얻는 방법이 바뀌는지 |
| 환자 제한 실험 | 합성 환자 20명, 짝지은 설정 80개 | 금지한 새 검사와 방문을 제거했을 때의 변화 |
| 새 시험 구조화 점검 | 시험 30건, 합성 환자 50명 | 개발과 겹치지 않는 조건에서 코드와 모델 역할 비교 |
| 공식 대회 합성 환자 | 10명 | 자유 문장 입력부터 결과 저장까지의 연결 |
| TREC Clinical Trials 2021·2022 | 환자 설명 125개, 시험 문서 약 2만 6천 건씩 | 공개 후보 검색 절차 재현 |
| TrialGPT 조건 표시 자료 | 환자 기록과 조건 1,015쌍 | 질문 전 개별 조건의 답 이름 비교 |

## 1. 공개 시험 원문

ClinicalTrials.gov에서 받은 공개 시험을 한 줄에 한 건씩 저장했다. 고정한 자료에는
1,931건이 있으며 모집 중, 모집 예정 또는 초대 등록 중인 589건을 검색에 사용한다.
시험 번호, 제목, 대상 질환, 요약, 참가 조건 원문, 성별, 연령, 모집 상태와 단계가
들어 있다.

환자별 관련성이나 참가 가능 여부는 원문에 붙어 있지 않다. 1,931건은 검색 범위를
뜻하며 추천 정확도를 계산할 때 분모로 쓰지 않는다. 원본 주소, 받은 날짜와 이용 조건은
[자료 출처](../../DATA_SOURCES.md)에 있다.

## 2. 공개 시험 질문 평가

### 2.1 시험과 조건

검색 대상 589건 가운데 다음 10개 질환에서 시험 5건씩 골랐다.

- 방광암
- 폐섬유증
- 급성 췌장염
- 갑상선 안병증
- 신증후군
- 편두통
- 망막박리
- 만성 췌장염
- 폐암
- 난소암

시험 50건의 참가 조건 원문은 내용이 있는 줄 2,118개로 이루어져 있다. 여기서 코드로
계산할 수 있는 조건 202개를 구조화했다. 연령 범위, 단일 수치 비교, 임신·수유 여부,
활동성 중증 감염, 짧은 예·아니오 조건과 원문에 관계가 표시된 일부 논리 묶음이
포함된다.

202개가 시험 50건의 모든 참가 조건을 나타내지는 않는다. 복잡한 예외, 시험군별 차이와
임상 판단이 필요한 문장은 이번 질문 평가에서 제외했다.

자료 위치:

- `data/public_protocol_benchmark_v1/trial_set.json`
- `data/public_protocol_benchmark_v1/patient_pairs.json`

### 2.2 합성 환자

질환마다 합성 환자 다섯 명을 만들었다. 한 환자에게 같은 질환의 시험 다섯 건을
연결하고 구조화 조건에 필요한 값과 날짜를 완성했다. 각 시험의 예상 상태를 별도
계산으로 정한 뒤, 추가 확인에 쓸 일부 정보를 시작 입력과 분리했다.

| 구분 | 환자 | 용도 |
|---|---:|---|
| 자료 제작·조정 | 20명 | 생성 규칙, 조건 계산과 정보 선택 방법 점검 |
| 최종 평가 | 30명 | 질문 전후 변화와 질문 순서 비교 |

통계 표본은 환자 30명이다. 환자 한 명의 시험 다섯 건을 서로 독립인 다섯 환자로 세지
않는다. 같은 질환의 환자 세 명은 시험 다섯 건을 공유하므로 질환별 결과도 새로운
시험 묶음에 대한 일반화 수치로 쓰지 않는다.

### 2.3 최종 평가의 시작 입력

나이, 임신·수유 여부, 활동성 중증 감염은 기본 문진 정보로 처음부터 제공한다. 세
정보를 넣은 뒤에도 남아 있는 환자별 추가 확인 정보는 1~4개였다.

시험 원문의 한 조건은 자유 문장으로 나이를 표현해 구조화한 나이와 다른 정보처럼
남아 있었다. 같은 환자 사실로 묶기 전에는 이미 아는 나이를 묻는 사례가 다섯 건
나왔다. 자료를 고친 뒤 다시 생성한 최종 결과에서는 중복 나이 질문이 0건이었다.

환자-시험 조합 150개 가운데 28개는 세 기본 정보를 넣기 전에도 처음 환자 자료만으로 상태가 정리돼
있었다. 세 정보를 넣자 합성 전체 상태에서 제외될 68건과 참가 가능 후보 32건이
추가로 정리됐다. 질문 전까지 모두 128개의 상태가 정해졌고, 나머지 22개가 추가 정보를
기다렸다. 이 22개는 기본 문진 뒤에도 남은 후보라는 조건이 붙은 평가 대상이다.

환자마다 한 번까지 확인하며, 질문이 필요 없는 환자에게는 확인 횟수를 채우지 않는다.
프로그램이 정보를 고른 뒤에만 분리해 둔 답을 공개한다. 전체 환자 상태에 없는 사실을
답변 과정에서 새로 만들지 않는다.

재생성 결과:

- `runs/public-protocol-common-facts-known-rebuild-v2/`

### 2.4 가능한 질문 순서

최종 평가에서 남은 정보가 한 개면 순서는 한 가지다. 네 개면 24개 순서를 모두
실행한다. `가능한 순서 전체 평균`은 무작위로 몇 번 뽑은 값이 아니며 모든 순서의 산술
평균이다.

비교하는 방법은 다음과 같다.

- 추가 확인 없음
- 자료 파일에 적힌 순서
- 가능한 순서 전체 평균
- 현재 미확정 시험과 조건에 많이 연결된 정보 우선
- 남은 확인 횟수의 조합을 함께 계산하는 방법

같은 환자, 시험, 숨긴 답, 확인 횟수와 최종 판정 규칙을 모든 방법에 사용한다.

### 2.5 기본 문진 민감도

처음 만든 자료는 나이, 임신·수유 여부와 활동성 중증 감염도 질문 후보에 넣었다. 이
자료에서 현재 규칙은 30명 가운데 29명에게 나이를 먼저 물었다. 자료 구성의 영향을
확인하려고 다음 세 설정을 모두 남겼다.

| 시작 입력 | 쓰임 |
|---|---|
| 기본 세 정보 없음 | 처음의 큰 질문 순서 차이가 생긴 이유 확인 |
| 나이 제공 | 나이 한 항목의 영향 확인 |
| 나이·임신/수유·감염 제공 | 실제 기본 문진을 가정한 최종 평가 |

초기 설정의 36.5%포인트 차이는 최종 성능 수치로 사용하지 않는다. 기본 문진 정보를
추가할수록 질문 순서 차이가 3.44%포인트, 0.44%포인트로 줄어드는 민감도 결과로
해석한다.

### 2.6 적격·부적격 방향별 보완 평가

기본 문진을 제공한 10개 질환 평가는 질문 전 미정 22건이 모두 전체 정보 기준 적격인
사례였다. 부적격으로 정리되는 방향까지 같은 조건에서 보기 위해 2형 당뇨병, 유방암과
주요우울장애의 공개 시험 15건에서 구조화 조건 80개를 골랐다. 합성 환자 30명 가운데
10명은 자료 제작·조정, 20명은 초기 독립 평가에 사용했다.

초기 독립 환자마다 두 가지 정보 가림을 적용하고 같은 질환의 시험 다섯 건을 연결했다.
따라서 평가는 환자 20명, 가림 사례 40개, 환자-시험 관측 200개로 펼쳐지지만 통계 단위는
환자 20명이다. 각 가림은 기본 사실 두 개만 보이고 나머지 다섯 사실을 숨긴다. 질문
선택이 끝난 뒤에만 숨긴 합성 답을 공개한다.

처음부터 전체 정보 기준 상태와 같았던 관측은 80개였다. 미정 120개 가운데 전체 정보
기준 적격은 30개, 부적격은 90개였다. 이 두 분모를 각각 적격 복원 기회와 부적격 정리
기회로 사용한다. 자료와 고정한 공개 원문은 다음 위치에 있다.

- `configs/interactive_public_benchmark_v1.json`
- `data/interactive_public_benchmark_v1/source_snapshot/`

## 3. 정보 연결 구조 1,800개

공개 시험 자료 한 묶음에만 기대지 않고 질문 순서의 작동 조건을 보기 위해 합성 연결
구조를 만들었다.

| 항목 | 구성 |
|---|---:|
| 연결 모양 | 9종 |
| 모양마다 만든 구조 | 200개 |
| 전체 구조 | 1,800개 |
| 구조마다 가능한 정보 상태 | 32개 |
| 비교한 정보 선택 방법 | 12개 |
| 허용한 확인 | 1회·2회·3회 |
| 확인 횟수 하나의 방법–상태 계산 | 691,200회 |
| 세 확인 횟수의 전체 계산 | 2,073,600회 |

연결 모양에는 완전 공유, 완전 분리, 공유 중심, 사슬, 겹치는 쌍, 낮은 공유, 세 갈래,
단계형 중심과 부담 충돌이 들어 있다. 같은 구조에 확인 1회·2회·3회를 각각 적용했다.
주 비교는 확인 2·3회의 단계별 무작위·영향 우선·조합 탐색이며, 확인 1회는 첫 선택의
효과를 분리한 보조 분석이다. 구조마다 환자 정보의 참·거짓 조합을 바꾸고, 개발 분포와
비슷한 평가와 일부 조건을 바꾼 평가를 분리했다.

이 자료는 의료 조건의 정확도를 재지 않는다. 시험–환자 정보 연결 모양이 질문 선택에
미치는 영향을 확인하는 통제 실험이다.

결과 위치:

- `runs/policy-scale-20260830/budget-2/structural-1800/`
- `runs/policy-scale-20260830/budget-3/structural-1800/`
- `runs/policy-scale-20260830/budget-1/structural-1800/` — 보조 진단

## 4. 확인 방법 통제 실험

어떤 정보를 확인할지와 그 정보를 얻는 방법을 나눠 보기 위해 같은 합성 답을 주는 두
확인 방법을 붙였다.

| 방법 | 대기 | 새 검사 | 추가 방문 |
|---|---:|---:|---:|
| 기존 공식 결과 조회 | 72시간 | 없음 | 없음 |
| 새 비침습 검사 | 8시간 | 있음 | 있음 |

합성 환자 20명에서 정보 두 개씩을 가린 40개 사례를 만들었다. 부담 최소, 이동·비용
제한, 시간 긴급 설정을 각각 적용한다. 두 방법의 답이 같아 정보 순서와 최종 시험
상태를 유지하면서 확인 방법만 비교할 수 있다.

시간과 부담에는 프로그램의 선택이 분명하게 갈리도록 정한 합성 값을 사용했다. 실제
의료 환경의 수치를 추정하는 데에는 쓰지 않는다.

결과 위치:

- `runs/policy-scale-20260830/route-choice-controlled/`

## 5. 환자 제한 실험

새 검사와 추가 방문을 허용하지 않는 환자 설정을 만들었다. 합성 환자 20명에 숨길 정보
조합 2개와 자료를 얻을 수 있는 상황 2개를 적용했다. 같은 80개 설정을 허용하지 않은 방법을
남긴 방법과 먼저 제거한 방법으로 각각 실행한다.

저장하는 결과는 다음과 같다.

- 새 검사와 추가 방문을 제안한 횟수
- 실행이 끝난 뒤 남은 확인 대기 시험
- 시험 다섯 건을 모두 정리한 설정 수
- 선택한 행동 수와 합성 대기시간
- 현재 허용된 확인 방법으로 알아낼 수 있는 정보만 놓고 계산한 개발용 목표 일치율

마지막 값은 채점 대상에서 알아낼 수 없는 정보를 빼므로 임상 정확도를 나타내지 않는다.
프로그램이 환자 제한을 무시한 결론을 높은 점수로 처리하지 않는지 확인하는 내부
점검값이다.

결과 위치:

- `runs/policy-scale-20260830/burden-ablation-final/`

## 6. 개발과 겹치지 않는 새 시험

주 평가 시험 50건과 겹치지 않는 5개 질환의 공개 시험 30건을 따로 골랐다.

| 구분 | 시험 | 구조화 조건 | 합성 환자 | 환자–시험 연결 |
|---|---:|---:|---:|---:|
| 개발용 | 15건 | 63개 | 25명 | 75건 |
| 최종 점검용 | 15건 | 53개 | 25명 | 75건 |

구조화한 조건을 코드와 언어모델 실행이 어떻게 처리하는지 확인하는 보조 자료다. 기대
결과와 프로그램이 같은 구조화 규칙 계열을 사용하므로 자유 문장 의료 추론의 성능
자료로 쓰지 않는다.

위치: `data/independent_new_trial_benchmark_v1/`

## 7. 공식 대회 합성 환자

공식 합성 환자 10명은 자유 문장 입력에서 프로필을 정리하고, ClinicalTrials.gov를
검색하고, 조건을 나누고, 필요한 정보를 묻고, 결과를 저장하는 연결 점검에 사용한다.
시험별 참가 가능 정답이 없으므로 추천 정확도를 계산하지 않는다.

## 8. TREC Clinical Trials 2021·2022

TREC Clinical Trials에는 환자 설명과 관련 임상시험에 대한 전문가 표시가 있다.

| 자료 | 환자 설명 | 시험 문서 | 전문가 판정 행 |
|---|---:|---:|---:|
| 2021 | 75개 | 26,149건 | 35,832개 |
| 2022 | 50개 | 26,581건 | 35,394개 |

수만 건의 시험에서 관련 시험을 검색 결과에 남기는지 평가한다. 개별 참가 조건, 다음
질문, 답변 뒤 상태 변화는 평가할 수 없다. 전문가가 표시하지 않은 모든 환자–시험
조합을 관련 없음으로 간주하지 않는다.

## 9. TrialGPT 조건 표시 자료

TrialGPT Criterion Annotations의 한 행에는 환자 기록, 임상시험 조건 하나, 전문가 답과
TrialGPT 공개 답이 들어 있다. 전체 규모는 조건 1,015개, 환자 53명, 환자–시험 조합
105개다. 원문 조건이 비어 있는 한 행은 모델 실행에서 제외한다.

이 자료에는 질문 전 개별 조건의 답이 있다. 여러 시험의 추천 순위, 다음에 확인할 정보,
답변 뒤 상태 변화와 종료 시점은 표시돼 있지 않다. 공개 파일의 `training` 열도 학습과
최종 평가를 나누는 공식 표지로 확인되지 않아 분할에 사용하지 않았다.

## 11. 선정 후 새 시험과 실패 가능한 근거 획득 — 활성

`data/paper_source_benchmark_v1/protocol_subsets.json`은 2026-10-22 수집한 공개 시험
검색 6개 층에서 만들었다. 기존 자료의 시험 번호 126개를 제외하고, 전 세계 검색 결과
중 지원 가능한 수치 조건이 있는 새 중재 시험을 조회 순서대로 8개씩 선택했다. 층 사이
중복을 없애고 고정 난수로 각 4건을 개발, 4건을 평가에 배치했다. 환자 값이나 정책
결과를 생성하기 전에 분할했다. 수집·재구성은 `collect_paper_trial_sources.py`,
`build_paper_trial_benchmark.py`로 재현한다. 재조회 시 등록 정보가 달라질 수 있으므로
같은 평가를 재현할 때에는 저장한 파생자료를 사용한다.

| 구분 | 시험 | 선택한 수치 조건 | 조건 하나만 포함한 시험 |
|---|---:|---:|---:|
| 개발로 배치 | 24 | 30 | 19 |
| 별도 평가 | 24 | 30 | 19 |

원문 인접 문맥을 저자가 확인하면서 복수 코호트, 여러 단계, 조건부 예외와 다중 행 OR를
하나의 필수 조건으로 펴면 안 되는 시험을 제외했다. 독립 임상가 주석은 아니다.
체중 변화·건체중을 현재 체중으로 읽지 않으며, `mg/dL`와 `g/dL`, 체표면적 보정 유무를
구분한다. `x 10^3/uL`은 수치에 1,000을 반영하고, 혈색소 `g/L`은 `/10`으로 `g/dL`에
맞춘다. 원문과 변환 전 수치는 보존한다. 전체 48건에는 비어 있지 않은 원문 행 1,394개가
있다. 조건 60개를 1,394개의 전체 조건 중 60개라고 세면 안 되며 행에는 제목도 들어 있다.
이 자료의 좁은 범위를 보여 주는 수치다.

개발 답 분포는 층당 64개, 총 384개의 합성 전체 특징 벡터로 계산한다. 평가에는 층당
새 환자 48개, 총 288개의 기본 합성 벡터와 같은 난수의 값 분포를 바꾼 288개 변형을 쓴다.
각 벡터의 두 가림 설정·방문 상한·확인 예산·방법·근거 품질 설정은 반복 관측이며 새
환자 수로 더하지 않는다. 수치 벡터는 제한된 정보 획득을 위한 가상 사례로, 실제 질환의
유병 분포나 생리적 공동분포를 재현하지 않는다. 시험의 나이·성별·병기·치료력 등 선택하지
않은 조건을 충족한다고 가정하거나 전체 참가 자격을 부여하지 않는다.

평가 프로그램은 직접 연산자를 계산하는 별도 정답 함수, 연구 계획기, 기존 실제 판정
엔진의 결과를 대조한다. 이 분리는 코드 오류를 찾기 위한 것이며 원문 해석의 독립적인
의학적 정답을 대신하지 않는다. 자세한 결과와 제한은 검증 결과 9절을 따른다.

## 12. 같은 공개 원문의 논리 확장 — 탐색 분석 완료

`paper_source_benchmark_v2/protocol_subsets.json`은 위 48개 시험과 분할을 재사용한다.
환자 결과를 본 뒤 평가 쪽 원문에서 범위·대안·예외를 더 표현한 자료이므로 새 독립
평가로 부르지 않는다. 개발 쪽은 그대로 24건·비교식 30개, 평가 쪽은 24건·비교식
93개다. 연구자 선언 30개가 추가됐으며 임상가 주석이나 자동 NLP 추출 결과가 아니다.
평가 시험 중 비교식 하나인 시험은 19건에서 8건으로 줄었다. 비교식은 동일 사실의
여러 경계와 같은 이진 표지의 반복을 포함한다.

범위, UACR/eGFR의 세 대안, LVEF에 따른 NT-proBNP 기준, 간 전이·Gilbert 표지에
따른 일부 검사 예외를 모두/하나 이상 트리로 보존한다. 원문 위치·원문 술어·적격 방향
논리 트리를 함께 저장한다. ‘조절되지 않는 당뇨’ 설명과 `HbA1c <8.5%`가 같이 있는
문구를 임의로 반대로 고치지 않았으며 축약과 빠진 대안도 보류로 남겼다. 같은 원문
행에 수치가 있어도 나머지 임상 의미가 미지원일 수 있어 부분 표현 행으로 표시한다.

확장한 특징에서 기본 합성 벡터 288개와 값 분포 변형을 다시 생성했다. 같은 난수
방식이더라도 특징 수와 값이 달라 초기 버전의 점수와 직접 비교하지 않는다. 주 재생은
103,680회, 방문 벌점 민감도는 27,648회다. 576개의 환자–가림 설정을 독립 환자로
세지 않으며, 실제 의료적 공동분포·전체 프로토콜의 정답도 아니다.

평가 시험별 결과와 환자별 첫 후보 확인을 별도로 집계했다. 환자와 시험의 교차 재표집은
원래 후보 집합에서 실행한 행동 기록의 평가 가중치 민감도다. 새로 뽑은 시험 집합에서
정책을 다시 실행한 결과가 아니다. 범위와 한계는 검증 결과 10절, 유지할 표·그림은
[논리 확장 결과](results/paper-logic-v2/)를 따른다.

## 13. 자유 문장 논리의 합성 구성요소 자료 — 탐색 평가 완료

`scripts/run_natural_protocol_logic_research.py`의 `cohort()`에 고정한 저자 합성 영어
15문장이다. 실제 시험에서 표집하거나 임상가가 주석한 자료가 아니다. AND/OR·괄호·
개수·범위·열거와 독립 필수 행의 12문장에서 각 수치의 경계·대표값에 누락을 추가한
185관측을 만든다. 정리 가능한 관측 115개와 원래 미정인 70개이며 독립 환자가 아니다.
참고 정답은 생산용 논리 트리와 별도로 가능한 완전 수치를 직접 계산한다.

IF·범위 모호성·감염 상태의 나머지 3문장·33관측에는 충분한 임상 정답을 부여하지 않는다.
한 AND 항이 거짓일 때의 제외처럼 남은 정보와 무관하게 정당한 결론도 가능하므로 이
부분의 모든 결론을 오판으로 세지 않는다. 지원 문법과 가까운 탐색 표본이며 실제 문구의
NLP 성능으로 일반화하지 않는다.

동일 모델·추론 설정에서 기존/새 계약 각각 15회 호출한 응답은
[구성요소 결과](results/natural-protocol-v1/)의 `model-old.json`, `model-new.json`에 있다.
원문과 모델 제안·정보 요구·합성 관측을 보존한다. 환자 문장 모델과 임상 판단 모델은
평가하지 않았다. 제안/코드 교차 재생은 이 응답을 다시 사용할 뿐 모델을 호출하지 않는다.
다중 관측·여러 재생을 새 문장이나 환자 수로 더하지 않는다. 사용한 실행기는 `0.147.0`,
모델은 `gpt-5.6-sol` / `medium`, 실제 추론일은 2026-10-23이다. 자세한 결과는 검증
결과 11절에 있다.

## 14. 공개 원문 묶음의 자동 준비 자료 — 탐색적 재사용 완료

`data/paper_source_benchmark_v2/public_clause_probe_v1.json`은 같은 평가 시험 24건에서
시험별로 선언 잎이 가장 많은 묶음 하나, 동률이면 앞선 행을 골랐다. 전체 원문 인용과
이전 참고 식의 완전한 하위 트리를 보존한다. 신규 시험이나 독립 임상가 주석이 아니다.
비수치 문맥을 지우지 않았으며 전체 프로토콜 확인 허용은 거짓이다.

경계의 위·아래·같음과 누락을 사용한 448개 합성 관측이다. 큰 두 묶음은 각각 고정
난수로 129개를 뽑았다. 이전 수치 부분 해석에서 정리 가능한 관측 358개와 미정 90개이며
실제 환자 수나 전체 임상 원문의 정답으로 취급하지 않는다. 개념 표기는 모델 호출 전에
고정했다. 시점·단위가 맞지 않는 보류를 무조건 임상 오류로 세지 않는다.

기존 `c25e002`와 v7 `24ee3b3`에서 각각 24회 실제 모델 호출을 했고, 후속 v8은 보존한
제안을 재생했다. 출처·수집일·권리는 기존 원문과 같고 새 API 조회는 없다. 자료를 기존
원문 가족 폴더에 두어 신규 시험 제외 집합이 파생자료 때문에 달라지지 않게 했다.
분모·범위·반례와 고정 제안은 검증 결과 12절 및 [공개 문구 결과](results/public-clause-v1/)를 따른다.

## 15. 자료원 대조·공유 오류의 합성 사건 — 탐색 연구 완료

같은 v2 평가 시험 24건·부분 표현 93개, 기본 합성 벡터 288개와 두 가림을 재사용한다.
새 환자군이나 실제 자료원 독립성 주석이 아니다. 초기 보이는 값에는 올바르게 대조된
두 합성 기록을 제공한다. 새 획득 값의 충분한 기록 확률은 0.70/0.95, 오류 확률은 0.05다.
각 사실의 오류를 독립·절반 공유·완전 공유로 만들고, 복사본에서는 두 경로의 자료원
계열도 같다고 알린다. 실제 품질·독립성·방문이나 오류율의 추정이 아니다.

모든 비교군에 같은 잠재 답을 주며, 정책에는 실제 참값·오류 플래그·미래 답을 전달하지
않는다. 공유 시나리오별로 관측되는 오류율은 표집·선택 때문에 다를 수 있다. 기대상의
주변 오류 확률은 같다. 현재 값의 두 보고가 정확히 같아야 통과하는 고정 값 모형이며
임상 측정 변동이나 초기 내용 오류는 포함하지 않는다.

주 비교 55,296회와 한 칸 오류 변경 민감도 55,296회다. 같은 관측의 정책·예산·방문·
공유 조건을 새 환자 수로 더하지 않는다. 주 오류는 두 칸 이동하되 이진에는 한 칸을
적용한다. 기존 내용 오류 계산도 17,280회 다시 실행했고 그 고정 집계는 같았다.
유지할 표·요약·반례·그림은 [자료원 대조 결과](results/corroboration-v1/), 실제 범위와
해석은 검증 결과 13절을 따른다. 외부 원본의 수집일·권리는 기존 v2와 같다.

## 16. 조건별 결론 대조의 균등 오답 사건 — 탐색 연구 완료

15절과 같은 v2 시험·기본 벡터·가림을 재사용했다. 오류 때 참값을 제외한 다른 격자 값을
균등하게 뽑아, 자료원 둘이 서로 다른 오답을 낼 수 있도록 했다. .05/.15의 오류 확률과
독립/완전 공유를 교차했다. 공유 시에는 오답 값도 공유한다. 품질 .70/.95, 초기의
올바른 두 보고, 확인 3회·방문 최대 1회는 유지했다. 실제 임상 오류 모형의 추정이 아니다.

다섯 방법의 11,520회 재생에서 정확한 값 계획과 같은 행동의 방향 판정을 분리했다.
후속 방향 재계획도 같은 잠재 반환을 쓴다. 파생 재생을 새 환자 수로 더하지 않으며
공유 조건·오류 확률 변형과 앞 실험의 점수를 직접 연결하지 않는다. 원시 사건은
`runs/direction-full-20261023/`, 유지할 표·그림은
[조건 방향 대조 결과](results/direction-corroboration-v1/), 범위는 검증 결과 14절에 있다.
새 외부 환자 데이터나 API 조회는 없고 원문의 출처·권리는 기존 v2와 같다.

## 17. 외부 저자의 Leaf 논리 표현 — 준비 중

저자 선언 참고식의 한계를 줄이기 위해 UW Bio-NLP의 공개 `leaf_logical_forms`를
2026-10-23 받았다. 원시 주석 파일 2,060개는 시험 번호 885개·서로 다른 원문 묶음
1,999개에 해당한다. 같은 원문의 주석 21묶음 중 13묶음은 구문이 다르며 의미적으로
다른지는 별도 확인이 필요하다. 원문의 수치 경계·연결과 주석이 일치하지 않을 가능성도
있어 외부 주석을 전체 임상 정답으로 간주하지 않는다. 실제 환자 자료는 없다.

`preparation/leaf_reference.py`는 공백 행 수와 Python 키워드 모양의 함수 때문에
원본을 잃지 않도록 읽는다. 따옴표 안의 원문을 바꾸거나 JavaScript를 실행하지 않는다.
두 최상위 표현을 한 개로 잘라 읽지도 않는다. 단일 표현 구문 2,054개를 읽었고 나머지
6개는 보류한다. 수치 필터를 가진 주석은 479개, 제한한 후보 구문은 218개다. 후보는
의미 검증·중복 제거·최종 시험 분할을 마친 평가 표본과 다르다.

원본·이용 조건·재현은 [자료 출처](../../DATA_SOURCES.md)의 Leaf 절, 원시는
`runs/leaf-source-20261023/`, 준비 출력은 `runs/leaf-reference-prepared-20261023/`다.
받은 MIT 허가 문구를 함께 보존한다. 새 모델 호출·후속 성능 비교는 아직 하지 않았다.
