1. [현재 상태](CURRENT_STATUS.md)
   - 완료한 설계, 현재 구현 범위와 바로 이어서 할 작업
2. [에이전트 워크플로우](CLARIFYTRIAL_AGENT_ARCHITECTURE_REDESIGN.md)
   - 고정 에이전트 3개와 선택적 검토 1개의 역할, 호출 조건과 전체 흐름
3. [근거문헌](CLARIFYTRIAL_AGENT_SOURCE_INDEX.md)
   - 각 단계의 원 논문, 공개 코드, 가져온 부분과 재현 범위
4. [RAG·평가 구현계획](CLARIFYTRIAL_RAG_EVALUATION_IMPLEMENTATION_PLAN.md)
   - 자료 다운로드와 후처리, 검색기, 모델 교체, 공통 평가와 구현 순서
5. [검증 결과](CLARIFYTRIAL_VALIDATION_RESULTS.md)
   - 실제 실행 범위, 결과, 비용, 채택·기각 결정과 아직 주장할 수 없는 내용

연구 질문과 데이터 정답을 확인할 때는 다음 문서를 읽는다.

| [현행 연구계획 v5](CLARIFYTRIAL_RESEARCH_PLAN_V5.md) | 연구 질문, 가설, 정답 구조, 비교 실험과 주장 범위 |

연구계획은 v5 문서 하나를 기준으로 삼는다. 나머지 문서는 현재 상태, 구현, 자료와
근거를 설명한다. 진행 관리·검색/판정·다음 확인의 세 고정 에이전트와 선택적 근거
검토를 잇는 첫 코드가 있으며, 한 건의 합성 사례로 상태 흐름을 검사했다. Claude
API와 TrialGPT 공개 주석을 연결하고, 20명 개발 자료에서 지시문을 조정한 뒤 겹치지
않는 33명에게 고정 지시문을 적용했다. 선정·제외 비대칭 방식은 79.1%로 기존
지시문의 52.0%보다 높았지만 공개 TrialGPT 고정 출력 88.8%에는 미치지 못했다.
이는 v5 전체 흐름 성능이 아니라 조건 라벨 판단 실험이다.

GPT-5.6 Sol `medium` 개발 20조합 구조 비교에서는 강한 단일 구조가 68.7%, 역할
분리 구조가 65.9%, 정보 부족 재검토 구조가 65.4%였다. 재검토는 131개 조건을 다시
봤지만 라벨을 바꾸지 않아 정적 조건 판단에서는 기각했다. TrialGPT 공개 후보
검색은 같은 TREC 자료에서 재현을 마쳤고 결합 검색을 최소 기준으로 고정했다. 강한
단일 판단은 75.8%, 검색 없는 검토는 75.8%, 인터넷 검토는 74.9%였으므로 두 검토
방식은 기각했다. 고정 후보 5개, 확인 후보 5개와 행동 한도 3회를 가진 대화형 합성
사례 12명의 코드·Sol 작동 확인을 마쳤다. 각 사례의 32개 정보 조합을 전수 계산했다.
평균 우선과 최악 우선 질문 계산은 대화형 평가기에 구현했다. 공개 시험 15개, 구조화
조건 80개, 합성 환자 30명과 마스크 60회까지 실행했다. 가능한 환자 값 77,792조합을
추가로 계산한 결과, 단순 동적 규칙이 고정 평가와 균등 분포에서 더 높고 확인 부담도
낮았다. 따라서 복잡한 계산은 비교용으로만 보존하고 일반 실행기에 연결하지 않는다.
기존 자료와 새 검사, 환자별 시간·이동·비용·절차 부담을 나눈 행동 자료형과 사람
승인 경계, 두 결과 형식을 구현했다. 360개 환자·자료 상황에 다섯 방식을 적용한
1,800개 정책 실행도 마쳤다. 자연어 환자 기록 정리, TrialGPT 실행용 후보 검색,
시험 조건 정리와 질문·답변·재판정을 한 명령으로 잇는 코드도 구현했다. 합성
스크립트 모델로 근거 문구, 핵심값, 숨은 답 분리와 두 시험 재판정까지 검사했다.
띄어쓰기·줄바꿈은 허용하고 수치·날짜·비교 방향이 달라지면 거부하도록 수정했다.
Sol `medium` 합성 사례 한 건에서는 12회 호출로 최근 공식 결과를 확인하고 후보 두
건을 모두 확인 완료로 바꿨다. 이 결과는 연결 확인이며 정확도 결과가 아니다. 다음
작업은 공개 원문과 환자 문장을 구조화하는 외부 모델의 정확도를 소표본에서 재는
일이다. 판정 기준은
[RAG·평가 구현계획](CLARIFYTRIAL_RAG_EVALUATION_IMPLEMENTATION_PLAN.md)에 있다.
기존 15개 시험·80개 조건은 개발용으로만 사용한다. 새 공개 시험 15건과
새 기본 환자 30명의 근거 상태 짝 60회 예비자료를 만들었으며, 원문 정리·고정 후보 대화·후보
검색 포함 평가를 순서대로 분리한다. 새 공개 시험은 질환별 본 시험 5건과 예비 시험
5건, 총 30건으로 고정했다. 자동 규칙은 본 시험에서 객관적 조건 후보 164개를
표시했지만 누락을 막기 위해 조건 원문 272줄을 두 사람의 독립 검토표에 모두 넣었다.
AI 단독 예비 검토에서는 본 시험의 단순 조건 62개를 남겼다. 조건이 부족한 본 시험
6건을 같은 방식으로 검토한 예비 시험으로 교체해 최종 예비 구성은 15건·92조건이
됐다. 30명·60회 전체에서 같은 임상값과 후보 결과를 확인했고, 확인된 답을 넣으면
충분한 근거 쪽 결과로 돌아왔다. 사람 두 명의 독립 검토는 아직 없으므로 고정 정답이나
성능 결과로 보지 않는다. 다음은 개발 10명에서 자연어 구조화 정확도를 재는 일이다.
